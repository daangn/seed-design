## 버전 표시

컴포넌트와 훅 문서 상단에 그 항목이 처음 사용 가능해진 패키지 버전을 표시합니다. 문서를 보다가 "우리 프로젝트 버전에서 이걸 쓸 수 있나"를 `package.json`과 대조하지 않아도 됩니다.

<AvailableSince packages="@seed-design/react@2.1.0, @seed-design/css@2.3.0" />

## 기여 가이드와 크레딧

- 기여 가이드를 추가했습니다. 이슈를 열고 PR을 보내는 절차, 커밋 컨벤션, 로컬 개발 환경 셋업을 담았습니다.
- 크레딧 페이지에 지금까지 SEED에 기여한 사람들을 정리했습니다.
- 사이드바에서 최근에 추가되거나 크게 바뀐 페이지에 강조 점을 붙입니다.

## 문서 빌드 개선

- 프로덕션 빌드를 Turbopack으로 전환했습니다.
- TypeScript 7 컴파일러를 도입했습니다.
- llms.txt에서 토큰 표가 깨져 나오던 문제를 수정했습니다.
