## 구조

다음과 같은 LLMs.txt 파일들을 제공합니다:

- [llms.txt](https://seed-design.io/docs/llms.txt): LLMs.txt 파일들의 구조를 제공하는 메인 파일입니다.
- [llms-components.txt](https://seed-design.io/docs/llms-components.txt): 각 컴포넌트 디자인 가이드라인 문서의 진입점입니다.
  - [llms-components/action-button.txt](https://seed-design.io/docs/llms-components/action-button.txt)
  - [llms-components/chip.txt](https://seed-design.io/docs/llms-components/chip.txt)
  - etc...
- [llms-foundation.txt](https://seed-design.io/docs/llms-foundation.txt): Foundation 문서의 진입점입니다.
  - [llms-foundation/spacing.txt](https://seed-design.io/docs/llms-foundation/spacing.txt)
  - [llms-foundation/color/palette.txt](https://seed-design.io/docs/llms-foundation/color/palette.txt)
  - etc...
