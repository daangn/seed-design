## Anatomy

Content Placeholder는 Root 컨테이너와 Asset으로 구성됩니다. 컨테이너의 사이즈에 따라 내부 Asset을 자연스럽게 표시합니다.

- Asset의 최소 너비는 16px, 최대 너비는 64px이며 정방형 비율을 고정합니다.
