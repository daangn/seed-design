## 개요

Editor Toolbar는 모바일 웹뷰 환경에서 가상 키보드와 함께 사용되는 텍스트 편집 도구 모음입니다. 사용자가 텍스트 서식을 적용하거나 정렬, 리스트 등의 편집 기능을 쉽게 사용할 수 있도록 도와줍니다.

### 옵션 테이블

| 속성         | 값                           | 기본값        |
| ------------ | ---------------------------- | ------------- |
| showKeyboard | true, false                  | false         |
| layout       | iconWithText, iconOnly       | iconWithText  |
| selected     | true, false                  | false         |
