## Anatomy

Side Panel은 Backdrop, Content, Header, Close Button, Body, Footer로 구성됩니다.

```tsx
<SidePanelContent title="제목" description="설명을 작성할 수 있어요">
  <SidePanelBody>Content</SidePanelBody>
  <SidePanelFooter>Actions</SidePanelFooter>
</SidePanelContent>
```

## Properties

### Direction

Side Panel이 열리는 방향을 설정합니다. `left`, `right` 중 선택할 수 있으며, 기본값은 `right`입니다.

좌우(left/right) 방향 모두 높이가 100vh로 고정됩니다.

### Size

Side Panel의 너비를 설정합니다. `small` (480px), `medium` (720px), `large` (960px)를 지원합니다.

프리셋 외에 뷰포트 기반의 유동적인 너비가 필요할 때는 StyleProps를 통해 `width`, `maxWidth` 등을 직접 지정할 수 있습니다.

### Show Close Button

Close Button 사용 여부를 설정합니다. 기본값은 `true`입니다.

### Modal / Non-modal

기본적으로 Side Panel은 Modal로 동작하며, Backdrop이 표시되고 포커스가 트랩됩니다.

`modal={false}`로 설정하면 배경과 상호작용이 가능하고, Backdrop이 표시되지 않습니다.

## Guidelines

- Side Panel은 주로 데스크탑 환경에서 네비게이션, 상세 정보, 설정 패널 등에 사용합니다.
- 화면 하단에서 슬라이드 업되는 모달이 필요하다면 [Bottom Sheet](/docs/components/bottom-sheet)를 사용하세요.

### Responsive Side Panel

데스크탑에서 Side Panel을 사용하는 경우, 기본적으로 Responsive Side Panel을 사용합니다. md 이상에서는 Side Panel, sm 이하에서는 [Bottom Sheet](/docs/components/bottom-sheet)로 자동 전환되어 각 환경에 적합한 사용성을 제공합니다.

- md 이상 (768px+): Side Panel로 표시합니다.
- sm 이하 (~767px): Bottom Sheet로 표시합니다.
- 공통 제약: Header/Body/Footer 구조는 양 컴포넌트에서 동일하게 유지합니다.

### 예외: Side Panel을 직접 사용해야 하는 경우

다음과 같은 경우에는 Responsive Side Panel이 아닌 Side Panel을 직접 사용할 수 있습니다.

- 모바일 사이드 메뉴/네비게이션 (햄버거 메뉴, 프로필 진입 메뉴 등): sm 이하에서도 부분 너비 패널로 표시되어야 네비게이션 컨텍스트가 유지됩니다.
- Persistent Type이 필요한 경우: md 이상 전용 영구 패널로 사용합니다.
