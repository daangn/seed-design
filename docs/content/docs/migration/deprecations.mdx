title: Deprecations
description: Deprecated 항목의 현황과 제거 계획을 관리합니다.

이 문서는 deprecated 현황의 원천 파일입니다. 변경 시 이 문서를 먼저 업데이트합니다.

## Deprecated 현황

| 항목                                   | 종류          | Deprecated 버전 | 제거 예정 버전 | 대체안                 | 비고                                                         |
| -------------------------------------- | ------------- | --------------- | -------------- | ---------------------- | ------------------------------------------------------------ |
| AppBar - divider 옵션                  | 컴포넌트 옵션 | 1.2.x           | 2.0.0          | -                      | 제거 후 하단 구분선 미표시. rootage top-navigation 옵션 정리 |
| BottomSheet - direction 옵션           | 컴포넌트 옵션 | 1.2.x           | 2.0.0          | -                      | 2.0.0부터 제거. 항상 아래에서 올라옴                         |
| Drawer - noBodyStyles 옵션             | 컴포넌트 옵션 | 1.2.x           | 2.0.0          | -                      | 2.0.0부터 무시되어 기본값(true)처럼 동작                     |
| Drawer - preventScrollRestoration 옵션 | 컴포넌트 옵션 | 1.2.x           | 2.0.0          | -                      | 2.0.0부터 무시되어 기본값(false)처럼 동작                    |
| Snackbar - shouldCloseOnAction prop    | 컴포넌트 옵션 | 1.2.x           | 2.0.0          | 제거 (자동 닫힘이 표준 동작) | snippet의 액션 닫기 동작을 디자인 시스템 스펙으로 통일       |

## 제거 완료 히스토리

| 항목                          | 제거 버전 | 대체안                       | 비고                                       |
| ----------------------------- | --------- | ---------------------------- | ------------------------------------------ |
| $color.bg.layer-fill          | 1.3.0     | $color.bg.neutral-weak       | 더이상 사용하지 않음 (elevation 문서 안내) |
| $gradient.fade-layer-floating | 1.3.0     | -                            | 대체안 없이 제거                           |
| $gradient.fade-layer-default  | 1.3.0     | -                            | 대체안 없이 제거                           |
| ChipTabs variant=brandSolid   | 1.3.0     | neutralSolid, neutralOutline | 대체안 사용 시 디자인 변경됨               |
| Checkbox weight=stronger      | 1.3.0     | weight=bold                  | 네이밍 변경                                |
| Checkbox weight=default       | 1.3.0     | weight=regular               | 네이밍 변경                                |
| Switch size=small             | 1.3.0     | size=16                      | 네이밍 변경                                |
| Switch size=medium            | 1.3.0     | size=32                      | 네이밍 변경                                |
| StyleProps camelCase 값       | 1.3.0     | kebab-case 값                | display, flexDirection, justifyContent 등  |
| Image Frame rounded 옵션      | 1.3.0     | borderRadius="r2"            | rootage image-frame 옵션 정리              |
| AppBar divider 옵션           | 1.3.0     | -                            | 제거 후 하단 구분선 미표시                 |
