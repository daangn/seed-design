이 문서는 deprecated 현황의 원천 파일입니다. 변경 시 이 문서를 먼저 업데이트합니다.

- **Deprecated 현황**: 아직 사용할 수 있지만 앞으로 제거될 항목이에요.
- **제거 완료 히스토리**: 이미 제거된 항목이에요. 해당 버전 이상으로 올리려면 먼저 정리해야 해요.

| 항목                       | 종류      | Deprecated 버전 | 제거 예정 버전 | 대체안                     | 비고                                                                                                         |
| -------------------------- | --------- | --------------- | -------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| $color.bg.neutral-inverted | 색상 토큰 | 3.0.0           | 4.0.0          | $color.bg.neutral-solid    | 기존 사용처의 하위 호환성을 위해 3.x에서는 deprecated 상태로 유지                                           |
| $color.bg.neutral-inverted-pressed | 색상 토큰 | 3.0.0   | 4.0.0          | $color.bg.neutral-solid-pressed | 기존 사용처의 하위 호환성을 위해 3.x에서는 deprecated 상태로 유지                                      |
