---
title: Vite
---

vite 프로젝트에서 seed-design 컴포넌트를 사용하기 위한 설정들에 대해서 알아봐요.

<Steps>
<Step>

### 의존성 설치

필요한 의존성들을 설치해요.

```package-install
@seed-design/react @seed-design/css @seed-design/vite-plugin
```

</Step>

<Step>
### base.css import하기

```ts title="index.tsx"
import "@seed-design/react/base.css";
```
</Step>

<Step>

### vite config 설정하기

```ts title="vite.config.ts"
+import { seedPlugin } from '@seed-design/vite-plugin';

export default defineConfig({
  plugins: [
+    seedPlugin()
  ]
})
```
</Step>

<Step>

### seed-design.json 생성하기

<Tabs items={['CLI로 추가', '직접 추가']}>
<Tab value="CLI로 추가">
<Steps>
<Step>

### init 명령어 입력하기

</Step>
```sh
npx @seed-design/cli@latest init
```

<Step>

### seed-design 설정
```sh
◇  Would you like to use TypeScript (recommended)?
│  Yes
│
◇  Are you using React Server Components?
│  No
│
◇  Would you like to use CSS Loader? (If true, CSS import will be added in components)
│  Yes
│
◇  Enter the path to your seed-design directory
│  ./seed-design
│
◇  seed-design.json written to seed-design.json
```
</Step>
</Steps>
</Tab>

<Tab value="직접 추가">
아래 파일을 프로젝트 루트에 생성해주세요.

```json title="seed-design.json"
{
  "rsc": false,
  "tsx": true,
  "css": true,
  "path": "./seed-design"
}
```
</Tab>
</Tabs>

</Step>

<Step>

### 컴포넌트를 한번 사용해볼까요?

```sh
npx @seed-design/cli@latest add box-button
```

</Step>

<Step>


### tsconfig.json 설정하기

</Step>

```json title="tsconfig.json"
{
  "compilerOptions": {
    // your options
    "paths": { // [!code highlight]
      "seed-design/ui/*": [ // [!code highlight]
        "./seed-design/ui/*" // [!code highlight]
      ] // [!code highlight]
    } // [!code highlight]
  }
}
```


</Steps>
