## Usage

```tsx
import { HStack } from "@seed-design/lynx-react";
```

```tsx
<HStack gap="x3" align="center">
  <text>Left</text>
  <text>Right</text>
</HStack>
```

## Examples

### Basic

```tsx
import { HStack, Box } from "@seed-design/lynx-react";

export function BasicExample() {
  return (
    <HStack gap="x2">
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>A</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>B</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>C</text>
      </Box>
    </HStack>
  );
}
```

### Align Center

높이가 다른 자식 요소들을 수직 중앙 정렬합니다.

```tsx
import { HStack, Box } from "@seed-design/lynx-react";

export function AlignCenterExample() {
  return (
    <HStack gap="x2" align="center">
      <Box bg="bg.brandWeak" px="x3" py="x1" borderRadius="r1">
        <text>Small</text>
      </Box>
      <Box bg="bg.criticalWeak" px="x3" py="x4" borderRadius="r1">
        <text>Tall</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Medium</text>
      </Box>
    </HStack>
  );
}
```

### Lynx 플랫폼 참고 사항

<Callout>
Lynx의 `HStack`은 HTML `div` 대신 네이티브 `view` 요소를 렌더링합니다. React의 `HStack`과 동일한 스타일 속성을 지원하지만, 다음 사항에 유의하세요.

- `overflow: scroll`은 지원되지 않습니다. 스크롤이 필요하면 `scroll-view`를 사용하세요.
- `position`은 `relative`, `absolute`, `fixed`만 지원됩니다.
</Callout>
