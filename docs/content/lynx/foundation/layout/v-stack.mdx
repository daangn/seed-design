## Usage

```tsx
import { VStack } from "@seed-design/lynx-react";
```

```tsx
<VStack gap="x3">
  <text>Top</text>
  <text>Bottom</text>
</VStack>
```

## Examples

### Basic

```tsx
import { VStack, Box } from "@seed-design/lynx-react";

export function BasicExample() {
  return (
    <VStack gap="x2">
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Item 1</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Item 2</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Item 3</text>
      </Box>
    </VStack>
  );
}
```

### Align Center

너비가 다른 자식 요소들을 수평 중앙 정렬합니다.

```tsx
import { VStack, Box } from "@seed-design/lynx-react";

export function AlignCenterExample() {
  return (
    <VStack
      gap="x2"
      align="center"
      bg="bg.neutralWeak"
      p="x3"
      borderRadius="r2"
    >
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Short</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Medium Text</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>A Longer Item</text>
      </Box>
    </VStack>
  );
}
```

### Nested Stacks

`VStack`과 `HStack`을 조합하여 복잡한 레이아웃을 구성할 수 있습니다.

```tsx
import { VStack, HStack, Box } from "@seed-design/lynx-react";

export function NestedStacksExample() {
  return (
    <VStack gap="x3" bg="bg.neutralWeak" p="x3" borderRadius="r2">
      <HStack gap="x2">
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>Row 1 - A</text>
        </Box>
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>Row 1 - B</text>
        </Box>
      </HStack>
      <HStack gap="x2">
        <Box bg="bg.criticalWeak" px="x3" py="x2" borderRadius="r1">
          <text>Row 2 - A</text>
        </Box>
        <Box bg="bg.criticalWeak" px="x3" py="x2" borderRadius="r1">
          <text>Row 2 - B</text>
        </Box>
        <Box bg="bg.criticalWeak" px="x3" py="x2" borderRadius="r1">
          <text>Row 2 - C</text>
        </Box>
      </HStack>
    </VStack>
  );
}
```

### Lynx 플랫폼 참고 사항

<Callout>
Lynx의 `VStack`은 HTML `div` 대신 네이티브 `view` 요소를 렌더링합니다. React의 `VStack`과 동일한 스타일 속성을 지원하지만, 다음 사항에 유의하세요.

- `overflow: scroll`은 지원되지 않습니다. 스크롤이 필요하면 `scroll-view`를 사용하세요.
- `position`은 `relative`, `absolute`, `fixed`만 지원됩니다.
  </Callout>
