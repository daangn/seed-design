## Usage

```tsx
import { Flex } from "@seed-design/lynx-react";
```

```tsx
<Flex direction="row" gap="x3" align="center">
  <text>Item 1</text>
  <text>Item 2</text>
</Flex>
```

## Examples

### Direction

`direction` 속성으로 주축 방향을 설정합니다.

```tsx
import { Flex, Box } from "@seed-design/lynx-react";

export function DirectionExample() {
  return (
    <view style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Flex direction="row" gap="x2">
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>A</text>
        </Box>
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>B</text>
        </Box>
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>C</text>
        </Box>
      </Flex>

      <Flex direction="column" gap="x2">
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>A</text>
        </Box>
        <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
          <text>B</text>
        </Box>
      </Flex>
    </view>
  );
}
```

### Align & Justify

`align`과 `justify` 속성으로 정렬을 제어합니다.

```tsx
import { Flex, Box } from "@seed-design/lynx-react";

export function AlignJustifyExample() {
  return (
    <Flex
      direction="row"
      gap="x2"
      justify="space-between"
      align="center"
      bg="bg.neutralWeak"
      p="x3"
      borderRadius="r2"
    >
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Start</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Center</text>
      </Box>
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>End</text>
      </Box>
    </Flex>
  );
}
```

### Wrap

`wrap` 속성으로 줄 바꿈을 설정합니다.

```tsx
  return (
    <Flex direction="row" gap="x2" wrap="wrap" bg="bg.neutralWeak" p="x3" borderRadius="r2">
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1">
        <text>Item 1</text>
      </Box>

```

### Grow

`flexGrow`를 사용하여 자식 요소의 크기 비율을 지정할 수 있습니다.

```tsx
import { Flex, Box } from "@seed-design/lynx-react";

export function GrowExample() {
  return (
    <Flex direction="row" gap="x2">
      <Box bg="bg.brandWeak" px="x3" py="x2" borderRadius="r1" flexGrow="1">
        <text>grow=1</text>
      </Box>
      <Box bg="bg.criticalWeak" px="x3" py="x2" borderRadius="r1" flexGrow="2">
        <text>grow=2</text>
      </Box>
    </Flex>
  );
}
```

### Lynx 플랫폼 참고 사항

<Callout>
Lynx의 `Flex`는 HTML `div` 대신 네이티브 `view` 요소를 렌더링합니다. React의 `Flex`와 동일한 스타일 속성을 지원하지만, 다음 사항에 유의하세요.

- `overflow: scroll`은 지원되지 않습니다. 스크롤이 필요하면 `scroll-view`를 사용하세요.
- `position`은 `relative`, `absolute`, `fixed`만 지원됩니다.
</Callout>
