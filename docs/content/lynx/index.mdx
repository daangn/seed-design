## Lynx + SEED Design

[Lynx](https://lynxjs.org/)는 크로스 플랫폼 UI 프레임워크로, React 문법으로 네이티브 앱을 만들 수 있습니다.
SEED Design은 Lynx 환경에서도 디자인 시스템 컴포넌트를 제공합니다.
