## Installation

```package-install
bun add @seed-design/lynx-react-toggle
```

## Import

```ts
import { useToggle } from "@seed-design/lynx-react-toggle";
```

`useToggle`은 [useControllableState](/lynx/hooks/use-controllable-state)와 [usePressTap](/lynx/hooks/use-press-tap)을 조합한 headless 훅입니다. 이 두 훅은 패키지의 의존성으로 설치됩니다. `useToggle`을 `@seed-design/lynx-react`에서 재export하지는 않습니다.

## Headless 컴포넌트

`Toggle.Root`는 스타일 없는 고정 `<view>`를 렌더링하고, 상태와 입력 이벤트를 연결하며 native 접근성 상태를 제공합니다. `as`/`asChild`는 제공하지 않습니다.

```tsx
import { Toggle, useToggleContext } from "@seed-design/lynx-react-toggle";

function Label() {
  const { pressed } = useToggleContext();
  return <text>{pressed ? "선택됨" : "선택 안 됨"}</text>;
}

<Toggle.Root defaultPressed onPressedChange={console.log}>
  <Label />
</Toggle.Root>
```

`pressed`, `defaultPressed`, `onPressedChange`, `disabled`는 훅과 동일합니다. 사용자 `bindtap`과 내부 토글을 함께 실행하며, disabled에서는 background/main-thread tap을 모두 차단합니다. 터치 핸들러와 ref는 native 요소로 전달합니다. 하위 컴포넌트는 `useToggleContext()`로 `pressed`·`active`·`disabled`를 읽어 Recipe를 선택할 수 있습니다. Scale Feedback과 아이콘은 styled 컴포넌트가 담당합니다.

## Usage

### Uncontrolled

```tsx
import { useToggle } from "@seed-design/lynx-react-toggle";

function Favorite() {
  const { pressed, active, rootProps } = useToggle({ defaultPressed: false });

  return (
    <view {...rootProps}>
      <text>{pressed ? "즐겨찾기 해제" : "즐겨찾기 추가"}</text>
      <text>{active ? "누르는 중" : ""}</text>
    </view>
  );
}
```

`pressed`는 tap할 때마다 반전되어 유지되는 **선택 상태**, `active`는 손가락으로 누르는 동안만 유지되는 **눌림 상태**입니다. `usePressTap`의 `pressed`가 여기서는 `active`에 해당합니다.

### Controlled

```tsx
import { useState } from "@lynx-js/react";
import { useToggle } from "@seed-design/lynx-react-toggle";

function ControlledFavorite() {
  const [selected, setSelected] = useState(false);
  const { rootProps } = useToggle({
    pressed: selected,
    onPressedChange: setSelected,
  });

  return (
    <view {...rootProps}>
      <text>{selected ? "선택됨" : "선택 안 됨"}</text>
    </view>
  );
}
```

`pressed`를 전달하면 부모가 값을 갱신해야 화면의 선택 상태도 바뀝니다. 전달하지 않으면 훅이 상태를 관리하며, `defaultPressed`는 최초 상태만 정합니다.

### Disabled

```tsx
import { useToggle } from "@seed-design/lynx-react-toggle";

function DisabledFavorite({ disabled }: { disabled: boolean }) {
  const { pressed, active, rootProps } = useToggle({ disabled });

  return (
    <view {...rootProps}>
      <text>{disabled ? "사용할 수 없음" : pressed ? "선택됨" : "선택 안 됨"}</text>
      <text>{active ? "누르는 중" : ""}</text>
    </view>
  );
}
```

비활성화하면 `rootProps`로 연결된 tap·touch 입력이 차단됩니다. 누르는 도중 비활성화되어도 `active`는 해제되며, 기존 `pressed` 값은 유지됩니다.

## API

### Options

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pressed` | `boolean` | - | Controlled 선택 상태입니다. `undefined`이면 uncontrolled입니다. |
| `defaultPressed` | `boolean` | `false` | Uncontrolled 초기 선택 상태입니다. |
| `onPressedChange` | `(pressed: boolean) => void` | - | 선택 상태 변경 요청을 전달합니다. |
| `disabled` | `boolean` | `false` | `rootProps`의 사용자 입력을 차단합니다. |

### Return

| Property | Type | Description |
| --- | --- | --- |
| `pressed` | `boolean` | 지속되는 선택 상태입니다. |
| `active` | `boolean` | 손가락으로 누르는 동안의 일시적인 상태입니다. |
| `disabled` | `boolean` | 현재 비활성화 여부입니다. |
| `toggle` | `() => void` | 선택 상태를 반전하는 변경을 요청합니다. |
| `rootProps` | 이벤트 객체 | native `<view>`에 펼칠 `bindtap`, `bindtouchstart`, `bindtouchend`, `bindtouchcancel`입니다. |

`UseToggleStateProps`, `UseToggleProps`, `UseToggleReturn` 타입도 같은 패키지에서 export합니다.

**`toggle()` 직접 호출은 `disabled`를 검사하지 않습니다.** 비활성화는 사용자 입력 경로인 `rootProps`가 담당합니다. 다른 버튼이나 코드에서 호출할 때도 비활성화를 적용하려면 호출 전에 `disabled`를 확인하세요.

Uncontrolled 모드에서는 재렌더 전 여러 번 `toggle()`해도 각 호출이 순서대로 반영됩니다. Controlled 모드는 부모가 마지막으로 전달한 `pressed`를 기준으로 변경을 요청합니다.

`rootProps` 뒤에 같은 이름의 handler를 쓰면 훅의 handler가 덮어써집니다. 선택 결과에 따른 부가 동작은 `onPressedChange`로 전달하거나, 사용자 handler 안에서 기존 handler를 함께 호출하세요.

### Context로 하위 컴포넌트에 전달

`ToggleContext.Provider`에 훅의 반환값을 전달하면 `useToggleContext()`로 읽을 수 있습니다. Provider를 자동으로 렌더링하는 Root 컴포넌트는 제공하지 않습니다.

```tsx
import { ToggleContext, useToggle, useToggleContext } from "@seed-design/lynx-react-toggle";

function ToggleLabel() {
  const { pressed } = useToggleContext("ToggleLabel");
  return <text>{pressed ? "선택됨" : "선택 안 됨"}</text>;
}

function CompoundToggle() {
  const toggle = useToggle({});

  return (
    <ToggleContext.Provider value={toggle}>
      <view {...toggle.rootProps}>
        <ToggleLabel />
      </view>
    </ToggleContext.Provider>
  );
}
```

`useToggleContext(consumer?: string)`는 `UseToggleContext`를 반환합니다. Provider 밖에서 호출하면 오류가 발생하며, `consumer`는 오류에 표시할 컴포넌트 이름입니다.

## 스타일·접근성과 웹의 차이

이 훅은 요소·스타일·접근성 속성을 생성하지 않습니다. `pressed`·`active`·`disabled`에 맞는 시각 표현과 접근성 이름·선택 상태는 소비하는 컴포넌트에서 구성하세요. 완성된 SEED UI가 필요하면 [Chip.Toggle](/lynx/components/chip)처럼 해당 용도의 컴포넌트를 먼저 확인하세요.

웹 `@seed-design/react-toggle`의 `onClick`·`aria-pressed`·`data-pressed`와 달리 Lynx에서는 `rootProps`의 native 이벤트와 반환된 상태를 사용합니다. 이 훅은 키보드·hover·focus 및 Main Thread tap 콜백을 추가로 제공하지 않습니다.
