### Lynx Usage

#### Autoresizing

`TextFieldTextarea`는 기본적으로 내용에 맞춰 높이가 늘어납니다. 높이가 바뀌면 `KeyboardAvoidingScrollView`가 활성 입력의 위치를 다시 계산합니다.

Android에서는 SEED typography의 줄 높이를 맞추기 위해 `line-spacing="3.2px"`를 기본 적용합니다. `fontSize`나 `lineHeight`를 바꾼다면 이에 맞는 `line-spacing`도 지정하세요. 기본 보정은 `line-spacing={0}`으로 해제할 수 있습니다.

#### Keyboard Avoidance

`KeyboardAvoidingScrollView.Content` 안에 배치하면 `TextFieldTextarea`가 focus될 때 자동으로 등록됩니다. autoresize로 레이아웃이 바뀌면 활성 입력 위치를 다시 계산합니다.

```tsx
import { KeyboardAvoidingScrollView } from "@seed-design/lynx-react";
import { TextField, TextFieldTextarea } from "@/components/ui/text-field";

export function KeyboardAwareFields() {
  return (
    <KeyboardAvoidingScrollView.Root className="screen-body">
      <KeyboardAvoidingScrollView.Content>
        <TextField label="내용">
          <TextFieldTextarea accessibility-label="내용" />
        </TextField>
      </KeyboardAvoidingScrollView.Content>
    </KeyboardAvoidingScrollView.Root>
  );
}
```

## Web Version Differences

- 편집 가능한 상태에서는 HTML `<textarea>` 대신 Lynx native `<textarea>`를 렌더링합니다.
- `readOnly` 상태에서는 focus, selection, 잘라내기 메뉴가 없는 `<text>`를 렌더링합니다. 이때 ref는 `<text>`를 가리키므로 textarea 전용 UI method와 이벤트를 사용할 수 없습니다.
- `onChange` 대신 `TextField`의 `onValueChange`를 사용합니다. native `bindinput`은 `TextFieldTextarea`에 직접 전달할 수 있습니다.
- DOM id로 label을 연결하지 않으므로 입력에 `accessibility-label`을 직접 지정하세요.
- autoresize는 DOM `scrollHeight`가 아니라 native 측정값을 사용합니다.
- `show-soft-input-on-focus`의 기본값은 `true`입니다. 커스텀 키보드를 사용한다면 `false`로 지정하세요.
- Android의 fullscreen extract input은 기본적으로 비활성화됩니다. 필요한 경우 `android-fullscreen-mode={true}`를 지정하세요.
- `android-set-soft-input-mode`는 기본값이 `"unspecified"`이며 host window 전체에 영향을 줍니다. 같은 window의 입력에는 같은 값을 사용하고, `KeyboardAvoidingScrollView`가 키보드 회피를 맡는 화면에서는 `"nothing"`을 사용하세요.

## Unsupported Lynx Features

- HTML form submit, browser validation, React Hook Form, `aria-describedby` id 연결은 지원하지 않습니다.
- 큰 textarea에서 현재 caret 위치만 기준으로 키보드를 회피하는 기능은 지원하지 않습니다. 현재는 Field·TextField·native 입력 영역 중 안전 영역에 맞는 가장 큰 영역을 선택합니다.
