## Usage

```tsx
import { ContentPlaceholder } from "@/components/ui/content-placeholder";
import { car } from "@seed-design/lynx-react/content-placeholder-presets/car";

<ContentPlaceholder preset={car} width="160px" height="160px" />
```

## Examples

### Type Preset

React와 같은 12개 프리셋을 제공합니다. 사용할 프리셋만 개별 경로에서 import해 `preset`으로 전달합니다. 각 프리셋에는 React SVG와 SEED 토큰에서 생성한 light/dark WebP 한 쌍이 들어 있으며, SEED 테마 클래스에 따라 표시합니다. `tint-color`로 표시 후 재착색하지 않습니다.

기본 모양은 `@seed-design/lynx-react/content-placeholder-presets/default`의 `defaultPreset`, 구매·판매 모양은 `.../buy-sell`의 `buySell`을 사용합니다. 나머지는 `car`, `commerce`, `coupon`, `food`, `group`, `image`, `jobs`, `business`, `post`, `realty` 경로와 같은 이름으로 import합니다.

사용하지 않은 프리셋은 번들에 포함되지 않습니다. `preset`을 생략하면 자동 기본 이미지를 넣지 않으며, `children`으로 전달한 커스텀 에셋만 표시합니다.

### Customizing Asset

React처럼 하나의 아이콘이나 이미지를 `children`으로 전달하면 프리셋을 대체합니다. 컴포넌트는 크기와 정렬만 처리하며 색을 변경하지 않습니다. 모노크롬 아이콘에는 첫 렌더부터 최종 색이 적용되도록 `tint-color`를 지정하세요. CSS `color`를 자동 변환하거나 표시 후 색을 동기화하지 않습니다.

커스텀 아이콘 컴포넌트는 전달받은 `style`과 `tint-color`를 실제 `<image>`에 연결해야 합니다. 직접 넣는 `<image>`에는 `mode="aspectFit"`과 `style={{ width: "100%", height: "100%" }}`를 지정하세요. 프리셋 색을 바꾸려면 원하는 색의 커스텀 에셋을 사용합니다.

```tsx
<ContentPlaceholder width="160px" height="160px">
  <image
    src={customAssetSrc}
    mode="aspectFit"
    style={{ width: "100%", height: "100%" }}
  />
</ContentPlaceholder>
```

`tint-color`는 ContentPlaceholder의 prop이 아니라 자식 아이콘에 전달하는 native 속성입니다. 아이콘 예제와 이미지 예제 모두 `children`으로 구성합니다.

## 웹 버전과의 차이

- HTML/SVG 대신 native `view`와 `image`를 사용합니다. `Root`·`Asset` 구성과 프리셋 모양은 React와 같습니다. React의 문자열 `type` 대신 개별 import한 `preset`을 전달해 사용하지 않는 이미지가 번들에 포함되지 않게 합니다.
- 프리셋은 테마별로 미리 착색되어 표시 후 tint 변경이 없습니다. 앱에 `useSeedClassName`으로 SEED 테마 클래스를 적용하세요.
- 커스텀 SVG의 `currentColor` 상속 대신 아이콘의 `tint-color`를 직접 지정합니다. `preserveOriginalColor`나 자동 색상 동기화는 제공하지 않습니다.
