## Usage

```tsx
import { ContentPlaceholder } from "@/components/ui/content-placeholder";

<ContentPlaceholder type="car" width="160px" height="160px" />
```

### Customizing Asset

하나의 아이콘이나 이미지를 `children`으로 전달하면 프리셋을 대체합니다. 컴포넌트는 크기와 정렬만 처리하며 색을 변경하지 않습니다. 모노크롬 아이콘에는 첫 렌더부터 최종 색이 적용되도록 `tint-color`를 지정하세요. CSS `color`를 자동 변환하거나 표시 후 색을 동기화하지 않습니다.

## 웹 버전과의 차이

- HTML/SVG 대신 native `view`와 `image`를 사용합니다. `Root`·`Asset` 구성과 `type` 프리셋은 React와 같습니다.
- 프리셋은 테마별로 미리 착색되어 표시 후 tint 변경이 없습니다. 앱에 `useSeedClassName`으로 SEED 테마 클래스를 적용하세요.
- 커스텀 SVG의 `currentColor` 상속 대신 아이콘의 `tint-color`를 직접 지정합니다. `preserveOriginalColor`나 자동 색상 동기화는 제공하지 않습니다.
