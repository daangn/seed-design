## Usage

### Content

탭 선택으로만 콘텐츠를 전환할 때는 `ChipTabsContent`를 `ChipTabsRoot` 안에 배치합니다. Trigger와 Content의 `value`를 맞추면 선택된 패널만 표시됩니다. 이 구성은 콘텐츠 높이에 맞춰 배치되며 좌우 스와이프는 제공하지 않습니다.

```tsx
import {
  ChipTabsContent,
  ChipTabsList,
  ChipTabsRoot,
  ChipTabsTrigger,
} from "@/components/ui/chip-tabs";

export function App() {
  return (
    <ChipTabsRoot defaultValue="1">
      <ChipTabsList>
        <ChipTabsTrigger value="1">라벨1</ChipTabsTrigger>
        <ChipTabsTrigger value="2">라벨2</ChipTabsTrigger>
        <ChipTabsTrigger value="3">라벨3</ChipTabsTrigger>
      </ChipTabsList>
      <ChipTabsContent value="1">
        <text>첫 번째 콘텐츠</text>
      </ChipTabsContent>
      <ChipTabsContent value="2">
        <text>두 번째 콘텐츠</text>
      </ChipTabsContent>
      <ChipTabsContent value="3">
        <text>세 번째 콘텐츠</text>
      </ChipTabsContent>
    </ChipTabsRoot>
  );
}
```

`ChipTabsRoot`는 `value`와 `onValueChange`로 제어하거나 `defaultValue`로 초기 선택 값을 지정합니다. `notification`을 설정한 Trigger에는 알림 배지가 표시됩니다.

### Swipeable

콘텐츠를 좌우로 밀어 탭을 바꾸려면 `ChipTabsContent`를 `ChipTabsCarousel` 안에 배치하고 `swipeable`을 설정합니다. Carousel에 앱 레이아웃에 맞는 높이를 지정하세요. iOS의 뒤로 가기 제스처 범위는 `iosBackGestureEdgeWidth`로 조절할 수 있습니다.

## Scroll Alignment

`ChipTabsList`의 `scrollAlign`은 선택한 chip을 가로 목록에 맞추는 방식입니다. `"nearest"`, `"start"`, `"center"`, `"end"`를 지원하며 기본값은 `"nearest"`입니다.

`"nearest"`는 선택한 chip이 완전히 보이면 이동하지 않고, 일부가 가려졌을 때만 필요한 만큼 스크롤합니다.

## Examples

### Extending to Safe Area

`ChipTabsRoot`에 `extendSafeAreaX`를 지정하면 스크롤 영역과 Carousel 패널이 좌우 safe area까지 확장됩니다. 첫 chip과 마지막 chip에는 기존 화면 여백과 inset이 함께 적용되고, 패널 내용은 안전 영역 안에 남습니다. 기본값은 `false`입니다.

기본 `scrollAlign="nearest"`는 안전 영역 안에 보이는 chip을 움직이지 않고, inset에 가린 chip만 안쪽으로 스크롤합니다.

`Box pl="safeArea" pr="safeArea"`처럼 좌우 inset을 이미 확보한 컨테이너 바로 안에서 사용하세요. inset을 확보하지 않은 곳에 적용하면 화면 밖으로 넘칠 수 있습니다. Carousel 안의 `fixed` 요소처럼 부모의 padding을 따르지 않는 요소는 별도로 처리해야 합니다.

## Web Version Differences

- 탭 이벤트는 `onClick` 대신 `bindtap`으로 받습니다.
- Carousel은 네이티브 `<viewpager>`, 가로 탭 목록은 `<scroll-view>`를 사용합니다.
- Root 밖에서 선택 값에 따라 네이티브 콘텐츠를 조건부로 렌더링할 수 있습니다.

## Unsupported Lynx Features

- 키보드 포커스와 roving focus
- RTL 순서와 스와이프 방향 반전
- `lazyMount`, `unmountOnExit`
- Carousel의 `loop`, `autoHeight`, `dragThreshold`, `carouselPreventDrag`
- 콘텐츠 전환 애니메이션
