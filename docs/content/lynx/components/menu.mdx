## Usage

`MenuContent`는 긴 목록을 스크롤합니다. `container`를 지정하지 않으면 Lynx view 안에, 지정하면 native overlay에 렌더링됩니다.

```tsx
import { ActionButton } from "@seed-design/lynx-react";

import {
  MenuContent,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuRoot,
  MenuTrigger,
} from "@/components/ui/menu";

export function App() {
  return (
    <MenuRoot>
      <MenuTrigger>
        <ActionButton variant="neutralSolid">열기</ActionButton>
      </MenuTrigger>
      <MenuContent>
        <MenuGroup>
          <MenuGroupLabel>작업</MenuGroupLabel>
          <MenuItem label="항목 1" />
          <MenuItem label="항목 2" />
        </MenuGroup>
        <MenuGroup>
          <MenuItem label="항목 3" />
        </MenuGroup>
      </MenuContent>
    </MenuRoot>
  );
}
```

- `MenuAnchor`는 위치만 정하며 Menu를 열지 않습니다. `open`과 `onOpenChange`로 상태를 제어하세요.
- `MenuContent` 안에 별도의 positioner나 scroll area를 추가하지 마세요.
- `MenuItem`은 `description`, `prefixIcon`, `suffixIcon`을 지원합니다.

### Container

`container`를 지정하지 않으면 Menu 레이어는 Lynx view 안의 `position: fixed` view로 렌더링되고, z-index `99`로 같은 화면의 형제 요소 위에 그려집니다. `container="window"`처럼 native container 이름을 지정하면 native overlay에 렌더링되어 Lynx view 밖의 host 화면까지 덮습니다. `overlayLevel`은 `container`를 지정했을 때 overlay의 표시 순서를 정합니다.

두 방식 모두 레이어 바깥을 탭하면 아래 화면에 탭을 전달하지 않고 `"interactOutside"` reason으로 닫힙니다.

### `onOpenChange` details

`onOpenChange`의 두 번째 인자인 `details`에는 상태를 바꾼 이유와 native event가 들어옵니다.

- 열림: `"trigger"`
- 닫힘: `"trigger"`, `"interactOutside"`, `"itemClick"`
- `container`를 지정한 native overlay가 닫힘을 요청한 경우(Android 뒤로 가기): `"dismiss"`. `container`가 없으면 전달하지 않으며, Android 뒤로 가기는 Menu가 아니라 host 화면을 닫습니다.

## 웹 버전과의 차이

- Trigger는 자식을 native `view`로 감싸며 `asChild`를 제공하지 않습니다. raw `<text>`처럼 이름을 만들 수 없는 자식에는 `accessibility-label`을 지정하세요.
- 키보드 focus, typeahead, ESC 키 닫힘은 지원하지 않습니다.
- 바깥 탭은 `"interactOutside"`, native overlay의 닫기 요청은 `"dismiss"` reason으로 전달합니다.
- Menu가 열려 있는 동안 화면 전체 레이어가 Anchor 밖의 탭을 받습니다.
