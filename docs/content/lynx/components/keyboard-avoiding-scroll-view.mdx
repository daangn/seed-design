## Usage

AppBar 아래 화면 본문처럼 높이가 정해진 영역에 `KeyboardAvoidingScrollView.Root`를 두고, 입력 화면을 `KeyboardAvoidingScrollView.Content`로 감쌉니다. 키보드 위에 붙여야 하는 하단 버튼은 Content 아래의 `KeyboardAvoidingScrollView.Footer`에 둡니다.

```tsx
import { KeyboardAvoidingScrollView } from "@seed-design/lynx-react";

export function Screen() {
  return (
    <KeyboardAvoidingScrollView.Root className="screen-body">
      <KeyboardAvoidingScrollView.Content>{/* 입력 화면 */}</KeyboardAvoidingScrollView.Content>
      <KeyboardAvoidingScrollView.Footer>{/* 하단 버튼 */}</KeyboardAvoidingScrollView.Footer>
    </KeyboardAvoidingScrollView.Root>
  );
}
```

- Root에는 높이를 지정하고 자식으로 Content와 Footer만 두세요. Footer는 Content 바로 아래에 배치합니다.
- Content는 focus된 입력이 키보드나 Footer에 가리지 않도록 스크롤과 하단 여백을 조정합니다. `keyboardGap`과 `scrollBehavior`로 간격과 이동 방식을 정할 수 있습니다.
- Footer는 키보드 위로 이동합니다. 하단 safe area 여백은 Root 바깥의 화면 컨테이너에 두세요.
- Text Field Registry의 Input과 Textarea는 focus, blur, 높이 변경을 자동으로 전달합니다.
- Android에서 이 컴포넌트가 키보드 회피를 맡으면 입력 요소에 `android-set-soft-input-mode="nothing"`을 지정하고 `avoid-keyboard`는 사용하지 마세요.

## 웹 버전과의 차이

- Lynx keyboard event와 native node 위치를 기준으로 세로 스크롤을 조정합니다.
- 브라우저의 form 제출과 자동 focus 이동은 제공하지 않습니다.

## Lynx 미지원 기능

- 가로 또는 중첩 scroll view
- 키보드 toolbar 높이와 큰 textarea의 caret 단위 회피
- 키보드 애니메이션과 정확히 같은 Footer 이동. 닫는 동안 잠시 간격이 생길 수 있습니다.
