## Usage

```tsx
import { Avatar } from "@/components/ui/avatar";
import { IdentityPlaceholder } from "@/components/ui/identity-placeholder";

<Avatar src="https://avatars.githubusercontent.com/u/54893898?v=4" alt="사용자 프로필" fallback={<IdentityPlaceholder />} />
```

이미지가 로딩 중이거나 실패한 동안 `fallback`을 표시합니다. `src`가 바뀌면 새 요청을 시작하며, 이전 요청의 이벤트는 상태에 반영하지 않습니다.

`onLoadingStatusChange`로 로딩 상태를 관찰할 수 있습니다. native 이미지 이벤트와 접근성 속성은 `imageProps`에 전달합니다.

```tsx
<Avatar
  src="https://avatars.githubusercontent.com/u/54893898?v=4"
  alt="사용자 프로필"
  imageProps={{
    binderror: () => { "background only"; console.log("프로필 이미지 로딩 실패"); },
  }}
/>
```

### Badge & Badge Mask

`badgeMask`는 이미지와 fallback에서 배지 주변을 `"circle"`, `"flower"`, `"shield"` 모양으로 잘라냅니다. 기본값인 `"none"`은 아바타를 자르지 않습니다. `size="20"`에서는 배지와 마스크를 모두 표시하지 않습니다.

`AvatarBadge`에는 선택한 마스크 모양에 맞는 에셋을 넣습니다. 다른 모양의 콘텐츠에는 `badgeMask="none"`을 사용하고 필요한 테두리를 직접 지정하세요.

```tsx
import { Avatar, AvatarBadge } from "@/components/ui/avatar";

<Avatar size="64" src={profile.imageUrl} alt={profile.name} badgeMask="shield">
  <AvatarBadge>
    <image
      src={shieldBadgeSrc}
      accessibility-label="인증된 프로필"
      mode="aspectFit"
      style={{ width: "100%", height: "100%" }}
    />
  </AvatarBadge>
</Avatar>
```

직접 만든 배지는 `badgeMask="none"`과 `children`으로 구성합니다.

```tsx
<Avatar size="64" src={profile.imageUrl} alt={profile.name} badgeMask="none">
  <AvatarBadge>
    <view style={{ width: "100%", height: "100%", display: "flex", alignItems: "center", justifyContent: "center", backgroundColor: "#20242B", borderRadius: "6px" }}>
      <text style={{ color: "#FFFFFF", fontSize: "12px" }}>+3</text>
    </view>
  </AvatarBadge>
</Avatar>
```

### Stack

`AvatarStack`은 자식 Avatar에 `size`를 전달합니다. 개별 Avatar에 지정한 `size`가 우선합니다.

```tsx
import { Avatar, AvatarStack } from "@/components/ui/avatar";

<AvatarStack size="48">
  <Avatar src={first.imageUrl} alt={first.name} />
  <Avatar src={second.imageUrl} alt={second.name} size="36" />
  <Avatar fallback="김" />
</AvatarStack>
```

### Fallback Image

`fallback`에는 이미지가 로드되지 않았을 때 표시할 요소를 지정합니다. 문자열과 숫자도 사용할 수 있으며, 주로 [IdentityPlaceholder](/lynx/components/identity-placeholder)를 사용합니다.

로딩에 성공하면 fallback을 언마운트합니다. 다시 표시할 때 유지해야 하는 상태는 부모에서 관리하세요.

## 웹 버전과의 차이

- DOM `<img>` 대신 native `<image mode="aspectFill">`을 사용합니다. `alt`는 `accessibility-label`로 전달합니다.
- `onLoad`와 `onError` 대신 `imageProps.bindload`와 `imageProps.binderror`를 사용합니다.
- Stack에서 영역 밖 콘텐츠를 함께 사용하면 React와 겹침 결과가 다를 수 있습니다.
- `asChild`, `srcSet`, DOM 이벤트와 속성은 지원하지 않습니다.
