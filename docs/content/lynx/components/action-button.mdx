## Installation

```package-install
npm install @seed-design/lynx-react
```

<Callout>
`@seed-design/css` 패키지가 peer dependency로 필요합니다.
</Callout>

## Usage

```tsx
import { ActionButton } from "@seed-design/lynx-react";

export function App() {
  return (
    <ActionButton variant="brandSolid" size="medium" bindtap={() => console.log("tapped")}>
      버튼
    </ActionButton>
  );
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"brandSolid" \| "neutralSolid" \| "neutralWeak" \| "criticalSolid" \| "brandOutline" \| "neutralOutline" \| "ghost"` | `"brandSolid"` | 버튼의 시각적 스타일을 결정합니다. |
| `size` | `"xsmall" \| "small" \| "medium" \| "large"` | `"medium"` | 버튼의 크기를 결정합니다. |
| `layout` | `"withText" \| "iconOnly"` | `"withText"` | 텍스트 포함 여부에 따른 레이아웃을 결정합니다. |
| `disabled` | `boolean` | `false` | 버튼을 비활성화합니다. |
| `loading` | `boolean` | `false` | 로딩 상태를 표시합니다. |
| `className` | `string` | - | 추가 CSS 클래스를 지정합니다. |
| `flexGrow` | `number` | - | CSS `flex-grow` 값을 지정합니다. |
| `bindtap` | `() => void` | - | 탭 이벤트 핸들러입니다. |
| `main-thread:bindtap` | `() => void` | - | 메인 스레드에서 실행되는 탭 이벤트 핸들러입니다. |
