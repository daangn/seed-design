## 웹 버전과의 차이

<Callout type="warning">
Lynx `ActionButton`은 React `ActionButton`과 다음 차이가 있습니다.

- `onClick` 대신 `bindtap`을 사용합니다.
- HTML `<button>` 대신 네이티브 `<view>`와 `<text>`를 렌더링합니다.
- `aria-label` 대신 `accessibility-label`을 사용합니다. 문자열 children에서 이름을 만들 수 없는 버튼과 `iconOnly` 버튼에는 이름을 직접 지정해야 합니다.
- 아이콘 색상은 Lynx `<image>`의 `tint-color`로 적용합니다.
- loading 중에는 원래 버튼 너비를 유지하면서 탭을 막습니다.
- bleed 값은 px 길이, `0`, `"safeArea"`만 받습니다. SEED 토큰과 `"asPadding"`은 inline style의 `calc()` 안에서 CSS 변수를 적용할 수 없어 지원하지 않습니다.
</Callout>

## Lynx 미지원 기능

현재 다음 스타일 사용자 지정을 지원하지 않습니다.

| 기능 | 웹 대응 | 설명 |
|------|---------|------|
| `color` | StyleProps | CSS variable 동적 주입 제한 |
| `fontWeight` | StyleProps | CSS variable 동적 주입 제한 |
