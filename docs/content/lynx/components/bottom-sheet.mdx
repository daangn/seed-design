## Usage

```tsx
import {
  BottomSheetBody,
  BottomSheetContent,
  BottomSheetFooter,
  BottomSheetRoot,
  BottomSheetTrigger,
} from "@/components/ui/bottom-sheet";

export function App() {
  return (
    <BottomSheetRoot snapPoints={["fit", "80%"]}>
      <BottomSheetTrigger>
        <text>시트 열기</text>
      </BottomSheetTrigger>
      <BottomSheetContent title="제목" description="부가 설명" showHandle>
        <BottomSheetBody>
          <text>본문 콘텐츠</text>
        </BottomSheetBody>
        <BottomSheetFooter>
          <text>하단 액션 영역</text>
        </BottomSheetFooter>
      </BottomSheetContent>
    </BottomSheetRoot>
  );
}
```

`BottomSheetTrigger`는 Content 밖에 두세요.

`container`를 지정하지 않으면 Bottom Sheet는 Lynx view 안에 렌더링됩니다. `container="window"`처럼 native container 이름을 지정하면 host 화면까지 덮는 native overlay에 렌더링됩니다. `overlayLevel`은 overlay의 표시 순서를 정합니다. 이 기능을 사용할 때는 앱의 Lynx Engine이 `<overlay>`를 지원해야 합니다.

### Imperative 제어

`BottomSheetRoot`에 `ref`를 전달하면 `open`, `close`, `snapTo`, `expand`, `collapse` 메서드를 호출할 수 있습니다. 이 메서드로 바꾼 열림 상태는 `onOpenChange`로 알리지 않습니다. `open`을 제어하는 경우에는 메서드 대신 `open` 값을 바꾸세요.

```tsx
import { useRef } from "@lynx-js/react";
import { BottomSheetRoot, type BottomSheetRootRef } from "@/components/ui/bottom-sheet";

export function App() {
  const ref = useRef<BottomSheetRootRef>(null);

  return (
    <BottomSheetRoot ref={ref} snapPoints={["fit", "80%"]}>
      {/* ... */}
    </BottomSheetRoot>
  );
}
```

### `onOpenChange` Details

`onOpenChange`의 두 번째 인자는 `{ reason }`입니다. Trigger로 열면 `"trigger"`, 배경을 탭해 닫으면 `"interactOutside"`, 시트를 끌어 닫으면 `"drag"`입니다. 닫히는 중에 시트를 다시 끌어 올리면 `open`이 `true`인 `"drag"`가 전달됩니다. Root ref의 메서드나 `open` prop으로 바꾼 상태에는 호출되지 않습니다. React 버전의 `escapeKeyDown`처럼 Lynx에 해당 입력이 없는 reason은 제공하지 않습니다.

### Snap Points

`snapPoints`에는 픽셀 숫자, 화면 높이 기준 백분율, 콘텐츠 크기에 맞추는 `"fit"`을 사용할 수 있습니다. 배열 순서가 snap index가 되며, `initialSnap`으로 처음 열릴 높이를 정합니다.

`onSnapChange`에서는 현재 index와 픽셀로 계산된 높이를 받을 수 있습니다. ref의 `snapTo` 메서드를 사용하면 원하는 높이로 이동할 수 있습니다.

### Fade From Index

Lynx는 `fadeFromIndex`를 지원하지 않습니다. snap index에 따른 Backdrop 투명도 변경도 지원하지 않습니다.

### Show Close Button

Lynx의 `BottomSheetContent`는 `showCloseButton`과 CloseButton을 지원하지 않습니다. 닫기 버튼이 필요하면 controlled 상태를 사용하고 `BottomSheetFooter`의 버튼에서 `open`을 `false`로 바꾸세요.

### Dismissible

Lynx에는 배경 탭, 드래그, ESC 닫기를 한 번에 제어하는 `dismissible` prop이 없습니다. `enableDragToClose={false}`로 드래그 닫기만 막을 수 있으며, Registry에서는 배경 탭 닫기를 끌 수 없습니다. ESC 키 닫기도 지원하지 않습니다. 닫기 동작을 막았다면 Footer 등에 닫기 버튼을 제공하세요.

### With Scroll Fog

`BottomSheetBody`는 스크롤 방식을 정하지 않는 native `<view>`입니다. 스크롤 힌트가 필요하면 Body 안에 [Scroll Fog](/lynx/components/scroll-fog)와 세로 `<scroll-view>`를 직접 배치하세요. fog 방향과 크기는 `ScrollFog`의 `placement`·`size`로, 스크롤바와 스크롤 동작은 `<scroll-view>` prop으로 제어합니다.

ScrollFog는 스크롤 위치와 관계없이 항상 효과를 표시하므로, `<scroll-view>`에 권장 padding인 상단 `20px`, 하단 `80px`을 지정해야 합니다.

## 웹 버전과의 차이

- `onOpenChange`의 `reason`은 `trigger`, `interactOutside`, `drag`만 제공합니다.
- Trigger는 자식을 native `view`로 감싸며 `asChild`를 제공하지 않습니다.
- Root ref의 `open`, `close`, `snapTo`, `expand`, `collapse`로 시트를 제어할 수 있습니다. ref로 바꾼 상태는 `onOpenChange`로 알리지 않습니다.
- `container`와 `overlayLevel`로 native overlay의 위치와 표시 순서를 지정합니다.
- Registry에서는 `lazyMount`와 `unmountOnExit`을 지원하지 않습니다.
