## Usage

`MenuSheetTrigger`는 자식을 native `<view>`로 감싸며 `asChild`를 제공하지 않습니다.

```tsx
import { useState } from "@lynx-js/react";
import { ActionButton } from "@seed-design/lynx-react";
import {
  MenuSheetContent,
  MenuSheetGroup,
  MenuSheetItem,
  MenuSheetRoot,
  MenuSheetTrigger,
} from "@/components/ui/menu-sheet";

export function App() {
  const [open, setOpen] = useState(false);

  function handleEdit() {
    "background only";
    setOpen(false);
  }

  return (
    <MenuSheetRoot open={open} onOpenChange={setOpen}>
      <MenuSheetTrigger accessibility-label="게시글 관리 메뉴 열기">
        <ActionButton variant="neutralSolid">메뉴 열기</ActionButton>
      </MenuSheetTrigger>
      <MenuSheetContent title="게시글 관리">
        <MenuSheetGroup>
          <MenuSheetItem label="수정하기" bindtap={handleEdit} />
          <MenuSheetItem label="삭제하기" tone="critical" />
        </MenuSheetGroup>
      </MenuSheetContent>
    </MenuSheetRoot>
  );
}
```

`Item`의 `bindtap`은 작업만 수행하며 시트를 자동으로 닫지 않습니다. 작업 후 닫아야 하면 위 예제처럼 `open`을 제어하세요. `open`을 제어하지 않는다면 `MenuSheetRoot` ref의 `close()`를 호출합니다. ref 메서드로 바꾼 열림 상태는 `onOpenChange`로 알리지 않으므로, `open`을 제어할 때는 ref 대신 `open` 값을 바꿉니다. `title`을 제공하지 않는 `Content`에는 native 보조 기술이 읽을 이름을 알 수 있도록 `accessibility-label`을 제공해야 합니다.

`container`를 지정하지 않으면 Menu Sheet는 Lynx view 안에 렌더링됩니다. `container="window"`처럼 native container 이름을 지정하면 host 화면까지 덮는 native overlay에 렌더링됩니다. `overlayLevel`은 overlay의 표시 순서를 정합니다.

### `onOpenChange` Details

`onOpenChange`의 두 번째 인자는 `{ reason }`입니다. 열릴 때는 `"trigger"`이고, 닫힐 때는 `"closeButton"`, `"interactOutside"`, `"drag"` 중 하나입니다. 닫히는 중에 시트를 다시 끌어 올리면 `open`이 `true`인 `"drag"`가 전달됩니다. Item 탭, Root ref의 메서드, `open` prop으로 바꾼 상태에는 호출되지 않습니다.

## 웹 버전과의 차이

- Lynx `MenuSheet`는 React의 `SwipeableMenuSheet`에 해당합니다.
- Trigger는 자식을 native `<view>`로 감싸며 `asChild`를 제공하지 않습니다.
- Item은 native `bindtap`을 사용하며 탭해도 자동으로 닫히지 않습니다.
- ESC 키와 상위 레이어 연쇄 닫힘이 없어 `escapeKeyDown`과 `cascadeDismiss` reason을 제공하지 않습니다.
- `closeOnInteractOutside`, `closeOnEscape`, `lazyMount`, `unmountOnExit`은 제공하지 않습니다.
- `container`와 `overlayLevel`로 native overlay의 위치와 표시 순서를 지정합니다.
