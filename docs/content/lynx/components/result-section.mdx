### Success Example

SEED는 Lynx용 Lottie 컴포넌트를 제공하지 않아 Success Example을 실행 예제로 제공하지 않습니다. 앱에서 사용하는 Lottie 노드를 `asset`에 전달하고, 확인 액션은 `primaryActionProps`로 연결합니다.

## 웹 버전과의 차이

| 영역 | React Web | Lynx |
| --- | --- | --- |
| 네이티브 요소 | `div`, `span`, `button` | `view`, `text` |
| 이벤트 | `onClick` | `bindtap`, `main-thread:bindtap` |
| 루트 속성 | HTML 속성 | Lynx 네이티브 요소 속성과 `accessibility-*` |
| 보조 액션 기본값 | `ghost`, `small`, `color="fg.neutral"`, `fontWeight="bold"`, `bleedX/bleedY="asPadding"` | `ghost`, `small`; 기본 bleed 없음 |
| 보조 액션 bleed 값 | 토큰과 `"asPadding"` 지원 | px 길이, `0`, `"safeArea"` 지원 |

버튼의 접근 가능한 이름과 탭 이벤트는 `primaryActionProps`와 `secondaryActionProps`로 전달합니다.
