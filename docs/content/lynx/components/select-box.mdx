## Usage

`CheckSelectBox`는 여러 항목을 각각 선택할 때 사용합니다. 각 항목이 자신의 선택 상태를 관리하며, `CheckSelectBoxGroup`은 레이아웃을 정합니다.

```tsx
import {
  CheckSelectBox,
  CheckSelectBoxCheckmark,
  CheckSelectBoxGroup,
} from "@/components/ui/select-box";

export function NotificationOptions() {
  return (
    <CheckSelectBoxGroup>
      <CheckSelectBox
        label="채팅 알림"
        description="새 메시지가 오면 알려드려요."
        defaultChecked
        suffix={<CheckSelectBoxCheckmark />}
      />
    </CheckSelectBoxGroup>
  );
}
```

`RadioSelectBoxRoot`는 여러 항목 중 하나만 선택할 때 사용합니다. `value`와 `onValueChange`를 함께 전달하면 선택 값을 직접 제어할 수 있습니다.

```tsx
import { useState } from "@lynx-js/react";
import {
  RadioSelectBoxItem,
  RadioSelectBoxRadiomark,
  RadioSelectBoxRoot,
} from "@/components/ui/select-box";

export function DeliveryOptions() {
  const [value, setValue] = useState("meeting");

  return (
    <RadioSelectBoxRoot value={value} onValueChange={setValue}>
      <RadioSelectBoxItem
        value="meeting"
        label="직거래"
        description="약속 장소에서 직접 거래해요."
        suffix={<RadioSelectBoxRadiomark />}
      />
    </RadioSelectBoxRoot>
  );
}
```

### Collapsible Footer

`footer`로 추가 콘텐츠를 표시하고 `footerVisibility`로 표시 조건을 정합니다.

- `"when-selected"`: 선택됐을 때 표시합니다. 기본값입니다.
- `"when-not-selected"`: 선택되지 않았을 때 표시합니다.
- `"always"`: 선택 상태와 관계없이 표시합니다.

## 웹 버전과의 차이

<Callout type="warning">
Lynx `Select Box`는 React 웹 버전과 다음과 같은 차이가 있습니다.

- **렌더링 요소**: HTML label, input 대신 Lynx `<view>`와 `<text>`를 렌더링합니다.
- **이벤트 핸들링**: DOM `onChange` 대신 `onCheckedChange` 또는 `onValueChange`를 사용합니다. tap과 pressed 상태는 컴포넌트 내부에서 처리합니다.
- **접근성**: snippet이 `label`을 Lynx의 `accessibility-label`로 전달합니다.
- **Label 조합**: ReactNode label 대신 문자열 `label`과 `labelAccessory`를 사용해 Lynx text와 view의 올바른 중첩을 유지합니다.
- **Grid 열 수**: Lynx에서는 `columns="1"`과 `columns="2"`를 지원합니다. 웹의 3열 예시는 2열로 변환했습니다.
- **아이콘**: raw SVG 대신 Lynx에서 렌더링할 수 있는 icon element를 사용해야 합니다.
</Callout>

## Lynx 미지원 기능

React 문서의 다음 예시는 Lynx 런타임에 HTML form 제출 모델이 없어 제공하지 않습니다.

| 예시 또는 기능 | 설명 |
|------|------|
| React Hook Form | hidden input과 DOM form event가 없습니다. controlled state와 변경 callback을 사용하세요. |
| Fieldset / RadioGroupField Integration | Lynx Select Box snippet은 field label, error message, form 제출 prop을 제공하지 않습니다. 필요한 안내 문구는 별도 Lynx layout으로 구성하세요. |
| `name`, `form`, `inputProps` | 전달할 HTML input이 없습니다. |
