### Grid Layout (Columns)

`columns` prop을 사용하여 여러 열로 배치할 수 있습니다. `columns`가 1보다 크면 하위 요소의 `layout`이 자동으로 `"vertical"`로 설정됩니다.

가로형(`layout="horizontal"`)은 단일 컬럼으로 배치합니다. 여러 열로 구성한 그룹에서 개별 항목을 가로형으로 바꾸려면, 아래 예제처럼 래퍼가 모든 열을 차지하도록 `gridColumnStart`와 `gridColumnEnd`를 지정해 전체 너비를 확보하세요.

래퍼는 `HStack align="stretch"`로 구성해 내부 Select Box가 grid 행 높이를 채우도록 합니다.

### Collapsible Footer

`footer` prop으로 추가 콘텐츠를 표시할 수 있습니다. `footerVisibility` prop으로 footer의 표시 조건을 제어할 수 있습니다.

- `"when-selected"` (기본값): 항목이 선택되었을 때만 표시
- `"when-not-selected"`: 항목이 선택되지 않았을 때만 표시
- `"always"`: 항상 표시

## 웹 버전과의 차이

- Lynx에는 native form 제출 모델이 없어 React Hook Form, hidden input, `name`, `required`를 제공하지 않습니다. 선택 값과 오류 상태를 앱에서 관리하세요.
- 라디오 그룹은 label, description, error message를 지원합니다. 체크박스 그룹은 React Registry의 Fieldset 연동을 제공하지 않습니다.
- 브라우저 키보드 focus 대신 native tap과 접근성 탐색을 사용합니다.
- 각 항목은 독립된 접근성 요소입니다. raw `<text>`를 포함하거나 텍스트가 없는 항목에는 `accessibility-label`을 지정하세요.
