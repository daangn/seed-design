## Installation

```package-install
@seed-design/lynx-react @seed-design/lynx-css
```

## Usage

```tsx
import { ImageFrame } from "@seed-design/lynx-react";
```

```tsx
<ImageFrame
  ratio={4 / 3}
  width="200px"
  borderRadius="r2"
  stroke
  src="..."
  alt="..."
  fallback={<view><text>이미지를 불러올 수 없습니다.</text></view>}
/>
```

`width`·`height`·`margin` 등 공통 레이아웃 prop을 받습니다. `margin`과 `bleed`는 함께 사용하지 않으며, `bleed`는 Lynx Box와 같이 px 길이·`0`·`"safeArea"`를 사용합니다.

## Lynx에서의 동작

Lynx Engine 3.9 이상을 지원합니다.

- 로딩 중에도 이미지를 마운트합니다. `src`가 바뀌면 이전 요청의 이벤트를 새 상태에 반영하지 않습니다.
- `alt`는 `accessibility-label`로 전달합니다. 장식용 이미지는 빈 문자열을 사용합니다.
- `onLoad`와 `onError` 대신 `bindload`와 `binderror`를 사용합니다. `onLoadingStatusChange`로 로딩 상태를 관찰할 수 있습니다.
- `ratio`의 기본값은 `4 / 3`, `borderRadius`의 기본값은 `"r2"`입니다.
- `ImageFrameIcon`의 `svg`에는 Lynx 아이콘 컴포넌트를 전달합니다.
- `ImageFrameReactionButton`은 토글 버튼입니다. `pressed`, `defaultPressed`, `onPressedChange`, `disabled`를 제공하며 접근성 이름은 `accessibility-label`로 지정합니다.
- 좋아요 버튼은 `hit-slop`으로 터치 영역을 기본 8px씩 확장합니다. 부모가 콘텐츠를 자르면 확장 영역도 제한될 수 있습니다.
- `as`, `asChild`, DOM 속성, 이미지의 `loading`, `decoding`, `crossOrigin`, `referrerPolicy`, `sizes`, `srcSet`은 지원하지 않습니다.

### Border Radius

`borderRadius`에는 토큰, `0`, CSS 길이를 전달합니다. 개별 모서리는 `borderTopLeftRadius` 같은 prop으로 지정합니다.

```tsx
<ImageFrame
  src={imageUrl}
  alt="상품 이미지"
  width="160px"
  ratio={1}
  borderRadius="r1"
  borderTopLeftRadius="r4"
  borderBottomRightRadius="24px"
  stroke
/>
```

#### Offset

`offsetX`와 `offsetY`로 가로와 세로 여백을 지정합니다. `0`, SEED 간격 토큰, CSS 길이를 사용할 수 있습니다. 가장자리의 기본 여백은 6px이며, 중앙 축의 기본 오프셋은 0입니다.

```tsx
import { ImageFrame, ImageFrameFloater, ImageFrameIndicator } from "@seed-design/lynx-react";

<ImageFrame src={imageUrl} alt="상품 이미지" width="150px" ratio={1}>
  <ImageFrameFloater placement="bottom-end" offsetX="12px" offsetY="12px">
    <ImageFrameIndicator>+9</ImageFrameIndicator>
  </ImageFrameFloater>
</ImageFrame>
```
