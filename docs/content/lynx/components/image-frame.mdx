## Installation

```package-install
@seed-design/lynx-react @seed-design/lynx-css
```

ImageFrame과 보조 컴포넌트는 별도 Registry snippet 없이 패키지에서 직접 제공합니다.

## Usage

```tsx
import { ImageFrame } from "@seed-design/lynx-react";
```

```tsx
<ImageFrame
  ratio={4 / 3}
  borderRadius="r2"
  stroke
  src="..."
  alt="..."
  fallback={<view><text>이미지를 불러올 수 없습니다.</text></view>}
/>
```

## Lynx에서의 동작

- `useImage`로 native `<image>`의 로딩 상태를 처리합니다. 이미지는 로딩 중에도 마운트되며, `src`가 바뀌면 `key={src}`로 native 요청을 분리합니다.
- `alt`는 이미지의 `accessibility-label`로 전달됩니다. 장식용 이미지는 빈 문자열을 사용합니다.
- `onLoad`/`onError` 대신 `bindload`/`binderror`를 사용합니다. `onLoadingStatusChange`로 `loading`, `loaded`, `error`를 관찰할 수 있습니다.
- `ratio`는 기본 `4 / 3`, `borderRadius`는 기본 `r2`입니다. React AspectRatio의 `as`/`asChild`, DOM 속성, 이미지 `loading`, `decoding`, `crossOrigin`, `referrerPolicy`, `sizes`, `srcSet`은 지원하지 않습니다.
- `ImageFrameIcon`의 `svg`에는 Lynx 아이콘 컴포넌트를 전달합니다. 내부 `Icon`이 native 이미지 색상을 처리합니다.
- `ImageFrameReactionButton`은 `useToggle`과 Scale Feedback을 사용합니다. `pressed`, `defaultPressed`, `onPressedChange`, `disabled`를 제공하며 접근성 이름은 `accessibility-label`로 지정합니다. HTML form·키보드 focus API는 제공하지 않습니다.
- 좋아요 아이콘은 React와 동일한 path와 선택 그라디언트를 SVG 이미지로 제공합니다. 웹의 `filter: drop-shadow()` 효과는 적용하지 않습니다. SVG 이미지 렌더링은 호스트의 이미지 서비스 지원이 필요합니다.
