## Installation

```package-install
@seed-design/lynx-react @seed-design/lynx-css
```

ImageFrame과 보조 컴포넌트는 별도 Registry snippet 없이 패키지에서 직접 제공합니다.

## Usage

```tsx
import { ImageFrame } from "@seed-design/lynx-react";
```

```tsx
<ImageFrame
  ratio={4 / 3}
  borderRadius="r2"
  stroke
  src="..."
  alt="..."
  fallback={<view><text>이미지를 불러올 수 없습니다.</text></view>}
/>
```

## Lynx에서의 동작

ImageFrame은 Lynx Engine 3.9 이상을 지원합니다. 3.6에서는 비율 기반 레이아웃과 콘텐츠 표시 문제가 확인되어 지원 범위에서 제외합니다.

- `@seed-design/lynx-react-image`의 headless Image 컴포넌트로 로딩 상태를 처리합니다. 이미지는 로딩 중에도 마운트되며, `src`가 바뀌면 native 요청을 분리합니다.
- `alt`는 이미지의 `accessibility-label`로 전달됩니다. 장식용 이미지는 빈 문자열을 사용합니다.
- `onLoad`/`onError` 대신 `bindload`/`binderror`를 사용합니다. `onLoadingStatusChange`로 `loading`, `loaded`, `error`를 관찰할 수 있습니다.
- `ratio`는 기본 `4 / 3`, `borderRadius`는 기본 `r2`입니다. React AspectRatio의 `as`/`asChild`, DOM 속성, 이미지 `loading`, `decoding`, `crossOrigin`, `referrerPolicy`, `sizes`, `srcSet`은 지원하지 않습니다.
- `ImageFrameIcon`의 `svg`에는 Lynx 아이콘 컴포넌트를 전달합니다. 내부 `Icon`이 native 이미지 색상을 처리합니다.
- `ImageFrameReactionButton`은 `@seed-design/lynx-react-toggle`의 headless Toggle 컴포넌트와 Scale Feedback을 사용합니다. `pressed`, `defaultPressed`, `onPressedChange`, `disabled`를 제공하며 접근성 이름은 `accessibility-label`로 지정합니다. HTML form·키보드 focus API는 제공하지 않습니다.
- 좋아요 아이콘은 호스트별 SVG 이미지 렌더링 차이를 피하기 위해 React와 동일한 path와 선택 그라디언트를 WebP로 제공합니다. 현재 이미지에는 웹의 그림자 효과를 포함하지 않습니다.
- 좋아요 버튼은 `hit-slop`으로 터치 영역을 기본 `8px`씩 확장합니다. 부모의 clipping에 따라 확장이 제한될 수 있으므로 프레임 가장자리에서도 탭을 확인하세요.

### Fallback Image

`fallback` prop으로 이미지가 로드되지 않았을 때 보여질 요소를 지정할 수 있습니다. 로딩 중과 오류 상태에 표시되며, 성공하면 언마운트됩니다. 숨긴 상태로 유지하는 React와 달리 자식의 내부 상태가 초기화되므로, 유지할 상태는 부모에서 관리하세요. 예제는 native `view`와 `text`로 fallback을 구성합니다.
