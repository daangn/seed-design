## Usage

```tsx
import { Count } from "@seed-design/lynx-react";

export function App() {
  return <Count>99+</Count>;
}
```

텍스트와 나란히 배치해 수치를 강조할 때 주로 사용합니다.

```tsx
import { Count } from "@seed-design/lynx-react";

export function App() {
  return (
    <view style={{ display: "flex", flexDirection: "row", gap: "4px", alignItems: "baseline" }}>
      <text>댓글</text>
      <Count>24</Count>
    </view>
  );
}
```

## 웹 버전과의 차이

<Callout type="warning">
Lynx `Count`는 React `Count`와 다음과 같은 차이가 있습니다.

- **렌더링 요소**: HTML `<span>` 대신 네이티브 `<text>` 요소를 렌더링합니다.
- **클래스**: `seed-count`가 `seed-count__text`로 변환되어 `<text>`에 직접 적용됩니다. 웹의 루트 래퍼 구조는 존재하지 않습니다.
- **HTML 속성 미지원**: `React.HTMLAttributes<HTMLSpanElement>`로 받던 웹 속성(`id`, `role`, `aria-*` 등)은 Lynx에 대응되지 않아 제거되었습니다.
</Callout>
