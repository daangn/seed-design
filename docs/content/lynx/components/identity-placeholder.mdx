## Usage

부모의 너비와 높이를 모두 채우며, 도형은 비율을 유지한 채 중앙에 표시됩니다. 크기를 지정한 부모 안에 배치하세요.

```tsx
import { Box } from "@seed-design/lynx-react";
import { IdentityPlaceholder } from "@/components/ui/identity-placeholder";

export function ProfileFallback() {
  return (
    <Box width="160px" height="160px">
      <IdentityPlaceholder />
    </Box>
  );
}
```

기본값인 `identity="person"`은 사람 도형을 표시합니다. 매장에는 `identity="business"`를 사용합니다.

## Props

<react-type-table
  path="./registry/lynx/ui/identity-placeholder.tsx"

`imageProps`로 native `<image>`의 접근성 속성을 전달할 수 있습니다. 기본 접근성 레이블은 `"Identity placeholder"`입니다.

```tsx
<IdentityPlaceholder imageProps={{ "accessibility-label": "프로필 이미지 없음" }} />
```

## 웹 버전과의 차이

- SVG 대신 패키지에 포함된 native 이미지를 사용합니다. 외부 URL 요청은 발생하지 않습니다.
- `imageProps`로 `src`나 `mode`를 지정하면 기본 이미지와 맞춤 방식을 덮어씁니다.
- 동적 tint와 `asChild`는 지원하지 않습니다.
