## Usage

```tsx
import {
  TabsCarousel,
  TabsContent,
  TabsList,
  TabsRoot,
  TabsTrigger,
} from "@/components/ui/tabs";

export function App() {
  return (
    <TabsRoot defaultValue="one" triggerLayout="fill">
      <TabsList>
        <TabsTrigger value="one">첫 번째</TabsTrigger>
        <TabsTrigger value="two">두 번째</TabsTrigger>
      </TabsList>
      <TabsCarousel swipeable className="tabs-carousel">
        <TabsContent value="one">
          <text>첫 번째 콘텐츠</text>
        </TabsContent>
        <TabsContent value="two">
          <text>두 번째 콘텐츠</text>
        </TabsContent>
      </TabsCarousel>
    </TabsRoot>
  );
}
```

`TabsCarousel`에는 `TabsContent`를 자식으로 전달합니다. 앱 레이아웃에 맞는 높이를 지정하고, `swipeable`을 설정하면 좌우 스와이프로 탭을 바꿀 수 있습니다.

iOS의 화면 왼쪽 가장자리에서 시작하는 뒤로 가기 제스처 범위는 `iosBackGestureEdgeWidth`로 조절할 수 있습니다.

`TabsList`의 `scrollAlign`은 선택한 탭을 가로 목록에 맞추는 방식입니다. `"nearest"`, `"start"`, `"center"`, `"end"`를 지원하며 기본값은 `"start"`입니다.


## Examples

### Extending to Safe Area

`TabsRoot`에 `extendSafeAreaX`를 지정하면 목록 배경과 하단 선, Carousel 패널이 좌우 safe area까지 확장됩니다. 탭과 패널 내용은 안전 영역 안에 남습니다. 기본값은 `false`입니다.

`scrollAlign`은 기존 정렬 방식을 유지하며, 확장된 목록에서는 안전 영역을 기준으로 선택한 탭을 보여 줍니다. `"center"`는 좌우 inset이 다른 경우에도 안전 영역의 중앙에 맞춥니다.

`Box pl="safeArea" pr="safeArea"`처럼 좌우 inset을 이미 확보한 컨테이너 바로 안에서 사용하세요. inset을 확보하지 않은 곳에 적용하면 화면 밖으로 넘칠 수 있습니다. Carousel 안의 `fixed` 요소처럼 부모의 padding을 따르지 않는 요소는 별도로 처리해야 합니다.

### Transition

<Callout type="warn">
Lynx의 `TabsCarousel`은 탭을 선택할 때 native viewpager의 `selectTab`을 `smooth: false`로 호출하므로 콘텐츠가 즉시 바뀝니다. 전환 효과가 필요하면 `TabsCarousel` 대신 선택 값을 기준으로 콘텐츠를 직접 렌더링하고 앱에서 애니메이션을 적용하세요.
</Callout>

## Web Version Differences

- 탭 이벤트는 `onClick` 대신 `bindtap`으로 받습니다.
- Carousel은 네이티브 `<viewpager>`, 가로 탭 목록은 `<scroll-view>`를 사용합니다.
- 접근성은 ARIA 대신 Lynx의 `accessibility-*` 속성을 사용합니다.

<Callout type="info">
스와이프와 Indicator 이동은 QR 코드 패널에서 Lynx Explorer로 확인하세요. 브라우저 미리보기와 네이티브 기기의 제스처 결과가 다를 수 있습니다.
</Callout>

## Unsupported Lynx Features

- 세로 `orientation`
- 키보드 방향키, Home/End, roving focus
- RTL 순서와 스와이프 방향 반전
- `asChild`
- `lazyMount`, `unmountOnExit`
- Carousel의 `loop`, `autoHeight`, `dragThreshold`, `carouselPreventDrag`
- 콘텐츠 전환 애니메이션
