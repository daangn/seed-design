## Installation
```package-install
@seed-design/lynx-react
```

Lynx의 `ScrollFog`는 Registry snippet이나 Recipe 없이 `@seed-design/lynx-react` 패키지에서 직접 제공합니다. native `<scroll-view>`의 fading edge를 사용합니다.

## Usage

`ScrollFog`는 하나의 native `<scroll-view>`를 렌더링하고 `fading-edge-length`로 스크롤 방향의 가장자리를 페이드합니다. `placement`의 두 값이 세로 방향이면 vertical scroll-view를, 가로 방향이면 horizontal scroll-view를 만듭니다.

```tsx
import { ScrollFog } from "@seed-design/lynx-react";

export function App() {
  return (
    <view style={{ height: "300px" }}>
      <ScrollFog placement={["top", "bottom"]}>
        <view style={{ padding: "20px 0 80px" }}>
          <text>스크롤할 콘텐츠</text>
        </view>
      </ScrollFog>
    </view>
  );
}
```

`size`의 숫자 값은 px 단위로 변환됩니다. 기본 크기는 `20`이며 `size="2em"`처럼 문자열 단위도 전달할 수 있습니다. `hideScrollBar`의 기본값은 `false`이므로 native `scroll-bar-enable=true`가 되고, `true`로 설정하면 indicator를 숨기기 위해 `false`가 됩니다.

## Props

### `ScrollFog`

지원하는 `placement`는 `['top', 'bottom']` 또는 `['left', 'right']`입니다. 한쪽 edge만 지정하거나 `['top', 'bottom', 'left', 'right']`처럼 두 축을 동시에 지정할 수 없습니다. 네이티브 `fading-edge-length`, `scroll-orientation`, `scroll-y`, `scroll-x`, `scroll-bar-enable` prop은 `ScrollFog`가 동작을 결정하므로 public native passthrough에서 제외됩니다.

## Examples

### Padding

네이티브 fog는 항상 그려지는 웹 mask와 달리, 해당 edge에 스크롤할 콘텐츠가 더 있을 때만 나타납니다. 콘텐츠가 fog에 가려지지 않도록 지정한 방향에 최소 `20px`의 여백을 두고, 화면 전체를 차지하는 세로 스크롤에서는 하단 `80px`, 상단 `20px` 정도를 권장합니다.

### Horizontal Scroll

`placement={["left", "right"]}`를 사용하면 가로 스크롤과 좌우 fog를 만들 수 있습니다. 좌우 콘텐츠에 `20px` 정도의 여백을 두세요.

React의 `sizes`처럼 edge마다 다른 길이를 지정하는 API는 Lynx에서 지원하지 않습니다. 네이티브 scroll-view가 한 축에 하나의 `fading-edge-length`만 사용하기 때문입니다. edge별 길이가 필요하면 앱에서 native scroll-view와 별도 overlay 또는 mask를 직접 조합하세요.

### All Directions

React의 `placement={["top", "bottom", "left", "right"]}` 2축 fog는 Lynx에서 지원하지 않습니다. `ScrollFog`는 한 번에 하나의 축만 가지는 native scroll-view를 렌더링합니다. 2축 콘텐츠가 필요하면 앱에서 스크롤 축별 native 영역과 시각적 안내 레이어를 직접 구성하세요.

`hideScrollBar`를 사용하면 fog 효과는 유지하면서 native scroll indicator를 숨깁니다.

## 웹 버전과의 차이

| 항목 | React Web | Lynx |
| --- | --- | --- |
| 렌더링 요소 | HTML overflow 영역과 CSS mask | native `<scroll-view>` 하나와 `fading-edge-length` |
| 방향 | top/bottom, left/right, 두 축 조합 | vertical 또는 horizontal 한 축 |
| fade 표시 | 지정한 edge에 CSS mask를 표시 | 해당 edge에 추가 콘텐츠가 있을 때만 native fade 표시 |
| 크기 | `size`와 edge별 `sizes` | 모든 edge에 같은 `size` 하나 |
| 스크롤 indicator | CSS scrollbar 제어 | `hideScrollBar`가 `scroll-bar-enable`을 결정 |

네이티브 fading edge는 현재 위치에서 더 스크롤할 콘텐츠가 남아 있는 edge에만 보입니다. 콘텐츠가 viewport에 모두 들어오거나 해당 방향의 끝에 도달하면 그 edge의 fade는 사라집니다.
