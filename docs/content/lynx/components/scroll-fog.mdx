Scroll Fog는 완전한 Scroll Area보다 간단한 스크롤 힌트를 위한 컴포넌트입니다. 지정한 edge에 Rootage의 `gradient.fade-mask`로 mask를 적용하며, 스크롤 자체는 하지 않습니다. 스크롤이 필요한 콘텐츠는 `<scroll-view>`나 스크롤을 소유한 컴포넌트로 감싸 `ScrollFog` 안에 둡니다.

## Installation

```package-install
@seed-design/lynx-react
```

Lynx의 `ScrollFog`는 Registry snippet이나 Recipe 없이 `@seed-design/lynx-react` 패키지에서 직접 제공합니다.

## Usage

`ScrollFog` 안에 스크롤 방향과 같은 축의 `<scroll-view>`를 직접 배치하세요. `placement`는 세로(`top`·`bottom`) 또는 가로(`left`·`right`) 중 한 축의 방향만 받습니다. 공통 `size`와 방향별 `sizes`로 fog 크기를 조절합니다. Fog mask는 콘텐츠를 감싸는 view에 적용되므로 터치 입력을 가로채지 않습니다.

```tsx
import { ScrollFog } from "@seed-design/lynx-react";

export function App() {
  return (
    <view style={{ height: "300px" }}>
      <ScrollFog placement={["top", "bottom"]} style={{ width: "100%", height: "100%" }}>
        <scroll-view scroll-orientation="vertical" style={{ width: "100%", height: "100%" }}>
          <view style={{ padding: "20px 0 80px" }}>
            <text>스크롤할 콘텐츠</text>
          </view>
        </scroll-view>
      </ScrollFog>
    </view>
  );
}
```

## Examples

### Padding

ScrollFog는 항상 fog 효과를 표시하므로, 지정된 방향에 충분한 padding이 필요합니다.

- **최소 padding**: 20px을 유지해야 합니다.
- **화면 전체를 차지하는 세로 스크롤**: 하단 80px, 상단 20px padding을 권장합니다.
- **가로 스크롤**: 좌우 20px padding을 권장합니다.

```tsx
// 상하 스크롤 - 상하 padding 필요
<ScrollFog placement={["top", "bottom"]}>
  <scroll-view scroll-orientation="vertical">
    <view style={{ padding: "20px 0 80px" }}>...</view>
  </scroll-view>
</ScrollFog>

// 좌우 스크롤 - 좌우 padding 필요
<ScrollFog placement={["left", "right"]}>
  <scroll-view scroll-orientation="horizontal">
    <view style={{ padding: "0 20px" }}>...</view>
  </scroll-view>
</ScrollFog>
```

### Horizontal Scroll

가로 스크롤이 필요한 경우 `scroll-orientation="horizontal"`인 `<scroll-view>`를 `placement={["left", "right"]}`인 `ScrollFog`로 감쌉니다. 콘텐츠가 잘리지 않도록 좌우 20px padding을 제공하세요.

## 웹 버전과의 차이

- **스크롤 축**: 웹은 하나의 `overflow: auto` 요소가 두 축으로 스크롤하므로 네 방향을 함께 지정할 수 있습니다. Lynx `<scroll-view>`는 `scroll-orientation`으로 세로 또는 가로 한 축만 스크롤하므로, `placement`도 한 축의 방향만 받습니다. React의 All Directions 예제에 대응하는 예제는 없습니다.
- **스크롤 host**: React `ScrollFog`는 자신이 스크롤 영역입니다. Lynx `ScrollFog`는 mask만 적용하고 스크롤하지 않으므로, `<scroll-view>`나 `ChipTabsList`처럼 스크롤을 소유한 요소를 자식으로 둡니다. ref와 native props는 스크롤하지 않는 root `view`에 전달되므로, 스크롤 위치 제어와 `bindscroll` 같은 이벤트는 자식 `<scroll-view>`에서 사용하세요.
- **스크롤바 숨김**: `hideScrollBar`를 제공하지 않습니다. 자식 `<scroll-view>`에 `scroll-bar-enable={false}`를 지정하세요.
