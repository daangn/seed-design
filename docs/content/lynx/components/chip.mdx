## 이전 버전에서 옮기기

- `Chip.Root`·`ChipRoot`(Props 타입 포함)를 제거했습니다. React와 같이 `Chip.Button`·`ChipButton`을 사용하세요. 동작과 스타일은 같습니다.
- `Chip.Toggle`의 기본 `accessibility-role-description`이 `"toggle"`에서 `"checkbox"`로 바뀌었습니다. 이전 값이 필요하면 `accessibility-role-description`을 직접 전달하세요.
- `Chip.RadioRoot`는 `radiogroup` 역할을 전달하지만 기본적으로 접근성 요소가 아닌 컨테이너입니다. 각 `Chip.RadioItem`이 독립된 접근성 요소로 노출됩니다. `disabled`이면 `accessibility-traits` 기본값은 `"disabled"`입니다.
- `Chip.Toggle`과 `Chip.RadioItem`의 `bindtap`이 선택 상태를 바꾸기 전에 호출됩니다. tap handler에서 바뀐 선택 값을 읽던 코드는 `onCheckedChange`나 `Chip.RadioRoot`의 `onValueChange`로 옮기세요.

## 웹 버전과의 차이

- 탭 이벤트는 `onClick` 대신 `bindtap`으로 받습니다. 선택 변경은 `onCheckedChange` 또는 `onValueChange`로 확인합니다.
- 접근성 역할과 상태는 Lynx의 `accessibility-role-description`, `accessibility-value`, `accessibility-traits`로 전달합니다.
- 문자열 label을 파악할 수 없는 구성에는 `accessibility-label`을 지정하세요.
- Lynx `Chip`은 별도 Registry snippet 없이 `@seed-design/lynx-react`에서 제공합니다.
