## 웹 버전과의 차이

<Callout type="warning">

- 값 변경은 `onChange`가 아닌 `onCheckedChange`로 받습니다.
- HTML `<label>`과 `<input>` 대신 네이티브 `<view>`와 `<text>`를 렌더링합니다.
- 직접 작성한 `<text>`, 텍스트 없는 `Switchmark`, prop으로만 렌더링한 문구는 접근성 이름을 만들 수 없습니다. `accessibility-label`을 직접 지정하세요.

</Callout>

## Scale Feedback

Lynx `Switch`는 누르는 동안 스위치 모양을 줄입니다. 콘텐츠를 축소하는 SEED 컴포넌트 안에서는 이 효과를 생략합니다. React의 `--seed-switchmark-feedback-scale` CSS 변수는 제공하지 않습니다.

## Lynx 미지원 기능

현재 Lynx 플랫폼 제약으로 다음 기능이 지원되지 않습니다.

### 런타임 모델 차이로 제외

| 기능 | 웹 대응 | 설명 |
|------|---------|------|
| `SwitchHiddenInput` | `<input type="checkbox">` | Lynx에 HTML form 제출 모델 없음 |
| `name` / `value` / `required` / `invalid` | form field props | Lynx에 native form 제출 모델 없음 |
| `focus` / `focusVisible` | 키보드 포커스 | Lynx에 키보드 포커스 개념 없음 |
| `onChange` (raw DOM event) | `React.ChangeEvent` | 의미 없음. `onCheckedChange`로 대체 |
