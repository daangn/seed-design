화면 상단에서 검색하는 경우에는 Search Input을 직접 배치하지 말고 [Search Bar](/lynx/components/search-bar)를 사용하세요. Search Bar는 Search Input을 App Bar에 Back·닫기 버튼과 함께 배치합니다.

## Usage

```tsx
import IconXmarkCircleFill from "@karrotmarket/lynx-monochrome-icon/IconXmarkCircleFill";
import { Icon, SearchInput } from "@seed-design/lynx-react";
```

```tsx
<SearchInput.Root value={value} onValueChange={setValue} onSubmit={handleSubmit}>
  <SearchInput.Input accessibility-label="검색" placeholder="검색어를 입력해주세요" />
  <SearchInput.ClearButton accessibility-label="지우기">
    <Icon icon={<IconXmarkCircleFill />} />
  </SearchInput.ClearButton>
</SearchInput.Root>
```

## Props

### `SearchInput.Root`

### `SearchInput.Input`

고유 prop이 없습니다. `placeholder`, `maxlength`, `accessibility-label`처럼 Lynx `<input>`의 속성을 받습니다. `confirm-type`은 `"search"`로 고정됩니다.

### `SearchInput.ClearButton`

고유 prop이 없습니다. `className`, `style`, `children`, `bindtap`, `accessibility-label`을 받습니다.

## Examples

### Submit

키보드의 검색 키를 누르면 `onSubmit`이 현재 값과 함께 호출됩니다. Lynx `<input>`의 `bindconfirm` 이벤트를 사용합니다.

제출한 뒤에는 입력의 focus를 해제해 키보드를 내립니다. 제출 뒤에도 계속 입력하게 하려면 `blurOnSubmit={false}`를 사용하세요. 이때 Lynx `<input>`의 `confirm-enter`를 켜서 native 입력이 제출 뒤 스스로 focus를 해제하지 않게 합니다.

### Clear Button

`SearchInput.ClearButton`은 값이 있을 때만 렌더링되고, 누르면 값을 비웁니다. `value`를 넘기지 않은 uncontrolled 상태에서도 동작하며, `onValueChange`가 빈 문자열과 함께 호출됩니다.

입력에 focus가 있었다면 지운 뒤에도 유지하고, 없었다면 새로 주지 않습니다. Clear 버튼은 `ignore-focus`로 탭이 입력의 focus를 가져가지 않게 하고, 그래도 탭 직전에 focus가 해제되는 host에서는 값을 비운 뒤 focus를 되돌립니다.

## Accessibility

- 화면에 보이는 레이블이 없으므로 `SearchInput.Input`과 `SearchInput.ClearButton`에 `accessibility-label`을 제공해야 합니다. 없으면 개발 콘솔에 경고가 출력됩니다.
- `SearchInput.ClearButton`은 `accessibility-traits="button"`으로 알립니다.
- 콘텐츠를 누르거나 스크롤할 때 키보드를 내리는 동작은 Search Input이 아닌 화면이 담당합니다. [Search Bar](/lynx/components/search-bar#keyboard) 예제를 참고하세요.

## 웹 버전과의 차이

- 제출은 Enter 키의 `keydown` 대신 Lynx `<input>`의 `bindconfirm`(키보드의 검색 키)으로 처리합니다.
- `SearchInput.Root`는 `value`·`defaultValue`·`onValueChange`·`name`과 제출 prop만 받습니다. `disabled`·`readOnly`·`invalid`·`required`는 지원하지 않습니다.
- `role="search"`에 대응하는 Lynx 접근성 역할이 없어 Root에는 역할을 지정하지 않습니다.
