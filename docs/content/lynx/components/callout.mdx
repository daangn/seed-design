## Usage

```tsx
import { Callout } from "@/components/ui/callout";

export function Notice() {
  return (
    <Callout
      tone="informative"
      title="새로운 기능"
      description="새로운 기능을 확인해 보세요."
    />
  );
}
```

Compound API가 필요하면 `Callout.Root`, `Callout.Content`, `Callout.Title`, `Callout.Description`, `Callout.Link`, `Callout.CloseButton`을 조합할 수 있습니다.

## Web Version Differences

- HTML element 대신 native `<view>`와 `<text>`를 사용합니다.
- `asChild`는 지원하지 않습니다. Actionable Callout은 `bindtap`으로 동작을 전달합니다.
- Web의 `aria-*` 대신 Lynx의 `accessibility-*` 속성을 사용합니다.
- 아이콘은 Lynx icon element를 `PrefixIcon` 또는 `SuffixIcon`으로 감쌉니다.

## Unsupported Lynx Features

- HTML link/button attribute와 DOM focus API는 제공하지 않습니다.
- `Callout.Link`는 Lynx의 `text` slot이며, 동작은 `bindtap`으로 연결해야 합니다.
- Dismissible 상태는 `open`, `defaultOpen`, `onDismiss`로 제어하며, 별도 Presence 애니메이션은 사용하지 않습니다.
