## Usage

`SelectContent`는 긴 목록을 스크롤합니다. `container`를 지정하지 않으면 Lynx view 안에, 지정하면 native overlay에 렌더링됩니다.

```tsx
import {
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectRoot,
  SelectTrigger,
} from "@/components/ui/select";

export function App() {
  return (
    <view style={{ width: "240px" }}>
      <SelectRoot defaultValue={["apple"]}>
        <SelectTrigger accessibility-label="과일" placeholder="과일을 선택하세요" />
        <SelectContent>
          <SelectGroup>
            <SelectItem value="apple" label="사과" />
            <SelectItem value="banana" label="바나나" />
            <SelectItem value="cherry" label="체리" />
          </SelectGroup>
        </SelectContent>
      </SelectRoot>
    </view>
  );
}
```

- `multiple`일 때는 항목을 탭해도 목록을 닫지 않고 선택 상태를 전환합니다.
- `SelectRoot`의 문자열 `label` 또는 `accessibility-label`은 Trigger의 기본 접근성 이름으로 사용됩니다.
- 목록을 열면 선택된 항목이 보이도록 스크롤하며, Trigger 주변의 여유 공간과 safe area에 맞춰 높이를 제한합니다.

### Long List

목록은 상하 8px 패딩을 포함한 내용 높이만큼 표시하며, 별도의 최소 높이는 없습니다. 최대 높이는 480px이고 trigger 주위의 남은 공간과 safe area에 맞춰 제한합니다. 내용이 이 높이를 넘을 때만 스크롤됩니다.

### Container

`container`를 지정하지 않으면 Select 레이어는 Lynx view 안의 `position: fixed` view로 렌더링되고, z-index `99`로 같은 화면의 형제 요소 위에 그려집니다. `container="window"`처럼 native container 이름을 지정하면 native overlay에 렌더링되어 Lynx view 밖의 host 화면까지 덮습니다. `overlayLevel`은 `container`를 지정했을 때 overlay의 표시 순서를 정합니다.

두 방식 모두 레이어 바깥을 탭하면 아래 화면에 탭을 전달하지 않고 `"interactOutside"` reason으로 닫힙니다. 닫힌 동안에도 레이어를 숨긴 채 유지하므로 열기 전에도 `defaultValue`의 label과 아이콘을 trigger에 표시합니다.

### `onOpenChange` Details

`onOpenChange`의 두 번째 인자는 상태를 바꾼 이유와 native event를 제공합니다.

- 열림: `"trigger"`
- 닫힘: `"trigger"`, `"itemSelect"`, `"interactOutside"`
- `container`를 지정한 native overlay가 닫힘을 요청한 경우(Android 뒤로 가기): `"dismiss"`. `container`가 없으면 전달하지 않으며, Android 뒤로 가기는 Select가 아니라 host 화면을 닫습니다.

### Form Integration

Lynx에는 HTML `<form>`과 native `<select>` 제출 모델이 없습니다. 선택 값은 `onValueChange`로 앱 state에 저장하고, 제출 action의 payload에 그 값을 넣으세요.

### React Hook Form

React Hook Form 통합은 제공하지 않습니다. `value`, `onValueChange`, `invalid`, `errorMessage`를 앱 상태에 연결하세요.

## 웹 버전과의 차이

- Trigger는 native 요소이며 `asChild`를 제공하지 않습니다.
- `onOpenChange`의 reason은 `trigger`, `itemSelect`, `interactOutside`, `dismiss`입니다.
- 키보드 focus, typeahead, Escape 키 닫기는 지원하지 않습니다.
- `container`를 지정하면 목록을 native overlay에 렌더링합니다.

## Lynx 미지원 기능

- HTML form 제출과 브라우저 validation은 지원하지 않습니다. `onValueChange`로 앱 상태를 갱신하고 제출 action에서 검증하세요.
- React Hook Form 통합은 제공하지 않습니다. 값과 오류 상태를 앱 상태에 직접 연결하세요.
- DOM focus, typeahead, ARIA id 연결은 지원하지 않습니다. native 접근성 속성과 host의 접근성 탐색을 사용하세요.
