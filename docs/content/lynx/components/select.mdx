## 사용법

```tsx
import {
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectRoot,
  SelectTrigger,
} from "@/components/ui/select";

const fruitOptions = [
  { value: "apple", textValue: "사과", label: "사과" },
  { value: "pear", textValue: "배", label: "배" },
  { value: "banana", textValue: "바나나", label: "바나나" },
];

<SelectRoot options={fruitOptions} defaultValue={["apple"]}>
  <SelectTrigger placeholder="과일을 선택하세요" />
  <SelectContent>
    <SelectGroup label="과일">
      {fruitOptions.map((option) => (
        <SelectItem key={option.value} value={option.value} />
      ))}
    </SelectGroup>
  </SelectContent>
</SelectRoot>;
```

- `SelectRoot`는 옵션, 선택 값(`value`)과 열림 상태를 관리합니다. 값은 항상 `string[]`으로 전달합니다.
- `SelectTrigger`는 선택된 값 또는 placeholder를 표시하고, 누르면 목록을 엽니다.
- `SelectContent`는 목록을 트리거 주변에 배치하는 컨테이너입니다.
- `SelectGroup`은 관련 옵션을 묶고 `label`로 그룹 제목을 표시합니다.
- `SelectItem`은 개별 옵션입니다. `value`가 필요하며, `description`으로 보조 설명을 표시할 수 있습니다.

## 웹 버전과의 차이

<Callout type="warning">
Lynx `Select`는 React `Select`과 다음 차이가 있습니다.

- **열림 상태 변경 사유**: Popover backdrop을 탭해 외부에서 목록을 닫을 수 있습니다. 다만 Lynx `Select`의 `onOpenChange`는 boolean만 전달하므로 웹의 `details.reason`과 `open-change-reason` 예제는 제공하지 않습니다.
- **Native form 제출**: `HiddenSelect`, `name`, submit validation을 제공하지 않습니다. Lynx에는 HTML native form 제출 모델이 없으므로 `form` 예제는 지원하지 않습니다.
- **React Hook Form**: native form과 React Hook Form 연동을 제공하지 않습니다.
- **키보드와 typeahead**: 웹의 키보드 포커스, 화살표 키 탐색, typeahead 검색은 제공하지 않습니다. 사용자는 native tap과 접근성 탐색으로 옵션을 선택합니다.
- **접근성**: HTML ARIA와 DOM 관계 속성 대신 Lynx의 native 접근성 역할과 선택 값을 사용합니다.
- **Field 구성**: `label`, `description`, `errorMessage`는 화면 표시와 접근성 안내를 지원하지만 native form 제출이나 HTML 검증에는 연결되지 않습니다.
</Callout>

React `Select`의 17개 시나리오 중 preview, 크기, 그룹, 여러 값 선택, 보조 설명, 앞 아이콘, 사용자 정의 라벨, 비활성화, 긴 목록, 제어된 선택 값, 제어된 열림 상태, 선택 값 표시 형식, 목록 위치, Field 구성은 Lynx에서 제공합니다. 열림 상태 변경 사유, form 제출, React Hook Form은 위 플랫폼 제약으로 제공하지 않습니다.
