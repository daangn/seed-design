## Examples

### Basic Usage

`FieldButton`은 값을 직접 편집하지 않고 선택창이나 피커를 여는 버튼입니다. `buttonProps.bindtap`에 열기 동작을 전달하고, 선택 여부에 따라 `FieldButtonValue` 또는 `FieldButtonPlaceholder`를 자식으로 사용합니다.

### Clear Button

`showClearButton`을 `true`로 설정하면 Clear Button이 표시됩니다. 선택 값은 소비처가 `values`로 소유하고, Clear Button을 누르면 `clearButtonProps.bindtap` 다음에 `onValuesChange([])`가 호출됩니다. `onValuesChange`에서 소비처 state를 비우세요. Field Button은 값을 직접 바꾸지 않습니다.

`FieldButton`이 `disabled` 또는 `readOnly` 상태이면 Clear Button은 표시되지 않습니다.

### Accessibility

Field Button 내부 버튼의 `accessibility-label`에 열리는 선택 화면과 현재 선택된 값을 함께 설명하세요.

```tsx
<FieldButton
  label="사용자 이름"
  description="본명을 사용하지 않아도 괜찮습니다."
  buttonProps={{
    "accessibility-label": `사용자 이름 선택 화면 열기. 현재 선택된 이름: ${username || "없음"}`,
    bindtap: openUsernamePicker,
  }}
>
  {username ? (
    <FieldButtonValue>{username}</FieldButtonValue>
  ) : (
    <FieldButtonPlaceholder>김하늘</FieldButtonPlaceholder>
  )}
</FieldButton>
```

## Web Version Differences

- HTML `<button>` 대신 Lynx `<view>`에 tap handler와 `accessibility-*` 속성을 적용합니다.
- `onClick` 대신 `buttonProps.bindtap`을 사용합니다. main thread handler가 필요하면 `buttonProps["main-thread:bindtap"]`을 사용할 수 있습니다.
- `aria-label` 대신 `buttonProps["accessibility-label"]`을 사용합니다.

## Unsupported Lynx Features

- HTML form submit과 hidden input(`HiddenInput`·`name`), browser validation, React Hook Form 연동은 지원하지 않습니다. Lynx에는 native form 제출 모델이 없습니다.
- DOM id 기반 `aria-describedby` 연결과 `aria-haspopup`은 지원하지 않습니다.
