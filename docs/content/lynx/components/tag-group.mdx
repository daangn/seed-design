## Examples

### Usage


```tsx
import { TagGroupRoot, TagGroupItem } from "@/components/ui/tag-group";

export function App() {
  return (
    <TagGroupRoot size="t2">
      <TagGroupItem label="동네 인증" />
      <TagGroupItem label="매너 온도 42.0°C" />
      <TagGroupItem tone="brand" weight="bold" label="추천" />
    </TagGroupRoot>
  );
}
```

`TagGroupRoot`의 `size`, `weight`, `tone`은 항목의 기본값이며 개별 `TagGroupItem`에서 덮어쓸 수 있습니다. 구분자는 기본 `"·"`이고 `separator`로 바꿀 수 있습니다.

`TagGroupItem`의 `flexShrink`로 긴 태그의 축소 우선순위를 조절할 수 있습니다.

`TagGroup`은 읽기 전용입니다. 단일 선택에는 `RadioGroup`, 다중 선택에는 `Checkbox`를 사용하세요.

## 웹 버전과의 차이

- 웹은 inline text flow로 항목 안의 텍스트도 줄바꿈할 수 있습니다. Lynx는 항목 단위로 다음 줄에 배치합니다.
- 문자열 구분자의 앞뒤 공백은 제거하고 컴포넌트가 일정한 간격을 적용합니다.
- 구분자는 스크린 리더에서 제외합니다. Root와 Item에는 전달한 `accessibility-*` 속성을 적용합니다.
- 이벤트는 `onClick` 대신 `bindtap` 또는 `main-thread:bindtap`으로 받습니다.

### 미지원 prop

- `truncate`
- `asChild`
- `prefixIcon`, `suffixIcon`
