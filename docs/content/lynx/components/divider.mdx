## Screen Reader Behavior

Divider는 기본적으로 접근성 트리에 포함되며 구분선으로 읽힙니다. 장식용이라면 `accessibility-element={false}`를 지정하세요.

## Web Version Differences

- native `<view>`를 렌더링하며 Lynx 접근성 속성을 사용합니다.
- 세로 Divider의 방향은 접근성 트리에 별도로 노출되지 않습니다.
- 세로 Divider는 부모가 높이를 지정해야 합니다.

## Unsupported Lynx Features

- 웹의 `as` prop을 지원하지 않습니다.
- 접근성 노출 여부는 `accessibility-element`로 조정합니다.
