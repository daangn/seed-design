## Web Version Differences

<Callout type="warning">
Lynx `Accordion`은 네이티브 탭 이벤트와 접근성 속성을 사용합니다.

`AccordionTrigger`의 `title`이 문자열이 아니면 `accessibility-label`을 직접 지정합니다.
</Callout>

## Unsupported Lynx Features

| 기능 | 설명 |
|------|------|
| `asChild` | `asChild` 기반 요소 교체를 지원하지 않습니다. |
| `headingLevel` | heading level을 지정할 수 없습니다. |
| DOM ARIA 연결 | `aria-controls`, `aria-labelledby`, `role="region"`을 지원하지 않습니다. |
| Arrow / Home / End 키 탐색 | 웹과 같은 키보드 포커스 이동을 지원하지 않습니다. |
| `size="responsive"` | `medium` 또는 `large`를 사용합니다. |
