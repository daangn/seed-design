## 웹 버전과의 차이

<Callout type="warning">
- `onClick` 대신 `bindtap`을 사용합니다.
- 선택 상태는 `accessibility-role-description="toggle button"`과 `accessibility-value`로 전달합니다.
- button과 form 속성, 키보드 focus, `asChild`는 지원하지 않습니다.
- `loading` 중에는 탭을 막고 비활성 상태로 노출합니다.
</Callout>
