`ProgressCircle`은 기본적으로 진행률 접근성 요소로 노출됩니다. `value`가 있으면 범위와 현재 값을 전달하고, 없으면 완료 시점을 알 수 없는 상태로 전달합니다. 스크린 리더 문구는 `accessibility-value`로 바꿀 수 있습니다.

`mainThreadProgress`는 PullToRefresh처럼 Main Thread에서 진행률을 갱신할 때 사용합니다. Indicator의 render props를 그대로 전달하고, 채널 하나에는 `ProgressCircle` 하나만 연결하세요. 같은 인스턴스의 `value`를 동시에 애니메이션하지 마세요.

```tsx
<ProgressCircle
  minValue={0}
  maxValue={100}
  value={40}
  accessibility-label="파일 업로드"
  accessibility-value="40% 완료"
/>
```

## 웹 버전과의 차이

- 공개 variant와 진행률 API는 웹과 같습니다.
- 웹의 ARIA 속성 대신 `accessibility-role-description`과 `accessibility-value`를 사용합니다.
- 완료 시점을 알 수 없는 상태는 엔진 애니메이션으로 원호와 둥근 끝을 회전합니다. JavaScript에서 매 프레임 스타일을 갱신하지 않습니다.
- `value`가 바뀌는 진행률 애니메이션과 `mainThreadProgress` 갱신은 Main Thread에서 처리합니다.
