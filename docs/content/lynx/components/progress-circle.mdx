## Installation

```package-install
npm install @seed-design/lynx-react
```

<Callout>
`@seed-design/lynx-css` 패키지가 peer dependency로 필요합니다.
</Callout>

## Usage

```tsx
import { ProgressCircle } from "@seed-design/lynx-react";

export function App() {
  return (
    <ProgressCircle.Root tone="brand" size="40">
      <ProgressCircle.Track />
      <ProgressCircle.Range />
    </ProgressCircle.Root>
  );
}
```

### Determinate

`minValue`, `maxValue`, `value`를 지정하면 determinate 모드로 동작합니다.

```tsx
import { ProgressCircle } from "@seed-design/lynx-react";

export function App() {
  return (
    <ProgressCircle.Root tone="brand" size="40" minValue={0} maxValue={1} value={0.5}>
      <ProgressCircle.Track />
      <ProgressCircle.Range />
    </ProgressCircle.Root>
  );
}
```
