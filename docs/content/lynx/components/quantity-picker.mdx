## Props

### `QuantityPicker`

Registry의 `QuantityPicker`는 수량 선택에 필요한 감소 버튼, 값, 증가 버튼을 함께 제공합니다.

<react-type-table path="./registry/lynx/ui/quantity-picker.tsx" name="QuantityPickerProps" />

`min`과 `max`는 필수이며 안전한 정수여야 합니다. `step`의 기본값은 `1`이고, `defaultValue`를 생략하면 `min`에서 시작합니다. `value`와 `onValueChange`를 함께 사용하면 값을 외부 상태로 제어할 수 있습니다.

### Removable

### Loading

`loading`으로 모든 action 또는 특정 action의 실행을 일시적으로 막고 loading indicator를 표시할 수 있습니다. `loading={true}`는 Decrement와 Increment 모두에 적용되며, `loading={{ increment: true }}`처럼 객체를 전달하면 해당 action만 막습니다.

  ```json doc-gen:file
  {

    "codeblock": true
  }
  ```

`disabled`, `readOnly`, `loading`은 모두 action을 실행하지 못하게 합니다. `disabled`는 두 action을 비활성화하고 접근성 상태에도 disabled를 전달합니다. `readOnly`는 수량 변경과 Remove 콜백 호출을 막지만 값을 다른 상태로 바꾸지는 않습니다. `loading`은 지정된 action만 일시적으로 막으며, 해당 action의 indicator를 표시합니다. 따라서 `removable`의 최솟값에서도 Decrement가 disabled, readOnly 또는 decrement loading이면 `onRemove`가 호출되지 않습니다.

### Form

Lynx에는 HTML `<form>`, hidden `<input>`, `FormData` 제출 모델이 없으므로 웹의 `inputProps`와 hidden input 기반 Form 예제를 제공하지 않습니다. 수량을 제출해야 할 때는 `value`와 `onValueChange`로 앱 상태를 관리한 뒤, 제출 또는 네트워크 요청을 만드는 코드에서 그 상태를 payload에 직접 넣으세요. 이 방식은 UI 표시용 `getValueText`와 서버에 보낼 raw 숫자 값을 분리할 수 있습니다.

## Accessibility

Quantity Picker의 용도를 설명하는 `accessibility-label`을 제공하세요. 이 label은 현재 수량을 표시하는 요소의 이름으로 사용되며, `getValueText`가 반환한 문자열이나 숫자는 접근성 값에도 반영됩니다.

Registry 컴포넌트는 감소, 증가, 삭제 버튼에 기본 접근성 label을 제공합니다. 문맥에 맞게 바꾸려면 `decrementAccessibilityLabel`, `incrementAccessibilityLabel`, `removeAccessibilityLabel`을 사용하세요. 특히 `removable`을 사용할 때는 삭제 대상을 알 수 있는 label을 제공해야 합니다.

`disabled`는 접근성 상태에도 반영됩니다. `readOnly`와 `loading`으로 동작을 막았다면 주변 label이나 안내 텍스트로 제한 상태를 설명하세요.

## 웹 버전과의 차이

- HTML 요소와 버튼 대신 Lynx native `<view>`와 접근성 요소를 렌더링하고 tap으로 동작합니다.
- `aria-*` 대신 `accessibility-*`와 Registry의 접근성 label props를 사용합니다.
- HTML form, hidden input, `FormData`, `inputProps`를 지원하지 않습니다. 제출할 수량은 `value`와 `onValueChange`로 관리해 요청 payload에 직접 넣으세요.
- 브라우저의 form 검증과 키보드 focus 모델이 없습니다. required 검증과 제출은 앱에서 처리합니다.
