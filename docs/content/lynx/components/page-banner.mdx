## Usage

설치한 snippet은 기본 PageBanner와 버튼, 전체 영역을 탭할 수 있는 ActionablePageBanner, 닫을 수 있는 DismissiblePageBanner를 export합니다.

```tsx
import { PageBanner } from "@/components/ui/page-banner";

export function App() {
  return <PageBanner title="알림" description="새로운 소식을 확인해 보세요." />;
}
```

저수준 조합이 필요하면 `@seed-design/lynx-react`의 compound API를 직접 사용할 수 있습니다.

```tsx
import { PageBanner } from "@seed-design/lynx-react";

export function App() {
  return (
    <PageBanner.Root tone="informative">
      <PageBanner.Content>
        <PageBanner.Body>
          <PageBanner.Title>알림</PageBanner.Title>
          <PageBanner.Description>새로운 소식을 확인해 보세요.</PageBanner.Description>
        </PageBanner.Body>
      </PageBanner.Content>
    </PageBanner.Root>
  );
}
```

## Tones and Variants

`tone`은 `neutral`, `informative`, `positive`, `warning`, `critical`, `magic`을 지원합니다. `variant`는 `weak`, `solid`를 지원합니다. 기본값은 `neutral`, `weak`입니다.

`tone="magic"`은 `variant="weak"` 조합으로만 사용하세요.

## Web Version Differences

| 영역 | React Web | Lynx |
| --- | --- | --- |
| Native element | `div`, `span`, `button` | `view`, `text` |
| Event | `onClick` | `bindtap`, `main-thread:bindtap` |
| Accessibility | HTML semantics, ARIA | `accessibility-*` |
| Polymorphism | `asChild` 지원 | 미지원 |
| Root pressed feedback | 배경과 content scale | 배경만 적용 |
| Focus | 웹 focus ring | 미지원 |

Lynx의 Button과 CloseButton은 눌리는 동안 scale feedback을 적용합니다. actionable Root는 button trait를 기본으로 사용하며, CloseButton은 접근 가능한 이름이 필요합니다.

## Unsupported Lynx Features

- `asChild`: Lynx에는 DOM Slot 기반 다형 렌더링이 없습니다.
- 웹 focus ring과 키보드 focus 동작: Lynx는 웹의 focus 모델을 사용하지 않습니다.
- actionable Root의 content scale feedback: Lynx에서는 tone과 variant에 맞는 pressed 배경만 적용합니다.
- HTML attribute와 ARIA prop: 대응하는 Lynx native prop과 `accessibility-*`를 사용하세요.
