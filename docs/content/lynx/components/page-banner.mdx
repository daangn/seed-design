```tsx

  return <PageBanner title="알림" description="새로운 소식을 확인해 보세요." />;

```


## Examples

### Extending to Safe Area

`extendSafeAreaX`를 지정하면 배경이 좌우 safe area까지 확장되고, 아이콘·글자·버튼은 기존 위치에 남습니다. 배너 내용의 눌림 피드백과 tone별 배경은 유지됩니다. 기본값은 `false`입니다.

`Box pl="safeArea" pr="safeArea"`처럼 좌우 inset을 이미 확보한 컨테이너 바로 안에서 사용하세요. inset을 확보하지 않은 곳에 적용하면 화면 밖으로 넘칠 수 있습니다.

배너와 이 컨테이너 사이에 다른 레이아웃을 두면 해당 레이아웃에 `style={{ overflow: "visible" }}`을 지정해야 확장한 배경이 잘리지 않습니다.

## Action and Dismiss

전체 배너를 액션으로 사용하려면 `ActionablePageBanner`에 `bindtap`과 `accessibility-label`을 전달하세요. 닫기 상태를 직접 관리하려면 `DismissiblePageBanner`의 `open`과 `onDismiss`를 사용합니다.

## Web Version Differences

- 탭 이벤트는 `onClick` 대신 `bindtap` 또는 `main-thread:bindtap`으로 받습니다.
- 접근성은 HTML 의미 요소와 ARIA 대신 Lynx의 `accessibility-*` 속성을 사용합니다.
- CloseButton은 Root의 직접 자식이나 Fragment 안에 두세요. 다른 컴포넌트로 감싸면 배너 본문과 함께 눌림 피드백이 적용됩니다.

## Unsupported Lynx Features

- `asChild`를 지원하지 않습니다.
- 웹의 focus ring과 HTML 속성은 지원하지 않습니다. 대응하는 Lynx native 속성을 사용하세요.
