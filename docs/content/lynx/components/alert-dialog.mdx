## Usage

```tsx
import { ActionButton } from "@seed-design/lynx-react";
import {
  AlertDialogAction,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogRoot,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog";

export function App() {
  return (
    <AlertDialogRoot>
      <AlertDialogTrigger>
        <ActionButton variant="neutralSolid">열기</ActionButton>
      </AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>주의</AlertDialogTitle>
          <AlertDialogDescription>이 작업은 되돌릴 수 없습니다.</AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogAction variant="neutralWeak">취소</AlertDialogAction>
          <AlertDialogAction variant="neutralSolid">확인</AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialogRoot>
  );
}
```

`AlertDialogTrigger`는 자식을 native `view`로 감쌉니다. 문자열 children에서 접근성 이름을 만들며, `accessibility-label`을 직접 지정하면 그 값을 사용합니다. raw `<text>`처럼 이름을 만들 수 없는 자식에는 이름을 명시하세요.

`AlertDialogAction`은 탭하면 Alert Dialog를 닫지만, `disabled` 또는 `loading` 상태에서는 닫지 않습니다. 사용자의 확인이 필요한 흐름을 위해 Backdrop 탭으로는 닫히지 않습니다.

## 웹 버전과의 차이

- `onOpenChange`는 변경된 boolean 값만 전달합니다. 닫힌 원인이 필요하면 Trigger와 action의 이벤트 핸들러에서 별도 상태로 기록하세요.
- Backdrop 탭과 ESC 키로 닫히지 않습니다. 필요한 닫기 흐름은 버튼과 controlled 상태로 구성하세요.
- Trigger는 자식을 native `view`로 감싸며 `asChild`를 제공하지 않습니다.
- DOM ref forwarding과 웹의 자동 focus 관리 API를 제공하지 않습니다.
- `container`와 `overlayLevel`로 native overlay의 위치와 표시 순서를 지정합니다.
- `ResponsivePair`는 제공하지 않습니다. Footer 안에서 action의 방향과 간격을 직접 지정하세요.
