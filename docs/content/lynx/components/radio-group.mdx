## Usage

```tsx
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";

export function ContactMethod() {
  return (
    <RadioGroup
      label="선호하는 연락 방법"
      indicator="필수"
      description="연락받을 방법을 선택해 주세요."
      defaultValue="chat"
    >
      <RadioGroupItem value="chat" label="채팅" />
      <RadioGroupItem value="phone" label="전화" />
    </RadioGroup>
  );
}
```

`invalid`가 `true`이면 `description` 대신 `errorMessage`를 표시합니다. `weight`, `size`, `tone`은 `RadioGroupItem`에 지정하며, 이전 버전에서 그룹에 지정한 값도 각 항목으로 옮겨야 합니다. Registry `RadioGroup`은 React와 같이 `required`와 `readOnly`를 받지 않습니다.

## 접근성

`RadioGroup`의 문자열 `label`은 그룹의 접근성 이름으로도 사용됩니다. `RadioGroupItem`의 문자열 `label`은 항목 이름으로 연결되며 선택 상태와 비활성 상태도 전달됩니다.

raw `<text>`를 사용하거나 항목에 텍스트가 없으면 `accessibility-label`을 지정하세요. raw `<text>`의 정적 텍스트는 접근성 이름을 만들 수 없습니다.

## Scale Feedback

Lynx `RadioGroupItem`은 누르는 동안 `Radiomark`를 줄입니다. 콘텐츠를 축소하는 SEED 컴포넌트 안에서는 이 효과를 생략합니다. React의 `--seed-radiomark-feedback-scale` CSS 변수는 제공하지 않습니다.

## 웹 버전과의 차이

<Callout type="warning">

- `invalid` 상태에서는 `description`을 제외하고 `errorMessage`만 화면과 접근성 트리에 표시합니다.
- 사용자 지정 아이콘은 Lynx 단색 아이콘 컴포넌트를 사용해야 합니다. raw `<svg>` 아이콘은 지원하지 않습니다.
- 값 변경은 `onChange`가 아닌 `onValueChange(value: string)`로 받습니다.
- HTML `<label>`과 `<input type="radio">` 대신 네이티브 `<view>`와 `<text>`를 렌더링합니다.
- `RadioGroupItem`은 `RadioGroup` 안에서, `Radiomark`는 해당 항목 안에서 사용해야 합니다.

</Callout>

사용자 지정 아이콘 패키지는 Registry 기본 설치에 포함되지 않습니다.

```sh
bun add @karrotmarket/lynx-monochrome-icon@^1.20.0
```

## Lynx 미지원 기능

현재 Lynx 플랫폼 제약으로 다음 기능이 지원되지 않습니다.

### 런타임 모델 차이로 제외

| 기능 | 웹 대응 | 설명 |
|------|---------|------|
| React Hook Form | HTML form 라이브러리 | `value`와 `onValueChange` 및 앱 수준 제출 로직으로 대체 |
| `RadioGroupItemHiddenInput` | `<input type="radio">` | Lynx에 HTML form 제출 모델 없음 |
| `name` | native form field name | Lynx에 native form 제출 모델 없음 |
| `focus` / `focusVisible` | 키보드 포커스 | Lynx에 키보드 포커스 개념 없음 |
| `onChange` (raw DOM event) | `React.ChangeEvent` | 의미 없음. `onValueChange`로 대체 |
