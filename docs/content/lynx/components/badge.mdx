## Usage

```tsx
import { Badge } from "@/components/ui/badge";

export function App() {
  return <Badge>라벨</Badge>;
}
```

## 웹 버전과의 차이

<Callout type="warning">
Lynx Badge는 React Badge와 같은 `size`, `variant`, `tone` 표면을 사용하지만, 네이티브 `<view>` root와 `<text>` label을 렌더링합니다. HTML span attribute나 `asChild`는 제공하지 않습니다.
</Callout>
