
## Usage

```tsx
import { Badge } from "@/components/ui/badge";

export function App() {
  return <Badge>라벨</Badge>;
}
```

<Callout type="warning">
HTML 속성 대신 Lynx native 접근성 속성과 이벤트를 사용합니다.

Action은 기본적으로 버튼으로 노출됩니다. 접근성 속성을 덮어쓸 때는 버튼으로 읽히는지 확인하세요.
</Callout>
