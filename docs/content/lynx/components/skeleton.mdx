## 웹 버전과의 차이

- 접근성 트리에서 숨겨지는 장식 요소입니다.
- `height`에는 반응형 값이 아닌 단일 값만 전달할 수 있습니다.
- 웹의 `asChild`는 지원하지 않습니다.
