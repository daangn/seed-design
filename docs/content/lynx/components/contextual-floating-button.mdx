## 웹 버전과의 차이

- `onClick` 대신 `bindtap` 또는 `main-thread:bindtap`을 사용합니다.
- `aria-label` 대신 `accessibility-label`을 사용합니다. `disabled` 또는 `loading` 상태는 비활성 버튼으로 알립니다.
- 웹 SVG 대신 Lynx icon을 `PrefixIcon` 또는 `Icon` slot에 전달합니다.
- Lynx에서는 loading 중 탭을 차단합니다.
- 버튼 자체의 `transform`을 덮어쓰지 마세요. 위치 조정이 필요하면 바깥 wrapper에 적용하세요.
