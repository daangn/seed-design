## 패키지 설치

Lynx 환경에서 SEED Design을 사용하려면 두 가지 패키지를 설치해야 합니다.

```package-install
npm install @seed-design/lynx-css @seed-design/lynx-react
```

- `@seed-design/lynx-css`: Lynx 환경에 최적화된 CSS 변수와 컴포넌트 스타일을 제공합니다.
- `@seed-design/lynx-react`: Lynx 환경에서 사용할 수 있는 React 컴포넌트를 제공합니다.

<Callout>
`@seed-design/lynx-react`는 `@seed-design/lynx-css`를 peer dependency로 필요로 합니다. 두 패키지를 함께 설치해야 합니다.
</Callout>
