<Steps>
<Step>

### 의존성 설치

필요한 의존성들을 설치해요.

```package-install
@seed-design/lynx-react @seed-design/lynx-css
```

<Callout>
`@seed-design/lynx-react`는 `@seed-design/lynx-css`를 peer dependency로 필요로 합니다. 두 패키지를 함께 설치해야 합니다.
</Callout>

</Step>

<Step>

### base.css import하기

```ts title="src/index.tsx"
import "@seed-design/lynx-css/base.css";
```

</Step>

<Step>

### seed-design.json 생성하기

<Tabs items={['CLI로 추가', '직접 추가']}>
<Tab value="CLI로 추가">
<Steps>
<Step>

### init 명령어 입력하기

</Step>
```package-install
npx @seed-design/cli@latest init
```

<Step>

### seed-design 설정

`@lynx-js/react`가 설치되어 있으면 프레임워크가 자동으로 Lynx로 감지돼요.

```sh
◇  TypeScript를 사용중이신가요?
│  Yes
│
◇  어떤 프레임워크를 사용하시나요?
│  Lynx
│
◇  seed-design 폴더 경로를 입력해주세요. (기본값은 프로젝트 루트에 생성됩니다.)
│  ./seed-design
│
◇  개선을 위해 익명 사용 데이터를 수집할까요?
│  Yes
```

</Step>
</Steps>
</Tab>

<Tab value="직접 추가">

아래 파일을 프로젝트 루트에 생성해주세요.

```json title="seed-design.json"
{
  "tsx": true,
  "framework": "lynx",
  "path": "./seed-design"
}
```

</Tab>
</Tabs>

</Step>

<Step>

### tsconfig.json 설정하기

<Callout>

위에서 설정한 [seed-design.json path](/react/getting-started/cli/configuration#path)의 경로와 동일해야 해요.

</Callout>

</Step>

```json title="tsconfig.json"
{
  "compilerOptions": {
    // ... your options
    "paths": {
      // [!code highlight]
      "seed-design/*": [
        // [!code highlight]
        "./seed-design/*"
      ]
    }
  }
}
```

<Step>

### Lynx 피쳐 플래그 설정하기

SEED Design 컴포넌트가 Lynx에서 정상 동작하려면 `pluginLynxConfig`로 피쳐 플래그를 설정해야 해요.

```package-install
@lynx-js/config-rsbuild-plugin
```

```ts title="lynx.config.ts"
import { pluginLynxConfig } from "@lynx-js/config-rsbuild-plugin";

export default defineConfig({
  plugins: [
    // ... 기존 플러그인들
    pluginLynxConfig({
      enableCSSSelector: true,
      enableCSSInvalidation: true,
      enableCSSInheritance: true,
      enableCSSInlineVariables: true,
      enableCSSStrictMode: true,
      enableTextRefactor: true,
      fontScaleEffectiveOnlyOnSp: true,
      enableFixedNew: true,
      enableFlexBasisZeroPercent: true,
    }),
  ],
});
```

<Callout>
각 플래그의 역할과 상황별 추가 설정은 [Feature Flags](/lynx/feature-flags)에서 확인하세요.
</Callout>

</Step>

<Step>

### 컴포넌트를 한번 사용해볼까요?

```package-install
npx @seed-design/cli@latest add ui:action-button
```

</Step>

<Step>

### (선택) lynx-console 설치하기

[lynx-console](https://github.com/daangn/lynx-console)은 Lynx 앱 안에서 콘솔 로그, 네트워크, 성능 지표를 확인할 수 있는 개발자 도구예요.

```package-install
lynx-console
```

앱 entry에서 초기화하고 컴포넌트를 추가해주세요.

```tsx title="src/App.tsx"
import { initLogMonitor, initNetworkMonitor, initPerformanceMonitor } from "lynx-console/setup";
import LynxConsole from "lynx-console";

initLogMonitor();
initNetworkMonitor();
initPerformanceMonitor();

function App() {
  return (
    <view>
      {/* your app */}
      <LynxConsole />
    </view>
  );
}
```

자세한 사용법은 [lynx-console GitHub](https://github.com/daangn/lynx-console)을 참고하세요.

</Step>

</Steps>
