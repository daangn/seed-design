## 개요

SEED는 라이트 모드와 다크 모드를 지원하는 테마 시스템을 제공합니다.
[Vanilla Extract](/lynx/getting-started/styling/vanilla-extract) 또는
[Tailwind CSS v4](/lynx/getting-started/styling/tailwind-css-4) 중 어떤 방식을 사용하더라도
아래의 루트 테마 설정을 공통으로 적용합니다.

웹 환경에서는 `data-*` 속성 셀렉터를 통해 테마를 제어하지만, Lynx에서는 `data-*` 속성 셀렉터를 지원하지 않기 때문에 CSS 클래스 이름을 사용합니다.
스타일시트에 선언된 CSS 커스텀 프로퍼티(변수)는 Lynx에서도 상속되므로, 루트 요소에 설정된 테마 토큰이 하위 요소에 자연스럽게 적용됩니다.

## 전역 설정 적용

`@seed-design/lynx-react`의 `getSeedClassName()` 함수를 사용하여 `<page>` 요소에 테마 클래스를 설정합니다.

```tsx
import { root } from "@lynx-js/react";
import { getSeedClassName } from "@seed-design/lynx-react";

function Root() {
  return (
    <page className={getSeedClassName({ colorMode: "system" })}>
      <App />
    </page>
  );
}

root.render(<Root />);
```

`getSeedClassName()`은 `colorMode` 옵션에 따라 `seed-user-color-scheme-light` 또는 `seed-user-color-scheme-dark` 클래스를 반환합니다.

### `colorMode` 옵션

| `colorMode` 설정 | 기기 설정 | 적용되는 테마 클래스 |
|---|---|---|
| `system` (기본값) | 라이트 모드 | `seed-user-color-scheme-light` |
| `system` | 다크 모드 | `seed-user-color-scheme-dark` |
| `light-only` | (무관) | `seed-user-color-scheme-light` |
| `dark-only` | (무관) | `seed-user-color-scheme-dark` |

`system`으로 설정하면 `lynx.__globalProps.theme` 값을 읽어 기기의 다크 모드 설정을 따릅니다.

## 테마 클래스 이해하기

SEED의 Lynx 테마 시스템은 두 종류의 클래스 이름을 사용합니다.

### `seed-user-color-scheme-*` (루트 레벨 테마)

`getSeedClassName()`이 `<page>` 요소에 적용하는 클래스입니다. 현재 해석(resolve)된 테마를 나타냅니다.

- `seed-user-color-scheme-light`: 라이트 모드가 적용됨
- `seed-user-color-scheme-dark`: 다크 모드가 적용됨

### `seed-color-mode-*-only` (자식 레벨 오버라이드)

특정 요소와 그 하위 요소에 테마를 강제 적용할 때 사용하는 클래스입니다.

- `seed-color-mode-light-only`: 해당 영역을 라이트 모드로 강제
- `seed-color-mode-dark-only`: 해당 영역을 다크 모드로 강제

## 작동 원리

SEED CSS는 클래스 이름의 조합을 통해 적절한 색상 토큰을 적용합니다:

```css
/* 라이트 모드가 적용되는 경우 */
:root,
:root.seed-user-color-scheme-light,
:root.seed-color-mode-light-only,
.seed-color-mode-light-only {
  /* 라이트 모드 색상 토큰 */
}

/* 다크 모드가 적용되는 경우 */
:root.seed-user-color-scheme-dark,
:root.seed-color-mode-dark-only,
.seed-color-mode-dark-only {
  /* 다크 모드 색상 토큰 */
}
```

- `:root` 단독 셀렉터는 기본값으로 라이트 모드 토큰을 적용합니다.
- `:root.seed-user-color-scheme-*` 셀렉터는 루트 요소에 설정된 전역 테마를 처리합니다.
- `.seed-color-mode-*-only` 셀렉터는 하위 요소에서의 테마 오버라이드를 처리합니다. `:root` 접두사가 있는 셀렉터와 없는 셀렉터 모두 포함되어 있어, 루트 요소와 자식 요소 모두에서 동작합니다.

## Vanilla Extract와 함께 사용하기

`@seed-design/lynx-css/base.css`를 불러온 뒤, `.css.ts`에서 `@seed-design/lynx-css/vars`의 토큰을 참조하세요.
토큰은 CSS 변수 참조이므로 색상 값을 직접 지정하지 않아도 루트 테마에 따라 색상이 바뀝니다.

```ts title="Content.css.ts"
import { vars } from "@seed-design/lynx-css/vars";
import { style } from "@vanilla-extract/css";

export const content = style({
  backgroundColor: vars.$color.bg.layerDefault,
});

export const label = style({
  color: vars.$color.fg.neutral,
});
```

```tsx title="Content.tsx"
import * as styles from "./Content.css";

export function Content() {
  return (
    <view className={styles.content}>
      <text className={styles.label}>테마에 반응하는 텍스트</text>
    </view>
  );
}
```

플러그인과 CSS import 설정은 [Vanilla Extract 가이드](/lynx/getting-started/styling/vanilla-extract)를 참고하세요.

## Tailwind CSS와 함께 사용하기

Tailwind CSS v4를 선택했다면 `@seed-design/tailwind4-theme`으로 SEED 토큰을 사용할 수 있습니다. 기존 v3 프로젝트에서는 `@seed-design/tailwind3-plugin`을 사용합니다.

```tsx
// 테마에 따라 자동으로 색상이 변경됩니다
<view className="bg-bg-layer-default">
  <text className="text-fg-neutral">테마에 반응하는 텍스트</text>
</view>
```

v3 클래스는 `var(--seed-color-*)`를 직접 참조합니다. v4 theme은 루트에 `--color-*` alias를 선언하고 utility에서 이를 참조합니다. 루트 `<page>`의 테마와 함께 사용하세요.

<Callout type="warning">
  v4에서는 하위 요소에 `seed-color-mode-dark-only` 등을 적용해도 루트에서
  정의한 Tailwind alias가 해당 영역의 SEED 토큰을 다시 참조하지 않을 수 있습니다.
  이 경우 Tailwind utility와 직접 토큰 참조의 색상이 달라집니다.
  현재 안내하는 v4 구성은 루트 테마 기준이며 하위 영역 덮어쓰기는 지원 범위에 포함하지 않습니다.
  [v4 설정과 제한사항](/lynx/getting-started/styling/tailwind-css-4)을 함께 확인하세요.
</Callout>

기기 모드 전환을 반영하려면 host가 변경된 theme global prop을 전달하고 앱이 루트 클래스를 갱신해야 합니다.
설정 후 실제 host에서 라이트 → 다크 → 라이트 전환을 확인하세요.

## 일부 요소에만 테마 오버라이드하기

아래는 직접 SEED 토큰 참조 또는 Tailwind v3에 해당하는 사용법입니다. 위의 v4 제한을 함께 확인하세요.

특정 영역에만 다른 테마를 적용하고 싶을 때는 해당 요소에 `seed-color-mode-light-only` 또는 `seed-color-mode-dark-only` 클래스를 추가합니다.

```tsx
function MyComponent() {
  return (
    <view>
      {/* 현재 전역 테마를 따르는 영역 */}
      <text>전역 테마가 적용됩니다</text>

      {/* 다크 모드 강제 적용 영역 */}
      <view className="seed-color-mode-dark-only">
        <text>다크 모드가 강제 적용됩니다</text>
      </view>

      {/* 라이트 모드 강제 적용 영역 */}
      <view className="seed-color-mode-light-only">
        <text>라이트 모드가 강제 적용됩니다</text>
      </view>
    </view>
  );
}
```

오버라이드된 영역 내부의 모든 하위 요소는 CSS 커스텀 프로퍼티 상속을 통해 해당 테마의 토큰을 사용하게 됩니다.

## Web과의 비교

| | Web (React) | Lynx |
|---|---|---|
| 테마 제어 방식 | `data-*` 속성 셀렉터 | CSS 클래스 이름 |
| 전역 테마 설정 | `data-seed-color-mode` + `data-seed-user-color-scheme` 속성을 `<html>`에 적용 | `seed-user-color-scheme-*` 클래스를 `<page>`에 적용 |
| 테마 오버라이드 | `data-seed-color-mode="light-only"` 또는 `"dark-only"` 속성 | `seed-color-mode-light-only` 또는 `seed-color-mode-dark-only` 클래스 |
| 토큰 상속 | CSS 커스텀 프로퍼티 상속 | CSS 커스텀 프로퍼티 상속 (동일) |
| 테마 설정 방법 | 번들러 플러그인이 `<script>` 주입 | `getSeedClassName()` 함수로 className 직접 설정 |
