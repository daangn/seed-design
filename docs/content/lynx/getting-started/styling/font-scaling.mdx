이 문서는 SEED Lynx의 폰트 스케일링 적용 방법을 다룹니다. Lynx는 WebView와 다른 렌더링 환경이며, React 웹용 `fontScaling` 옵션이나 DOM 속성을 사용하지 않습니다. 글자가 커질 때의 정보·배치 기준은 [Font Scaling 패턴](/patterns/font-scaling)을 참고하세요.

## 배율 설정 확인하기

[Installation](/lynx/getting-started/installation)의 `pluginLynxConfig` 설정에서 `fontScaleEffectiveOnlyOnSp: true`를 유지합니다. 이 설정을 켜면 글자 크기와 줄 높이 등 폰트 관련 길이 중 `sp`로 지정한 값에만 사용자 글자 배율을 적용합니다. 여백이나 아이콘 크기까지 모두 확대하는 옵션은 아닙니다.

이 옵션 자체가 OS 설정을 읽거나 앱의 확대 정책을 정하는 것은 아닙니다. Lynx 화면을 실행하는 호스트 앱에서 실제 배율을 확인하고, 사용자가 글자 크기를 바꾼 뒤에도 화면에 반영되는지 살펴봅니다. 플래그의 기본값과 지원 범위는 [Feature Flags](/lynx/getting-started/feature-flags#텍스트와-레이아웃)를 참고하세요.

## SEED 텍스트 스타일 적용하기

SEED Lynx는 Dynamic 글자 크기·줄 높이 토큰을 `sp`로 제공합니다. 사용자 글자 크기에 대응할 텍스트에는 Dynamic 스타일을 사용합니다. `fontScaleEffectiveOnlyOnSp: true`로 설정하면 Static 토큰은 사용자 글자 배율에 따라 확대되지 않습니다.

[Text](/lynx/foundation/typography/text)의 `textStyle`로 글자 크기와 줄 높이가 조합된 스타일을 적용할 수 있습니다.

```tsx
import { Text } from "@seed-design/lynx-react";

<Text textStyle="t5Regular">사용자 글자 크기에 대응하는 본문</Text>
```

크기를 개별 지정할 때도 글자 크기와 줄 높이를 함께 확인합니다. `Text`에 `fontSize`만 지정하면 같은 단계의 줄 높이 토큰을 함께 사용합니다. 자세한 props는 [Text 문서](/lynx/foundation/typography/text)를 참고하세요.

Static 스타일을 사용할 때는 사용자가 해당 글자를 키워 읽을 수 없다는 점을 고려합니다. 글자가 넘친다면 먼저 줄바꿈·영역 확장·배치 변경을 검토합니다. 예외가 필요하면 적용 대상과 이유, 정보를 읽을 수 있는 다른 방법을 명시합니다.

## rem과 사용자 배율 구분하기

SEED Lynx의 `base.css`는 루트 글자 크기를 16px로 설정합니다. `rem`으로 지정한 크기는 이 루트 글자 크기를 기준으로 계산합니다. 사용자 글자 배율인 `fontScale`을 반영하려면 아래 안내에 따라 Dynamic 타이포그래피를 사용합니다.

사용자 배율에 대응할 텍스트에는 SEED Dynamic 타이포그래피를 사용합니다. Tailwind의 단위와 유틸리티 적용은 [Tailwind CSS v4](/lynx/getting-started/styling/tailwind-css-4#rem-기준-크기) 또는 [v3](/lynx/getting-started/styling/tailwind-css-3#rem-기준-크기)를 참고하세요.

## iOS·Android에서 확인하기

같은 SEED 토큰을 사용해도 OS 설정과 호스트 앱, Lynx 엔진에 따라 실제 표시 결과가 달라질 수 있습니다. WebView의 `textZoom`이나 Android 네이티브의 확대 계산을 Lynx에도 그대로 대입하지 않습니다.

| 환경 | 확인할 항목 |
| --- | --- |
| iOS 앱 | 시스템 글자 크기를 바꾼 뒤 Lynx 텍스트에 반영되는지, 화면 복귀 시 갱신되는지 확인합니다. 글자가 커져도 줄바꿈이 자연스럽고 버튼을 누를 수 있는지 확인합니다. |
| Android 앱 | 시스템 글자 크기별 실제 텍스트와 줄 높이를 확인합니다. 네이티브 화면과 같은 배율로 표시되는지, 설정을 바꾸고 돌아왔을 때 글자 크기가 갱신되는지, 글자가 잘리지 않는지 살펴봅니다. |

기본 크기·작은 크기·중간 단계·가장 큰 설정을 비교하고, OS 버전·호스트 앱·Lynx 엔진 버전·SEED 패키지 버전을 함께 기록합니다. 시스템 글자 크기를 바꿨을 때의 동작은 실제 앱에서 검증합니다. 브라우저의 Lynx 미리보기만으로는 이 동작을 확인할 수 없습니다.
