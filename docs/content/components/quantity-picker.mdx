## Properties

Quantity Picker는 Size, State, Value, Removable 속성을 제공합니다.

### Size

Quantity Picker는 Small, Medium, Large 크기를 제공합니다.

### State

Quantity Picker는 Enabled, Disabled, Error 상태를 제공합니다.

### Value

Value는 Min, InRange, Max(~99), Max(~999) 상태로 구성됩니다.

### Removable

Removable은 False와 True를 제공합니다.
