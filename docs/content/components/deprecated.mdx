아래 컴포넌트는 더 이상 사용되지 않습니다. 대체 컴포넌트를 사용하세요.

| 컴포넌트              | 대체 컴포넌트                                                        |
| --------------------- | -------------------------------------------------------------------- |
| Action Chip           | [Chip](/components/chip)의 Button을 `variant="solid"`로 사용         |
| Action Sheet          | [Menu Sheet](/components/menu-sheet)                                 |
| Control Chip          | [Chip](/components/chip)의 Toggle 또는 Button                        |
| Error State           | [Result Section](/components/result-section)                         |
| Extended Action Sheet | [Menu Sheet](/components/menu-sheet)                                 |
| Extended FAB          | [Contextual Floating Button](/components/contextual-floating-button) |
| FAB                   | [Contextual Floating Button](/components/contextual-floating-button) |
| Inline Banner         | [Page Banner](/components/page-banner)                               |
| Link Content          | [Action Button](/components/action-button)을 `variant="ghost"`로 사용 |
