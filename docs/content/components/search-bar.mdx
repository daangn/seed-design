## Anatomy

<FigmaImage
  id="355:8753"
  alt="Search Bar의 Anatomy. Search Input, Search Input Clear, Close Button과 Back Button으로 구성됩니다."
/>

Search Bar는 Search Input, Back Button, Close Button을 조합해 제공하며, Search Input만 따로 사용하는 것은 권장하지 않습니다.

## Properties

### Stack

<FigmaImage
  id="355:8769"
  alt="Search Bar의 Use Stack 속성 - 꺼진 경우 Search Input과 닫기 버튼만, 켜진 경우 Back Button이 함께 표시됩니다."
/>

Search Bar는 검색 플로우에서 네비게이션 기능을 제공하기 위해 Use Stack 속성으로 Back Button을 표시할 수 있습니다. Back Button은 검색 플로우에서 네비게이션 동작을 제공하는 경우에만 사용해야 합니다.

### Search Input State

<FigmaImage
  id="355:8788"
  alt="Search Input의 Filled, Focused 조합 - 플레이스홀더만 있는 상태, 포커스된 빈 상태, 값이 입력된 상태, 포커스된 입력 상태"
/>

Search Input은 Filled 상태로 검색어 입력 여부를 표현하며, Focused 상태도 함께 제공합니다.

Search Bar는 [Top Navigation](/components/top-navigation)과 함께 사용하지 않고 단독으로 화면 최상단에 배치하는 것을 권장합니다. [Tabs](/components/tabs) 같은 다른 요소와 조합할 수도 있으며, 이때도 Search Bar는 상단 Fixed 영역에 고정하고 Content만 Scroll되도록 하는 것을 권장합니다.

<FigmaImage

<FigmaImage

  alt="n Depth에서 Back Button을 클릭했는데 최초 진입점(Root)으로 이동하는 예시"

Stack을 사용하면 검색 플로우에 Back Button과 Close Button이 항상 함께 표시되어, 사용자가 이전에 검색한 결과 페이지를 다시 확인할 수 있습니다.

- **Back Button:** 이전 Depth로 이동합니다.
- **Close Button:** 현재 Depth와 상관없이 검색 화면을 닫습니다.

**Back Button을 Close Button처럼 사용하지 않도록 주의해주세요.**

### 매우 긴 검색어를 입력한 경우

<FigmaImage
  id="355:9094"
  alt="입력한 검색어가 Search Input 너비보다 길어진 예시"
/>

Search Input 사용 시 긴 검색어를 입력해도 줄바꿈이 발생하지 않아요.

### 검색하기

<FigmaImage
  id="355:9101"
  alt="검색 중 OS Keyboard의 Submit 버튼을 누르면 Keyboard가 사라지고 검색 결과 화면이 표시되는 예시"
/>

OS Keyboard에서 Submit 버튼을 누르면 입력된 검색어로 검색 결과가 화면에 표시되고 OS Keyboard는 사라집니다.

### Keyboard

<FigmaImage id="355:9155" alt="OS별 권장 Keyboard - iOS와 Android" />

Search Input에 포커스되면 검색어를 제출할 수 있는 OS Keyboard를 사용해야 하며, Submit 버튼에는 OS에서 권장하는 스타일을 적용해야 합니다.

<FigmaImage
  id="355:9169"
  alt="검색 중 Content 빈 영역을 탭하거나 스크롤하면 Keyboard가 내려가고 포커스가 해제되는 예시"
/>

검색 중에 Content의 빈 영역을 탭하거나 스크롤하면 Keyboard가 내려가고 Search Input의 포커스가 해제됩니다.

### 검색어 지우기

<FigmaImage
  id="355:9235"
  alt="Clear Button을 누르면 검색어가 지워지고 포커스가 유지된 채 플레이스홀더가 표시되는 예시"
/>

Search Input에 검색어가 입력되어 있으면 Clear Button으로 지울 수 있습니다. Input에 포커스된 상태였다면 검색어를 지운 뒤에도 포커스를 유지해야 합니다.
