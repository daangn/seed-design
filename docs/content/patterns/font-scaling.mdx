## 폰트 스케일링 이해하기

폰트 스케일링은 사용자가 설정한 글자 크기에 맞춰 화면의 텍스트 크기를 조절하는 기능입니다. **글자가 커져도 필요한 정보를 읽고 같은 작업을 완료할 수 있어야 합니다.**

이 문서는 iOS·Android 앱과 앱 내 WebView를 다룹니다. 일반 웹사이트의 브라우저 확대는 [웹 콘텐츠의 텍스트 크기 조정 기준](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)을 참고합니다.

### 용어 구분하기

| 용어 | 의미 |
| --- | --- |
| 타이포그래피 스케일 | 제목·본문 등에 사용하는 기본 글자 크기의 체계입니다. 사용자 설정에 따른 확대와 구분합니다. |
| 폰트 스케일링 | 사용자가 설정한 글자 크기에 맞춰 화면의 텍스트 크기를 조절하는 기능입니다. |
| 사용자 글자 크기 설정 | OS에서 사용자가 선택한 크기 단계입니다. 모든 텍스트에 곱하는 하나의 배율을 뜻하지는 않습니다. |
| 실제 적용 크기·배율 | 화면에 표시되는 글자 크기와, 기본 크기에 비해 얼마나 커지거나 작아졌는지를 나타내는 비율입니다. |
| 확대 적용 범위 | 사용자 설정에 따라 글자를 키우거나 줄일 수 있는 범위입니다. 크기를 제한한다면 어떤 텍스트에 누가 설정한 제한인지 확인합니다. |
| Static 텍스트 스타일 | 사용자의 글자 크기 설정이 바뀌어도 같은 크기를 유지하는 SEED 스타일입니다. |
| 화면 확대 | 텍스트뿐 아니라 화면을 확대하는 기능입니다. 폰트 스케일링과 별도로 확인합니다. |

### 화면 전체를 확대하는 것과 다릅니다

글자가 커지면 같은 너비 안에서 줄바꿈이 늘어나고, 내용을 모두 담으려면 더 많은 높이가 필요합니다. 이때 사진과 여백까지 같은 비율로 키울 필요는 없습니다.

## SEED로 적용하기

SEED는 글자 크기와 줄 높이 토큰, 이를 조합한 텍스트 스타일을 제공합니다. 크기와 줄 높이를 함께 적용하고, 글자가 커졌을 때 이를 담는 영역과 배치도 조정합니다. 토큰의 구성은 [Typography](/foundations/typography)에서 확인할 수 있습니다.

같은 사용자 설정도 OS와 실행 환경에 따라 다르게 반영될 수 있습니다. 사용하는 프레임워크에 맞춰 설정 방법과 지원 범위를 확인합니다.

- [React에서 적용하기](/react/getting-started/styling/font-scaling): 앱 내 WebView의 설정과 iOS·Android별 동작
- [Lynx에서 적용하기](/lynx/getting-started/styling/font-scaling): Lynx의 배율 설정과 Dynamic·Static 텍스트 스타일

Lynx는 WebView와 다른 렌더링 환경입니다. 한 환경의 옵션이나 확대 결과를 다른 환경에도 그대로 적용하지 않습니다.

## 적용 범위와 예외

### 글자 크기를 어디에서 제한하는지 확인합니다

사용자가 OS에서 선택할 수 있는 크기와 앱이 실제로 표시하는 글자 크기는 다를 수 있습니다. 앱이나 텍스트 스타일, 개별 컴포넌트에서 확대 범위를 제한할 수 있기 때문입니다. 크기를 제한해야 한다면 먼저 어느 설정에서 제한하는지 확인합니다.

확대 범위를 문서에 적을 때는 **어떤 환경의 어떤 요소에 적용하는지, 어디에서 설정하는지, 어느 버전부터 지원하는지**를 함께 설명합니다. 컴포넌트별 예외는 해당 컴포넌트 가이드에 적습니다. 한 환경의 제한값을 다른 플랫폼에도 적용되는 값으로 안내하지 않습니다.

**왼쪽: 확대 상한 미적용 · 오른쪽: 확대 상한 적용.** 데모 이미지를 편집해 확대 상한에 따른 차이를 보여줍니다. 현재 제품을 검증한 캡처가 아니며, 특정 제한값을 권장하지 않습니다.

상한을 적용하면 한 화면에 더 많은 내용을 표시할 수 있지만, 사용자가 요청한 크기보다 글자가 작게 보일 수 있습니다. 이 비교만으로 어느 쪽의 접근성이 더 좋다고 판단하지 않습니다. 큰 글자에서의 잘림과 넘침은 줄바꿈, 영역 확장, 재배치로 먼저 해결합니다.

확대를 제한해야 한다면 그 이유와 사용자가 정보를 읽고 작업을 끝낼 방법을 함께 설명합니다. 상한을 적용하더라도 글자가 잘리거나 버튼이 가려지는 문제는 해결해야 합니다.

## 크기와 배치 원칙

텍스트는 읽기 편하도록 키우고, 텍스트를 담는 영역은 내용에 맞춰 늘립니다. 사진과 여백은 역할에 맞는 크기를 유지합니다. 하나의 컴포넌트 안에서도 글자, 배경, 아이콘을 각각 살펴봅니다.

### 읽어야 하는 글자는 크기 설정을 따릅니다

본문뿐 아니라 제목, 가격, 버튼 레이블, 입력값, 도움말, 오류 메시지처럼 정보를 이해하거나 작업을 완료하는 데 필요한 글자도 확인합니다. 보조 정보라는 이유만으로 작은 크기에 고정하지 않습니다.

글자 크기에 맞춰 줄 높이도 조정합니다. 글자만 커지고 줄 높이가 그대로이면 줄 사이가 좁아지거나 글자가 겹칠 수 있습니다. SEED에서는 [Typography](/foundations/typography)의 대응하는 폰트 크기·줄 높이 토큰을 함께 사용합니다.

### 영역은 커진 내용을 담을 수 있어야 합니다

텍스트가 들어 있는 목록 행, 카드, 입력 필드, 버튼은 커진 글자가 모두 들어갈 공간이 필요합니다. 기본 글자 크기에서 맞았던 높이를 그대로 고정하면 글자가 잘리거나 다음 요소와 겹칠 수 있습니다.

- 여러 줄을 허용하는 내용은 줄바꿈에 따라 영역의 높이가 늘어나게 합니다.
- 한 줄로 읽어야 하는 값은 충분한 너비를 확보하거나 주변 요소의 배치를 바꿉니다.
- 최소 크기를 유지하면서 내용에 따라 늘어날 수 있도록 합니다.
- 영역이 늘어날 때 다음 요소도 함께 밀려나도록 배치합니다.

**커진 글자가 모두 들어가도록 영역을 늘립니다.** 버튼이나 카드의 너비와 높이에 글자 배율을 그대로 곱하지 않습니다.

### 여백과 이미지는 역할에 맞는 크기를 유지합니다

화면 여백, 요소 사이 간격, 모서리 반경, 구분선 두께, 장식 이미지를 글자 배율에 맞춰 일괄 확대하지 않습니다. 텍스트에 사용할 수 있는 공간이 과도하게 줄어들 수 있습니다.

예를 들어 사진과 설명이 나란한 목록에서는 사진 크기를 유지하면서 설명 영역과 행 높이를 늘릴 수 있습니다. 사진이 중요한 정보를 담고 있다면 사진 자체를 확대해 확인하는 방법도 별도로 고려합니다.

이미지에 포함된 글자는 텍스트 크기 설정으로 독립적으로 커지지 않습니다. 읽어야 하는 안내나 조건을 이미지 안에만 넣지 않고 텍스트로 제공합니다.

### 아이콘은 글자와의 관계를 확인합니다

하나의 규칙으로 아이콘을 모두 고정하거나 모두 확대하지 않습니다.

- 문장이나 레이블과 함께 의미를 전달하는 아이콘은 커진 글자 옆에서도 식별할 수 있는지 확인합니다. 필요하면 크기와 정렬을 함께 조정합니다.
- 단독으로 사용하는 버튼 아이콘은 눈에 보이는 크기와 실제로 누를 수 있는 영역을 각각 확인합니다. 글자가 커져도 누를 수 있는 영역이 줄거나 주변 요소와 겹치지 않아야 합니다.
- 장식 아이콘은 읽는 데 필요한 공간을 과도하게 차지하지 않도록 합니다.

아이콘이 포함된 컴포넌트는 해당 구현이 지원하는 크기와 정렬을 먼저 확인합니다. 인라인 아이콘의 확대 비율을 모든 컴포넌트에 공통으로 지정하지 않습니다.

## 공간이 부족할 때

### 줄바꿈과 배치 변경으로 공간을 확보합니다

큰 글자에서 가로 공간이 부족해지면 다음 방법을 내용의 역할에 맞게 선택합니다.

- 본문·설명: 줄바꿈과 영역의 높이 증가를 허용합니다.
- 레이블과 값: 한 행에서 읽기 어렵다면 레이블 아래에 값을 배치합니다.
- 정보와 액션: 정보가 잘리면 액션을 다음 줄로 옮겨 각각의 공간을 확보합니다.
- 여러 버튼: 가로로 나란히 두었을 때 레이블을 읽기 어렵다면 세로 배치를 검토합니다.

배치를 바꾸어도 정보의 읽는 순서와 액션의 의미를 유지합니다. 글자 크기만 보고 일률적으로 전환하기보다 화면 너비와 실제 문구가 차지하는 공간을 함께 판단합니다.

### 말줄임으로 중요한 정보를 잃지 않습니다

말줄임을 적용하기 전에 **사용자가 남은 문구만으로 내용을 이해할 수 있는지, 전체 내용을 볼 방법이 있는지**를 확인합니다.

- 금액, 수량, 거래 조건, 오류 해결 방법처럼 현재 작업에 필요한 정보는 잘리지 않도록 공간을 확보합니다.
- 목록의 미리보기처럼 상세 화면에서 전체 내용을 읽는 구조라면 말줄임 이후에도 항목을 구별하고 상세 화면에 접근할 수 있어야 합니다.
- 버튼 레이블은 실행할 작업을 알 수 있어야 합니다. 의미를 잃는 말줄임 대신 너비와 배치를 조정합니다.

긴 본문은 영역을 늘리거나 스크롤을 제공해 끝까지 읽을 수 있게 합니다. 기본 화면의 모양을 유지하기 위해 줄 수를 제한하거나 글자를 다시 줄이지 않습니다.

### 크기 고정을 레이아웃 문제의 해결책으로 사용하지 않습니다

SEED의 [Static 텍스트 스타일](/foundations/typography#스케일-텍스트-스타일)을 사용하면 사용자 설정이 바뀌어도 글자 크기를 유지할 수 있습니다. 다만 사용자가 글자를 키워 읽을 수 없으므로 적용할 대상을 신중하게 정합니다.

글자가 넘친다는 이유로 Static 스타일을 적용하기 전에 줄바꿈, 영역 확장, 배치 변경을 검토합니다. 확대를 제한하는 예외가 필요하다면 사용자가 해당 정보를 읽고 기능을 사용할 방법까지 함께 검토합니다.

## 상황별 확인

### 입력 화면

레이블뿐 아니라 입력값, 도움말, 오류 메시지까지 확인합니다. 오류 메시지가 나타나도 다음 필드나 제출 버튼과 겹치지 않아야 합니다.

한 줄 입력은 입력 중인 위치를 확인할 수 있어야 하고 여러 줄 입력은 내용이 늘어날 때의 높이와 스크롤 동작을 확인합니다. 키보드가 열린 상태에서도 입력 위치와 오류 안내에 접근할 수 있어야 합니다.

### 칩과 탭

레이블이 커져도 선택지를 구별하고 선택할 수 있어야 합니다. 칩을 여러 줄로 배치하거나 탭의 가로 스크롤을 활용할 수 있습니다. 사용하는 컴포넌트가 해당 배치를 지원하는지 먼저 확인합니다.

가로 스크롤로 처음과 마지막 항목까지 온전히 볼 수 있어야 합니다. 탭이 커져 화면 밖으로 나가도 선택한 항목을 확인할 수 있는지 살펴봅니다.

### 하단 고정 영역

하단 버튼이나 안내가 커지면 본문에 남는 높이가 줄어듭니다. 본문이 고정 영역 뒤에 가려지지 않도록 실제 고정 영역의 높이를 반영합니다.

끝까지 스크롤하면 마지막 콘텐츠 전체를 읽고 조작할 수 있어야 합니다. 기본 글자 크기에서 측정한 높이만큼만 여백을 남기지 않습니다. [Safe Area](/patterns/safe-area)의 하단 안전 영역과 기본 여백도 함께 고려합니다.

고정 영역 때문에 본문을 읽거나 입력하기 어려워지면 일부 안내를 본문으로 옮기거나 고정 방식을 바꾸는 등 구성을 검토합니다.

### 다이얼로그와 바텀시트

제목·설명·액션이 차지하는 높이를 함께 확인합니다. 내용이 길어져도 본문을 읽고 확인·취소 같은 액션에 도달할 수 있어야 합니다.

내용이 늘어날 때 시트나 다이얼로그를 얼마나 높일지, 화면에 다 담지 못하면 어느 영역을 스크롤할지 정합니다. 고정된 제목이나 버튼 때문에 본문을 읽을 공간이 부족하면 별도 화면으로 제공하는 방법도 검토합니다. 닫기 버튼이 화면 밖으로 밀려나지 않는지 확인합니다.

## 디자인·개발에서 확인하기

### 디자인 시안에서 정할 것

- 기본 크기와 큰 글자 상태에서 보여야 할 정보, 허용할 줄바꿈, 배치 전환 조건을 정합니다.
- 고정할 요소와 내용에 따라 늘어날 요소를 구분하고, 정보가 길 때의 처리도 함께 설명합니다.
- Static 스타일을 쓰거나 확대를 제한해야 한다면 어떤 텍스트에 왜 적용하는지, 사용자가 그 내용을 읽을 다른 방법은 무엇인지 적습니다.
- 시안에 사용한 글자 크기와 실제 OS 설정을 구분합니다. 모든 글자에 같은 배율을 곱한 시안은 플랫폼별 실제 표시 결과와 다를 수 있습니다.

### 실제 실행 환경에서 확인할 것

시안에서 글자를 크게 만드는 것과 실제 기기의 설정을 바꾸는 것은 다를 수 있습니다. 사용자에게 제공하는 실행 환경에서 확인합니다.

- 기본 화면: 폰트 스케일링을 적용하기 전후로 기본 글자 크기에서 글꼴·줄 높이·배치가 의도대로 유지되는지 확인합니다.
- 글자 크기: 기본 크기뿐 아니라 작은 크기, 중간 단계, OS가 제공하는 가장 큰 설정을 확인합니다. 앱에서 실제로 어떤 크기로 표시되는지도 구분합니다.
- 화면과 콘텐츠: 좁은 화면, 긴 제목·가격·레이블, 여러 줄 설명, 지원 언어별 문구를 확인합니다.
- 상태: 오류 메시지, 선택 상태, 키보드가 열린 상태, 스크롤 끝을 확인합니다.
- 설정 변경: 글자 크기를 바꾼 뒤 화면으로 돌아왔을 때 글자와 배치가 함께 갱신되는지 확인합니다.
- 작업 완료: 읽기뿐 아니라 선택·입력·제출·취소를 끝까지 수행해 봅니다.

비교 스크린샷은 같은 화면 폭과 같은 문구를 사용합니다. OS 버전, 실행 환경, 글자 크기 설정을 함께 기록합니다. 설명용 시안에는 실제 앱 캡처가 아니라는 점을 표시합니다. 이미지를 보지 않아도 비교 내용을 이해할 수 있도록 캡션과 대체 텍스트에 차이를 적습니다.
