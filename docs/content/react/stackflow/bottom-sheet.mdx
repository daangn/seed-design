## Making a Bottom Sheet Activity

<StackflowExample path="/examples/bottom-sheet" />

BottomSheet 전체를 하나의 [Activity](https://stackflow.so/docs/get-started/activity)로 만들 수 있습니다. 아래와 같은 경우에 유용합니다.

- 독립적인 페이지로 취급되어야 하는 BottomSheet
- URL 접속 시 바텀 시트를 열어야 하는 경우 (딥링킹)

BottomSheet가

```tsx
const ActivityBottomSheetSimple: ActivityComponentType<"ActivityBottomSheetSimple"> = () => {
  const { pop } = useFlow();
  const activity = useActivity();

  return (
    {/* [!code highlight] */}
    <BottomSheetRoot open={activity.isActive} onOpenChange={(open) => !open && pop()}>
      <BottomSheetContent
        showHandle
        showCloseButton={false}
        title="Activity로 만들어진 BottomSheet"
      >
        <BottomSheetFooter>
          <ActionButton onClick={pop} variant="neutralSolid" size="large">
            확인
          </ActionButton>
        </BottomSheetFooter>
      </BottomSheetContent>
    </BottomSheetRoot>
  );
};
```

## Syncing BottomSheet State with a Step

**BottomSheet가 표시된 상태를 하나의 [Step](https://stackflow.so/docs/get-started/navigating-step)으로** 만들 수 있습니다. 현재 Activity를 유지하면서도, 뒤로 가기 버튼 등으로 BottomSheet를 닫고 싶은 경우 유용합니다.

### 기본 구조

Step 패턴은 `useStepOverlay` 훅을 사용하여 Activity 내에서 BottomSheet를 오버레이로 표시합니다.

### 핵심 요소

#### 1. `useStepOverlay` 훅

Step 패턴에서는 `useStepOverlay`를 사용하여 BottomSheet의 상태를 관리합니다.

- `dialogProps`: BottomSheetRoot에 전달할 props (`open`, `onOpenChange` 포함)
- `setOpen`: BottomSheet를 열고 닫는 함수

#### 2. Portal 사용

Step 패턴에서는 `<Portal>`로 BottomSheetContent를 감싸야 합니다.

이는 BottomSheet가 현재 Activity의 DOM 계층 구조 밖에서 렌더링되게 함으로써 Stackflow UI와의 충돌을 방지합니다.

#### 3. layerIndex 설정

현재 활성화된 Activity 위에 BottomSheet가 올바르게 표시되도록 `layerIndex`를 설정합니다.
