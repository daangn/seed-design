---
title: Side Navigation
description: 서비스의 최상위 메뉴 간 이동을 돕고 앱의 전체 구조를 탐색할 수 있게 하는 컴포넌트입니다.
whenToRead: React 구현 문서로, 웹 앱 사이드 내비게이션을 ui:side-navigation 스니펫과 블록 예제로 설치하거나, SideNavigationProvider로 접힘 상태를 제어하거나, SideNavigationGroup에 중첩 items를 넘기거나, 현재 메뉴를 current로 표시할 때 읽는다.
full: true
---

## Installation

```package-install
npx @seed-design/cli@latest add ui:side-navigation
```
