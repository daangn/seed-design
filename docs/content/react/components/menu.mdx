### `onOpenChange` Details

`onOpenChange` 두 번째 인자로 `details`가 제공됩니다.

#### `reason`

**열릴 때** (`open: true`)

- `"trigger"`: `MenuTrigger`로 열림

**닫힐 때** (`open: false`)

- `"escapeKeyDown"`: <kbd>ESC</kbd> 키 사용
- `"interactOutside"`: 외부 영역 클릭
- `"itemClick"`: 메뉴 항목 클릭
- `"cascadeDismiss"`: 상위 레이어 닫힘으로 인한 연쇄 닫힘
