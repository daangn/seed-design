주민등록번호 뒷자리 첫 번째 자리만 받거나 카드번호 뒷자리를 가려야 하는 경우처럼, 하나의 Text Input으로 처리하기 어려운 국내 입력 형식에 사용합니다. 전화번호·이메일, 해외 카드번호처럼 구간을 나눌 필요가 없는 입력은 [Text Field](/react/components/text-field-input)에 포맷을 적용해서 받으세요.

Segment마다 입력 하나를 두고, 값은 입력 Segment 순서대로 `string[]`로 다룹니다.

- 끝에서 입력해 Segment를 채우면 다음 Segment로 이동합니다. 가운데에 넣어 자리 수를 넘는 입력은 반영하지 않습니다.
- 빈 Segment에서 Backspace를 누르면 이전 Segment의 마지막 글자를 지웁니다. 끝에서 → 키, 처음에서 ← 키를 누르면 옆 Segment로 이동합니다.
- 가린(`masked`) Segment는 입력한 글자 대신 자리 수만큼 점을 그립니다. 가린 값 안에서는 caret을 옮기지 않고 끝에서만 입력·삭제하며, ←·→ 키는 바로 옆 Segment로 이동합니다.
- 붙여넣은 값은 구분자를 지우고 다음 Segment까지 차례로 채웁니다. 가린(`masked`) Segment 앞에서 멈춥니다.
- `autoComplete="bday"` Segment는 OS가 넣은 생년월일(`yyyy-MM-dd` 등)을 자리 수에 맞춰 바꿉니다.
- 한글 조합 중에는 다음 Segment로 이동하지 않습니다.

## Installation

주민등록번호와 카드번호는 snippet으로 제공합니다. 자리 구성과 문구(`aria-label`, placeholder)는 snippet에 있으니 필요하면 설치한 파일에서 고쳐 쓰세요.

```package-install
npx @seed-design/cli@latest add ui:resident-number-field
```

### `SegmentedTextInput.Dots`

<react-type-table
  path="../packages/react/src/components/SegmentedTextInput/SegmentedTextInput.tsx"
  name="SegmentedTextInputDotsProps"
/>

주민등록번호 뒷자리처럼 가린 자리를 7×7 점으로 표시합니다. `staticText`·`staticSuffix`·`placeholder`에 넣습니다.

```tsx
<SegmentedTextInput.Segment
  aria-label="주민등록번호 뒷자리 첫 번째 자리"
  length={1}
  placeholder={<SegmentedTextInput.Dots count={1} />}
  staticSuffix={<SegmentedTextInput.Dots count={6} />}
/>
```
