### Size

`<DialogRoot>`에 `size` prop을 설정하여 Dialog의 너비를 변경할 수 있습니다. `"medium"` (480px, 기본값)과 `"large"` (800px)를 지원합니다.
`md` 미만 화면에서는 뷰포트 너비의 90%를 차지하고, `md` 이상에서 각 size의 최대 너비가 적용됩니다. content의 높이는 뷰포트의 80%로 제한됩니다.
`alert` size는 Alert Dialog 전용이라 이 스니펫에서는 노출되지 않습니다.

### Confirm Before Close

`DialogRoot`는 기본적으로 `closeOnInteractOutside={false}`라 바깥 영역을 클릭해도 닫히지 않습니다. 반면 <kbd>ESC</kbd> 키는 기본적으로 Dialog를 닫습니다.
작성 중인 내용을 실수로 닫는 것을 막고 싶다면, `onOpenChange`의 `details.reason`이 `"escapeKeyDown"`일 때 바로 닫지 않고 확인용 Alert Dialog를 띄워 사용자에게 되물을 수 있습니다.
`open`을 제어 상태로 두고, `reason`이 `"escapeKeyDown"`이면 `open`을 유지한 채 확인 Dialog만 엽니다.

## Keyboard Interactions

| Key | Behavior |
| --- | --- |
| `Escape` | `closeOnEscape=true`(기본값)일 때 Dialog를 닫습니다. |
| `Tab` | `modal=true`일 때 Dialog 내부 요소들 사이로 포커스를 순환합니다. |
| `Shift + Tab` | `modal=true`일 때 역방향으로 포커스를 순환합니다. |
