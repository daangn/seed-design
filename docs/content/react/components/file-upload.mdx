## Usage

### 기본 사용법

`FileUploadField` 내에 `FileUpload`, `FileUploadDropzone`, `ReorderableFileUpload`, `ReorderableFileUploadDropzone`을 조합하여 사용합니다.

```tsx
import {
  FileUploadField,
  FileUpload,
  FileUploadDropzone,
} from "seed-design/ui/file-upload";

<FileUploadField>
  <FileUpload />
</FileUploadField>;

<FileUploadField>
  <FileUploadDropzone />
</FileUploadField>;
```

```tsx
import { FileUploadField } from "seed-design/ui/file-upload";
import {
  ReorderableFileUpload,
  ReorderableFileUploadDropzone,
} from "seed-design/ui/file-upload-reorderable";

<FileUploadField>
  <ReorderableFileUpload />
</FileUploadField>;

<FileUploadField>
  <ReorderableFileUploadDropzone />
</FileUploadField>;
```

### Item 직접 구성하기

`FileUpload`, `FileUploadDropzone`, `ReorderableFileUpload`, `ReorderableFileUploadDropzone`의 render prop으로 `acceptedFileEntries`를 받아와 `FileUploadItem`을 직접 렌더링할 수 있습니다.

`FileEntry`는 같은 컴포넌트 내에서 `key`로 사용할 수 있는 파일별 고유한 ID를 제공합니다.

```tsx
import {
  FileUploadField,
  FileUpload,
  FileUploadItem,
} from "seed-design/ui/file-upload";

<FileUploadField>
  <FileUpload>
    {({ acceptedFileEntries }) =>
      acceptedFileEntries.map((entry) => (
        <FileUploadItem key={entry.id} fileEntry={entry} />
      ))
    }
  </FileUpload>
</FileUploadField>;
```
