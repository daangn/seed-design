### Direction

`<DrawerRoot>`에 `direction` prop을 설정하여 Drawer가 열리는 방향을 변경할 수 있습니다.
기본값은 `"right"`입니다.

  {

    "codeblock": true
  }
  ```
</ComponentExample>

### Size

`<DrawerRoot>`에 `size` prop을 설정하여 좌우 방향 Drawer의 너비를 변경할 수 있습니다.
`"small"` (480px), `"medium"` (720px, 기본값), `"large"` (960px)를 지원합니다.

size는 `direction`이 `"left"` 또는 `"right"`일 때만 적용됩니다. 상하 방향에서는 높이가 콘텐츠에 맞게 자동 조절됩니다.

  ```
</ComponentExample>
