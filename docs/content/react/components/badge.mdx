## Installation

```package-install
npx @seed-design/cli@latest add ui:badge
```

<ManualInstallation name="badge" />

<react-type-table path="./registry/react/ui/badge.tsx" name="BadgeProps" />

## Usage

```tsx
"use client";

import { Badge } from "seed-design/ui/badge";

export function Example() {
  return <Badge>라벨</Badge>;
}
```

## Prefix and Action

`prefix`에는 Label 앞에 표시할 아이콘 요소를 전달합니다.
