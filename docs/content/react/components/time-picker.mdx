## Usage

```tsx
import { TimePicker } from "@seed-design/react";
```

```tsx
<TimePicker defaultValue={{ hour: 10, minute: 30 }} />
```

`TimePicker`는 시간 선택 UI만 제공합니다. Trigger, Popover, Bottom Sheet, 확인·취소 버튼과 form 직렬화는 사용하는 화면에서 구성합니다.

현재는 12시간제만 지원하며, 공개 값의 `hour`는 오전·오후를 포함한 0–23 범위입니다.

### Minute Step

`minuteStep`은 `1`, `5`, `10`, `15`, `30` 중 하나를 사용할 수 있으며 기본값은 `5`입니다.
선택된 분이 step에 맞지 않으면 가장 가까운 값으로 반올림합니다. 예를 들어 9시 13분은
`minuteStep={5}`에서 9시 15분으로 표시됩니다.
