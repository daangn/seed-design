## Usage

```tsx
import {
  SelectRoot,
  SelectTrigger,
  SelectContent,
  SelectGroup,
  SelectGroupLabel,
  SelectItem,
} from "seed-design/ui/select";
```

```tsx
<SelectRoot defaultValue={["apple"]}>
  <SelectTrigger aria-label="과일" placeholder="과일을 선택하세요" />
  <SelectContent>
    <SelectGroup>
      <SelectGroupLabel>과일</SelectGroupLabel>
      <SelectItem value="apple" label="사과" />
      <SelectItem value="banana" label="바나나" />
    </SelectGroup>
  </SelectContent>
</SelectRoot>
```

- `SelectRoot`: 선택 값(`value`)과 열림 상태를 관리합니다.
- `SelectTrigger`: 선택된 값 또는 placeholder를 표시하며, 클릭 시 목록을 엽니다.
- `SelectContent`: 옵션 목록을 감싸는 플로팅 컨테이너입니다.
- `SelectGroup`: 관련된 옵션들을 그룹으로 묶습니다. 모든 `SelectItem`은 `SelectGroup` 안에 있어야 합니다.
- `SelectGroupLabel`: 그룹의 제목을 표시합니다.
- `SelectItem`: 개별 옵션입니다. `value`가 필요하며, 선택되면 체크마크가 표시됩니다.

### Custom Item Label

`SelectItem`의 `label`에는 ReactNode를 넘길 수 있습니다. 이 노드는 목록의 옵션에만 렌더링됩니다. 트리거에는 노드 대신 `textValue`가 표시됩니다. 노드가 가진 레이아웃이 트리거의 한 줄짜리 값 자리에 들어가면 트리거가 깨지기 때문입니다.

`label`이 문자열이 아닌 경우 `textValue`를 함께 지정하세요. `textValue`는 트리거에 표시되는 문구, 키보드로 타이핑해 옵션을 찾을 때 매칭되는 문자열, 폼 제출용 native `<option>`의 텍스트로 쓰입니다. 지정하지 않으면 이 값들이 모두 옵션의 `value`로 대체되고, 개발 모드에서 경고가 출력됩니다.

트리거에도 노드를 렌더링하려면 `SelectRoot`의 `formatValue`를 사용하세요. 아래 [Custom Value Format](#custom-value-format)을 참고하세요.

타이핑 매칭 문자열만 따로 지정하려면 `typeaheadLabel`을 사용하세요.

### Custom Value Format

`SelectRoot`의 `formatValue` prop으로 트리거에 표시되는 선택 값을 커스텀합니다. 지정하지 않으면 단일·다중 선택 모두 선택된 옵션들의 `textValue`를 `", "`로 이어 표시합니다.

`formatValue`가 받는 각 항목에는 `label`도 담겨 있으므로, ReactNode `label`을 트리거에 렌더링하고 싶다면 여기서 꺼내 쓰면 됩니다.

```tsx
<SelectRoot formatValue={(items) => items[0]?.label} />
```

다중 선택에서 [`Intl.ListFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/ListFormat)을 사용하면 locale에 맞는 접속사로 목록을 조합할 수 있습니다.
