## Usage

Select는 아래와 같은 구조로 구성됩니다. 트리거는 Input Button, 목록은 Menu의 스타일을 따릅니다.

```tsx
import {
  SelectRoot,
  SelectTrigger,
  SelectContent,
  SelectGroup,
  SelectGroupLabel,
  SelectItem,
} from "seed-design/ui/select";
```

```tsx
<SelectRoot defaultValue={["apple"]}>
  <SelectTrigger aria-label="과일" placeholder="과일을 선택하세요" />
  <SelectContent>
    <SelectGroup>
      <SelectGroupLabel>과일</SelectGroupLabel>
      <SelectItem value="apple" label="사과" />
      <SelectItem value="banana" label="바나나" />
    </SelectGroup>
  </SelectContent>
</SelectRoot>
```

- `SelectRoot`: 선택 값(`value`)과 열림 상태를 관리합니다.
- `SelectTrigger`: 선택된 값 또는 placeholder를 표시하며, 클릭 시 목록을 엽니다. `role="combobox"`로 동작합니다.
- `SelectContent`: 옵션 목록을 감싸는 플로팅 컨테이너입니다. 기본적으로 트리거 너비에 맞춰집니다.
- `SelectGroup`: 관련된 옵션들을 그룹으로 묶습니다. 모든 `SelectItem`은 `SelectGroup` 안에 있어야 합니다.
- `SelectGroupLabel`: 그룹의 제목을 표시합니다.
- `SelectItem`: 개별 옵션입니다. `value`가 필요하며, 선택되면 체크마크가 표시됩니다.

Select는 [select-only combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) 패턴을 따릅니다. 목록이 열려 있어도 DOM 포커스는 트리거에 유지되고, 활성 옵션은 `aria-activedescendant`로 표시됩니다.

### With Prefix Icon

`SelectItem`의 `prefixIcon` prop으로 옵션에 아이콘을 표시합니다. 정확히 하나의 옵션이 선택되면 해당 옵션의 아이콘이 트리거의 prefix 자리에 함께 표시되며, 아이콘이 없는 옵션을 선택하면 prefix 자리는 비워집니다. `SelectTrigger`의 `prefixIcon` prop은 선택이 없거나 여러 개일 때만 표시됩니다.

### Custom Value Format

`SelectRoot`의 `formatValue` prop으로 트리거에 표시되는 선택 값을 커스텀합니다. 지정하지 않으면 단일 선택은 옵션의 `label`, 다중 선택(`multiple`)은 옵션들의 `textValue`를 `", "`로 이어 표시합니다.

다중 선택에서 [`Intl.ListFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/ListFormat)을 사용하면 locale에 맞는 접속사로 목록을 조합할 수 있습니다.
