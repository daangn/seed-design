## Installation

### Default

좌/우 가장자리에서 슬라이드되는 기본 Side Panel 컴포넌트를 포함합니다.

```package-install
npx @seed-design/cli@latest add ui:side-panel
```

<ManualInstallation name="side-panel" />

### Responsive

뷰포트에 따라 Bottom Sheet로 자동 전환되는 반응형 변형입니다. dependency로 `ui:bottom-sheet`와 `ui:side-panel`이 함께 설치됩니다.

```package-install
npx @seed-design/cli@latest add ui:responsive-side-panel
```

## Usage

### Responsive를 권장합니다

데스크탑 UI에서 Side Panel을 사용하는 경우 **기본적으로 `ResponsiveSidePanel`을 권장합니다.** md 이상에서는 Side Panel, sm 이하에서는 Bottom Sheet로 자동 전환되어 각 환경에 적합한 사용성을 제공합니다.

- md 이상 (768px+): Side Panel로 표시
- sm 이하 (~767px): Bottom Sheet로 표시
- 공통 제약: Header/Body/Footer 구조는 양 컴포넌트에서 동일하게 유지됩니다.

`ResponsiveSidePanelRoot`는 `SidePanelRoot` props를 그대로 받습니다. `direction`, `size`, `width`, `maxWidth` 등 SidePanel 전용 prop은 sm 이하에서는 무시되며, 뷰포트가 breakpoint를 가로질러도 wrapper가 open 상태를 보존해 패널이 닫히지 않습니다.

### SidePanel을 직접 사용해야 하는 경우

다음 케이스에서만 일반 `SidePanel`을 직접 사용합니다.

- 모바일 사이드 메뉴/네비게이션 (햄버거 메뉴, 프로필 진입 메뉴 등) — sm 이하에서도 부분 너비 패널로 표시되어야 네비게이션 컨텍스트가 유지됨
- Persistent Type이 필요한 경우 (md 이상 전용 영구 패널)

## Keyboard Interactions

| Key | Behavior |
| --- | --- |
| `Escape` | `dismissible=true`일 때 Side Panel을 닫습니다. |
| `Tab` | `modal=true`일 때 Side Panel 내부 요소들 사이로 포커스를 순환합니다. |
| `Shift + Tab` | `modal=true`일 때 역방향으로 포커스를 순환합니다. |
