`NextList`는 기존 `List`의 후속 컴포넌트입니다. "이 행이 어떻게 동작하는지(버튼인지, 링크인지, 폼 컨트롤인지)"를 결정하는 책임을 스니펫이 아니라 `@seed-design/react` 라이브러리로 옮겨, pressed scale 같은 상호작용 변경을 스니펫 수정 없이 적용할 수 있습니다.

기존 `List`는 그대로 유지되며 이후 별도로 deprecate될 예정입니다.

## Installation

```package-install
npx @seed-design/cli@latest add ui:next-list
```

<ManualInstallation name="next-list" />

## Usage

variant마다 형태가 동일하고, 사용하는 컴포넌트 이름만 달라집니다. `asChild`나 press 상태 관리 같은 구현 디테일은 노출되지 않습니다.

```tsx
import { ListHeader } from "seed-design/ui/list-header";
import { NextList, NextListItem, NextListButtonItem, NextListDivider } from "seed-design/ui/next-list";

<VStack>
  <ListHeader as="h2">리스트 헤더</ListHeader>
  <NextList>
    <NextListItem title="정적인 행" />
    <NextListDivider />
    <NextListButtonItem title="누를 수 있는 행" onClick={() => {}} />
  </NextList>
</VStack>
```

## Pressed Scale

누를 수 있는 모든 행(`NextListButtonItem`, `NextListLinkItem`, `NextListCheckItem`, `NextListRadioItem`, `NextListSwitchItem`)은 눌리는 동안 행 전체가 살짝 축소되는 시각 피드백을 가집니다. 정적인 `NextListItem`은 이 피드백이 없습니다.

두 레이어가 독립적으로 동작합니다.

- **배경 레이어**: 좌우가 안쪽으로 좁혀지며 pressed 배경색이 나타납니다.
- **레이아웃 레이어**: prefix/content/suffix를 포함한 행 전체가 `transform: scale`로 축소됩니다.

scale 값은 디자인 토큰으로 관리되며, OS의 "동작 줄이기(prefers-reduced-motion)" 설정이 켜진 경우 토큰 레이어에서 `1`로 resolve되어 축소가 비활성화됩니다. 따라서 React 컴포넌트나 스니펫에서 별도로 처리할 필요가 없습니다.

### Affixes는 격리됩니다

`suffix`나 `prefix`에 `ActionButton`처럼 누를 수 있는 보조 요소를 넣어도, 그 요소를 누르는 동안에는 보조 요소만 반응하고 행 전체는 축소되지 않습니다. 행의 press 신호는 행 자체의 interactive 요소에서만 발생하기 때문입니다.

`prefix` 또는 `suffix`에 클릭할 수 있는 요소를 포함하는 경우 `z-index: 1`, `position: relative`, `isolation: isolate` 등의 스타일을 적용하세요. `ActionButton`, `ToggleButton` 등 SEED React 컴포넌트는 추가 스타일이 필요 없습니다.

## Examples

### Affixes (Prefix/Suffix)

```tsx
<NextList>
  <NextListButtonItem
    prefix={<Icon svg={<IconPersonCircleLine />} />}
    title="프로필"
    suffix={<Icon svg={<IconChevronRightLine />} />}
    onClick={() => {}}
  />
</NextList>
```

### `input`s in List Items

`NextListSwitchItem`, `NextListCheckItem`, `NextListRadioItem`을 사용해서 리스트 항목에 `input` 요소를 포함할 수 있습니다. [Switchmark](/react/components/switch#using-switchmark), [Checkmark](/react/components/checkbox#using-checkmark), [Radiomark](/react/components/radio-group#using-radiomark)와 같은 컨트롤 요소를 `prefix`나 `suffix` 영역에 넣어 사용합니다.

```tsx
<NextList>
  <NextListSwitchItem prefix={<Switchmark />} title="알림" defaultChecked />
</NextList>
```

### Accessibility

`NextList`는 기본적으로 `<ul>`입니다. `NextListCheckItem`와 `NextListRadioItem`를 사용하는 경우 `NextList`에 적절한 role을 부여해야 합니다.

```tsx
{/* [!code highlight] */}
<NextList as="fieldset">
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="알림 수신 동의"
    detail="푸시 알림을 받으시겠습니까?"
  />
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="마케팅 정보 수신 동의"
    detail="마케팅 정보를 받으시겠습니까?"
  />
</NextList>
```

```tsx
{/* [!code highlight] */}
<NextList asChild>
  <RadioGroup.Root defaultValue="짜장" aria-label="점심 메뉴"> {/* <div role="radiogroup"> */}
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짜장" title="짜장" />
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짬뽕" title="짬뽕" />
  </RadioGroup.Root>
</NextList>
```

### Alignment

`alignItems` prop으로 `prefix`와 `suffix`의 정렬 방식을 조정할 수 있습니다.

```tsx
<NextList>
  <NextListItem alignItems="start" prefix={<Avatar size="48" />} title="제목" detail="긴 설명" />
</NextList>
```
