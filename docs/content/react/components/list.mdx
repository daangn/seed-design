## 구조

List 컴포넌트는 다음과 같은 구조로 구성됩니다:

```
List.Root
└── List.Item
    ├── List.Prefix (선택사항)
    ├── List.Content
    │   ├── List.Title
    │   └── List.Detail (선택사항)
    └── List.Suffix (선택사항)
```

### 영역별 역할

- **List.Root**: 전체 리스트를 감싸는 컨테이너 역할
- **List.Item**: 개별 리스트 항목을 나타내며, 클릭 가능한 영역을 정의
- **List.Prefix**: 아이콘, 아바타, 체크박스 등을 표시하는 왼쪽 영역
- **List.Content**: 주요 콘텐츠가 들어가는 중앙 영역
- **List.Title**: 리스트 항목의 주제목
- **List.Detail**: 부가 설명이나 세부 정보
- **List.Suffix**: 액션 버튼, 화살표, 상태 표시 등을 위한 오른쪽 영역

#### `List.Content`에 `asChild` prop을 사용하는 경우

리스트 항목 전체 영역을 클릭 가능하게 만드는 경우 사용합니다. `List.Item`에 `asChild` prop을 사용하지 않도록 유의하세요. `List.Suffix`에 버튼을 넣는 경우 `button`이 중첩되는 등 유효하지 않은 HTML이 생성될 수 있습니다.

```tsx
import { List as SeedList } from "@seed-design/react"

<SeedList.Item>
  {/* [!code highlight] */}
  <SeedList.Content asChild>
    {/* [!code highlight] */}
    <button type="button" onClick={() => alert("사용자 클릭됨")}>
      <SeedList.Title>사용자</SeedList.Title>
      {/* [!code highlight] */}
    </button>
    {/* [!code highlight] */}
  </SeedList.Content>
  <SeedList.Suffix>
    <ActionButton
      size="xsmall"
      variant="brandSolid"
      onClick={() => alert("보기 클릭됨")}
    >
      보기
    </ActionButton>
  </SeedList.Suffix>
</SeedList.Item>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `ListItemButton` 및 `ListItemLink`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { ListItemButton } from "seed-design/ui/list"

<ListItemButton
  onClick={() => alert("사용자 클릭됨")}
  title="사용자"
  detail="항목 6개"
  suffix={
    <ActionButton
      size="xsmall"
      variant="brandSolid"
      onClick={() => alert("보기 클릭됨")}
    >
      보기
    </ActionButton>
  }
/>
```

#### `List.Item`에 `asChild` prop을 사용하는 경우

리스트 항목 전체 영역을 `label`로 만들고, `List.Suffix`에 라디오 버튼, 체크박스 등 `input`을 넣는 경우 사용합니다.

```tsx
import { List as SeedList } from "@seed-design/react";

{/* [!code highlight] */}
<SeedList.Item asChild> {/* <label> */}
  {/* [!code highlight] */}
  <Checkbox.Root.Primitive defaultChecked>
    <SeedList.Content>
      <SeedList.Title>동의</SeedList.Title>
    </SeedList.Content>
    <SeedList.Suffix>
      <Checkmark />
      <Checkbox.HiddenInput />
    </SeedList.Suffix>
    {/* [!code highlight] */}
  </Checkbox.Root.Primitive>
  {/* [!code highlight] */}
</SeedList.Item>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `ListItemCheckbox` 및 `ListItemRadio`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { ListItemCheckbox } from "seed-design/ui/list"

<ListItemCheckbox defaultChecked title="동의" />
```
