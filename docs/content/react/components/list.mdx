## 구조

List 컴포넌트는 다음과 같은 구조로 구성됩니다:

```
List.Root
└── List.Item
    ├── List.Prefix (선택사항)
    ├── List.Content
    │   ├── List.Title
    │   └── List.Detail (선택사항)
    └── List.Suffix (선택사항)
```

### 영역별 역할

- **List.Root**: 전체 리스트를 감싸는 컨테이너 역할
- **List.Item**: 개별 리스트 아이템을 나타내며, 클릭 가능한 영역을 정의
- **List.Prefix**: 아이콘, 아바타, 체크박스 등을 표시하는 왼쪽 영역
- **List.Content**: 주요 콘텐츠가 들어가는 중앙 영역
- **List.Title**: 리스트 아이템의 주제목
- **List.Detail**: 부가 설명이나 세부 정보
- **List.Suffix**: 액션 버튼, 화살표, 상태 표시 등을 위한 오른쪽 영역

#### `List.Content`에 `asChild` prop을 사용하는 경우

리스트 항목 전체 영역을 클리커블한 버튼으로 만드는 경우 사용합니다. `List.Item`을 `button`으로 만들지 않도록 유의하세요. `List.Suffix`에 버튼을 넣는 경우 `button`이 중첩되는 문제가 발생합니다.

```tsx
<List.Item>
  {/* [!code highlight] */}
  <List.Content asChild>
    {/* [!code highlight] */}
    <button type="button" onClick={() => alert("사용자 클릭됨")}>
      <List.Title>사용자</List.Title>
      {/* [!code highlight] */}
    </button>
    {/* [!code highlight] */}
  </List.Content>
  <List.Suffix>
    <ActionButton size="xsmall" variant="brandSolid" onClick={() => alert("보기 클릭됨")}>
      보기
    </ActionButton>
  </List.Suffix>
</List.Item>
```

#### `List.Item`에 `asChild` prop을 사용하는 경우

리스트 항목 전체 영역을 `label`로 만들고, `List.Suffix`에 라디오 버튼, 체크박스 등 `input`을 넣는 경우 사용합니다.

```tsx
{/* [!code highlight] */}
<List.Item asChild> {/* <label> */}
  {/* [!code highlight] */}
  <Checkbox.Root.Primitive defaultChecked>
    <List.Content>
      <List.Title>동의</List.Title>
    </List.Content>
    <List.Suffix>
      <Checkmark />
      <Checkbox.HiddenInput />
    </List.Suffix>
  {/* [!code highlight] */}
  </Checkbox.Root.Primitive>
{/* [!code highlight] */}
</List.Item>
```
