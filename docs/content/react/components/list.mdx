## 구조

List 컴포넌트는 다음과 같은 구조로 구성됩니다:

```
List.Root
└── List.Item
    ├── List.Prefix (선택사항)
    ├── List.Content
    │   ├── List.Title
    │   └── List.Detail (선택사항)
    └── List.Suffix (선택사항)
```

### 영역별 역할

- **List.Root**: 전체 리스트를 감싸는 컨테이너 역할
- **List.Item**: 개별 리스트 아이템을 나타내며, 클릭 가능한 영역을 정의
- **List.Prefix**: 아이콘, 아바타, 체크박스 등을 표시하는 왼쪽 영역
- **List.Content**: 주요 콘텐츠가 들어가는 중앙 영역
- **List.Title**: 리스트 아이템의 주제목
- **List.Detail**: 부가 설명이나 세부 정보
- **List.Suffix**: 액션 버튼, 화살표, 상태 표시 등을 위한 오른쪽 영역

## 사용 가이드

### 접근성

- `List.Item`에 `asChild` prop을 사용하여 적절한 시맨틱 요소와 조합하세요
- 클릭 가능한 아이템의 경우 키보드 접근성을 고려하세요
- 스크린 리더를 위해 적절한 aria 속성을 추가하세요

### 성능 최적화

- 긴 리스트의 경우 가상화를 고려하세요
- 이미지가 포함된 경우 lazy loading을 적용하세요
- 불필요한 리렌더링을 방지하기 위해 key prop을 적절히 사용하세요
