title: List
description: 가로 행으로 구성된 콘텐츠를 표현하는 컴포넌트입니다. 행의 동작과 pressed scale 같은 상호작용은 NextList item이 책임집니다.
---

기존 `List` item 컴포넌트(`ListItem`, `ListButtonItem` 등)는 deprecated이며 `NextList` item으로 대체되었습니다([Migrating from List](#migrating-from-list) 참고). 컨테이너 `List`·`ListDivider`·`ListHeader`는 그대로 유지됩니다.

## Installation

```package-install
npx @seed-design/cli@latest add ui:next-list
```

<ManualInstallation name="next-list" />

## Usage

```tsx
import { ListHeader } from "seed-design/ui/list-header";
import { NextList, NextListItem, NextListButtonItem, NextListDivider } from "seed-design/ui/next-list";

<VStack>
  <ListHeader as="h2">리스트 헤더</ListHeader>
  <NextList>
    <NextListItem title="정적인 행" />
    <NextListDivider />
    <NextListButtonItem title="누를 수 있는 행" onClick={() => {}} />
  </NextList>
</VStack>
```

## Pressed Scale

누를 수 있는 행은 눌리는 동안 행 전체가 살짝 축소되는 pressed scale 피드백을 가집니다. scale 값은 디자인 토큰으로 관리되며 `prefers-reduced-motion` 설정 시 자동으로 비활성화됩니다.

### Accessibility

`NextList`는 기본적으로 `<ul>`입니다. `NextListCheckItem`와 `NextListRadioItem`를 사용하는 경우 `NextList`에 적절한 role을 부여해야 합니다.

```tsx
{/* [!code highlight] */}
<NextList as="fieldset">
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="알림 수신 동의"
    detail="푸시 알림을 받으시겠습니까?"
  />
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="마케팅 정보 수신 동의"
    detail="마케팅 정보를 받으시겠습니까?"
  />
</NextList>
```

```tsx
{/* [!code highlight] */}
<NextList asChild>
  <RadioGroup.Root defaultValue="짜장" aria-label="점심 메뉴"> {/* <div role="radiogroup"> */}
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짜장" title="짜장" />
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짬뽕" title="짬뽕" />
  </RadioGroup.Root>
</NextList>
```

## Migrating from List

기존 `List` item은 deprecated입니다(`@seed-design/react@2.1.0`에서 deprecated, `3.0.0`에서 제거 예정). 아래 대응표에 따라 `NextList` item으로 교체하세요.

| Deprecated        | 대체                  |
| ----------------- | --------------------- |
| `ListItem`        | `NextListItem`        |
| `ListButtonItem`  | `NextListButtonItem`  |
| `ListLinkItem`    | `NextListLinkItem`    |
| `ListCheckItem`   | `NextListCheckItem`   |
| `ListRadioItem`   | `NextListRadioItem`   |
| `ListSwitchItem`  | `NextListSwitchItem`  |

```tsx
// Before
import { List, ListButtonItem } from "seed-design/ui/list";

<List>
  <ListButtonItem title="누를 수 있는 행" onClick={() => {}} />
</List>

// After
import { NextList, NextListButtonItem } from "seed-design/ui/next-list";

<NextList>
  <NextListButtonItem title="누를 수 있는 행" onClick={() => {}} />
</NextList>
```
