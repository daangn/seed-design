## Usage

`List`·`ListDivider` 컨테이너는 그대로 사용하고, 행만 `NextList` item으로 채웁니다.

```tsx
import { ListHeader } from "seed-design/ui/list-header";
import { List, ListDivider } from "seed-design/ui/list";
import { NextListItem, NextListButtonItem } from "seed-design/ui/next-list-item";

<VStack>
  <ListHeader as="h2">리스트 헤더</ListHeader>
  <List>
    <NextListItem title="정적인 행" />
    <ListDivider />
    <NextListButtonItem title="누를 수 있는 행" onClick={() => {}} />
  </List>
</VStack>;
```

### Accessibility

`List`는 기본적으로 `<ul>`입니다. `NextListCheckItem`와 `NextListRadioItem`를 사용하는 경우 `List`에 적절한 role을 부여해야 합니다.

```tsx
{/* [!code highlight] */}
<List as="fieldset">
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="알림 수신 동의"
    detail="푸시 알림을 받으시겠습니까?"
  />
  <NextListCheckItem
    suffix={<Checkmark size="large" />}
    title="마케팅 정보 수신 동의"
    detail="마케팅 정보를 받으시겠습니까?"
  />
</List>
```

```tsx
{/* [!code highlight] */}
<List asChild>
  <RadioGroup.Root defaultValue="짜장" aria-label="점심 메뉴"> {/* <div role="radiogroup"> */}
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짜장" title="짜장" />
    <NextListRadioItem suffix={<Radiomark size="large" />} value="짬뽕" title="짬뽕" />
  </RadioGroup.Root>
</List>
```

## Customization and Composition

### Usage

`@seed-design/react` 패키지의 `List`(컨테이너)·`ListHeader`와 `NextList` item 컴포넌트는 다음과 같은 구조로 사용됩니다.

```
ListHeader
List.Root
└── NextList.Item
    ├── NextList.Prefix (선택사항)
    ├── NextList.Content
    │   ├── NextList.Title
    │   └── NextList.Detail (선택사항)
    └── NextList.Suffix (선택사항)
└── NextList.Item
    ├── ...
```

```tsx
import { ListHeader, List, NextList, Icon } from "@seed-design/react";

<ListHeader>내 정보</ListHeader>
<List.Root>
  <NextList.Item>
    <NextList.Prefix>
      <Icon svg={<IconPersonCircleLine />} />
    </NextList.Prefix>
    <NextList.Content>
      <NextList.Title>내 프로필</NextList.Title>
      <NextList.Detail>다른 사람들에게 보이는 내 정보를 관리합니다.</NextList.Detail>
    </NextList.Content>
    <NextList.Suffix>
      <Icon svg={<IconArrowRightLine />} />
    </NextList.Suffix>
  </NextList.Item>
  <NextList.Item>
    {/* ... */}
  </NextList.Item>
</List.Root>
```

- `ListHeader`: 리스트의 제목이나 설명을 표시하는 헤더 역할
- `List.Root`: 모든 리스트 항목을 감싸는 컨테이너 역할
  - `NextList.Item`: 개별 리스트 항목
  - `NextList.Prefix`: 아이콘, [Avatar](/react/components/avatar), [Checkmark](/react/components/checkbox#using-checkmark) 등을 표시할 수 있는 시작 영역
  - `NextList.Content`: 주요 콘텐츠가 들어가는 중앙 영역
    - `NextList.Title`: 리스트 항목의 제목
    - `NextList.Detail`: 부가 설명이나 세부 정보
  - `NextList.Suffix`: 아이콘, [Action Button](/react/components/action-button), [Toggle Button](/react/components/toggle-button) 등을 표시할 수 있는 끝 영역

### 적절한 시맨틱 요소로 렌더링하기

<Card title="Composition" href="/react/components/concepts/composition#aschild-prop" icon={<IconComponent />}>

`asChild` prop에 대해 자세히 알아봅니다.

</Card>

`NextList` item은 인터랙티브한 항목을 위해 적절한 시맨틱 요소(`button`, `a`, `label`)로 렌더링되는 primitive를 제공합니다. 내부적으로 `asChild`를 사용하므로 직접 배선하지 않아도 됩니다.

#### 클릭 가능한 항목: `NextList.ButtonItem`, `NextList.AnchorItem`

리스트 항목 전체 영역을 클릭 가능한 버튼 또는 링크로 만드는 경우 `NextList.ButtonItem` 또는 `NextList.AnchorItem`을 사용합니다. `NextList.Content`가 `button` 또는 `a`로 렌더링되며, `NextList.Prefix` 또는 `NextList.Suffix`에 넣은 요소는 형제로 남아 별개의 클릭 영역으로 동작합니다.

```tsx
import { NextList as SeedNextList } from "@seed-design/react";

<SeedNextList.ButtonItem onClick={() => alert("사용자 클릭됨")}> {/* NextList.Content가 <button>으로 렌더링됩니다 */}
  <SeedNextList.Content>
    <SeedNextList.Title>사용자</SeedNextList.Title>
    <SeedNextList.Detail>항목 6개</SeedNextList.Detail>
  </SeedNextList.Content>
  <SeedNextList.Suffix>
    <ActionButton
      size="xsmall"
      variant="brandSolid"
      onClick={() => alert("보기 클릭됨")}
    >
      보기
    </ActionButton>
  </SeedNextList.Suffix>
</SeedNextList.ButtonItem>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `NextListButtonItem` 및 `NextListLinkItem`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { NextListButtonItem } from "seed-design/ui/next-list-item";

<NextListButtonItem
  onClick={() => alert("사용자 클릭됨")}
  title="사용자"
  detail="항목 6개"
  suffix={
    <ActionButton size="xsmall" variant="brandSolid" onClick={() => alert("보기 클릭됨")}>
      보기
    </ActionButton>
  }
/>
```

#### `input`을 포함하는 항목: `NextList.CheckboxItem`, `NextList.RadioItem`, `NextList.SwitchItem`

리스트 항목 전체 영역을 `label`로 만들고 `NextList.Prefix` 또는 `NextList.Suffix`에 [Switchmark](/react/components/switch#using-switchmark), [Checkmark](/react/components/checkbox#using-checkmark) 또는 [Radiomark](/react/components/radio-group#using-radiomark)를 넣는 경우 `NextList.CheckboxItem`, `NextList.RadioItem`, `NextList.SwitchItem`을 사용합니다. root가 `label`로 렌더링되고 hidden input이 내장됩니다.

```tsx
import { NextList as SeedNextList } from "@seed-design/react";

<SeedNextList.CheckboxItem defaultChecked> {/* root가 <label>로 렌더링되고 hidden input이 내장됩니다 */}
  <SeedNextList.Content>
    <SeedNextList.Title>동의</SeedNextList.Title>
  </SeedNextList.Content>
  <SeedNextList.Suffix>
    <Checkmark />
  </SeedNextList.Suffix>
</SeedNextList.CheckboxItem>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `NextListSwitchItem`, `NextListCheckItem` 및 `NextListRadioItem`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { NextListCheckItem } from "seed-design/ui/next-list-item";

<NextListCheckItem defaultChecked title="동의" suffix={<Checkmark size="large" />} />
```

## Migrating from List

기존 `List` item은 deprecated입니다(`@seed-design/react@2.1.0`에서 deprecated, `3.0.0`에서 제거 예정). 컨테이너 `List`·`ListDivider`·`ListHeader`는 그대로 두고, 아래 대응표에 따라 item만 `NextList` item으로 교체하세요.

| Deprecated       | 대체                 |
| ---------------- | -------------------- |
| `ListItem`       | `NextListItem`       |
| `ListButtonItem` | `NextListButtonItem` |
| `ListLinkItem`   | `NextListLinkItem`   |
| `ListCheckItem`  | `NextListCheckItem`  |
| `ListRadioItem`  | `NextListRadioItem`  |
| `ListSwitchItem` | `NextListSwitchItem` |

```tsx
// Before
import { List, ListButtonItem } from "seed-design/ui/list";

<List>
  <ListButtonItem title="누를 수 있는 행" onClick={() => {}} />
</List>;

// After
import { List } from "seed-design/ui/list";
import { NextListButtonItem } from "seed-design/ui/next-list-item";

<List>
  <NextListButtonItem title="누를 수 있는 행" onClick={() => {}} />
</List>;
```
