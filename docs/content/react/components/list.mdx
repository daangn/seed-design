#### 접근 가능하게 만들기

`List`는 기본적으로 `<ul>`입니다. `ListItemCheck`와 `ListItemRadio`를 사용하는 경우 `List`에 적절한 role을 부여해야 합니다.

```tsx
{/* [!code highlight] */}
<List as="fieldset">
  <ListItemCheck
    title="알림 수신 동의"
    detail="푸시 알림을 받으시겠습니까?"
  />
  <ListItemCheck
    title="마케팅 정보 수신 동의"
    detail="마케팅 정보를 받으시겠습니까?"
  />
</List>
```

```tsx
{/* [!code highlight] */}
<List asChild>
  <RadioGroup.Root defaultValue="짜장" aria-label="점심 메뉴"> {/* <div role="radiogroup"> */}
    <ListItemRadio value="짜장" title="짜장" />
    <ListItemRadio value="짬뽕" title="짬뽕" />
  </RadioGroup.Root>
</List>
```

#### 컨트롤 요소 배치하기

`position="prefix"`를 사용해서 컨트롤을 리스트 항목의 시작 부분에 배치하고, `suffix`를 추가할 수 있습니다.

```tsx
<ListItemCheck
  position="prefix"
  suffix={<Icon svg={<IconPersonCircleLine />} />}
  title="동의"
  detail="약관에 동의합니다."
/>
```

`position="suffix"`를 사용해서 컨트롤을 리스트 항목의 끝 부분에 배치하고, `prefix`를 추가할 수 있습니다.

```tsx
<ListItemCheck
  position="suffix"
  prefix={<Icon svg={<IconPersonCircleLine />} />}
  title="동의"
  detail="약관에 동의합니다."
/>
```

## 구조와 영역별 역할

List 컴포넌트는 다음과 같은 구조로 구성됩니다.

```
List.Root
└── List.Item
    ├── List.Prefix (선택사항)
    ├── List.Content
    │   ├── List.Title
    │   └── List.Detail (선택사항)
    └── List.Suffix (선택사항)
```

```tsx
import { List, Icon } from "@seed-design/react";

<List.Root>
  <List.Item>
    <List.Prefix>
      <Icon svg={<IconPersonCircleLine />} />
    </List.Prefix>
    <List.Content>
      <List.Title>내 프로필</List.Title>
      <List.Detail>다른 사람들에게 보이는 내 정보를 관리합니다.</List.Detail>
    </List.Content>
    <List.Suffix>
      <Icon svg={<IconArrowRightLine />} />
    </List.Suffix>
  </List.Item>
  <List.Item>
    {/* ... */}
  </List.Item>
</List.Root>
```

- `List.Root`: 모든 리스트 항목을 감싸는 컨테이너 역할
  - `List.Item`: 개별 리스트 항목. 클릭 가능한 영역을 정의
  - `List.Prefix`: 아이콘, [Avatar](/react/components/avatar), [Checkmark](/react/components/checkbox#checkmark-활용하기) 등을 표시하는 시작 영역
  - `List.Content`: 주요 콘텐츠가 들어가는 중앙 영역
    - `List.Title`: 리스트 항목의 제목
    - `List.Detail`: 부가 설명이나 세부 정보
  - `List.Suffix`: 아이콘, [Action Button](/react/components/action-button), [Toggle Button](/react/components/toggle-button) 등을 표시하는 끝 영역

## 사용 가이드

### `asChild` prop을 사용하여 적절한 시맨틱 요소와 조합하세요

<Card title="Composition" href="/react/components/concepts/composition#aschild-prop" icon={<Component />}>

`asChild` prop에 대해 자세히 알아봅니다.

</Card>

리스트 항목 전체 영역을 클릭 가능하게 만드는 경우 사용합니다. `List.Item`에 `asChild` prop을 사용하지 않도록 유의하세요. `List.Suffix`에 버튼을 넣는 경우 `button`이 중첩되는 등 유효하지 않은 HTML이 생성될 수 있습니다.

```tsx
import { List as SeedList } from "@seed-design/react"

<SeedList.Item>
  {/* [!code highlight] */}
  <SeedList.Content asChild>
    {/* [!code highlight] */}
    <button type="button" onClick={() => alert("사용자 클릭됨")}>
      <SeedList.Title>사용자</SeedList.Title>
      {/* [!code highlight] */}
    </button>
    {/* [!code highlight] */}
  </SeedList.Content>
  <SeedList.Suffix>
    <ActionButton
      size="xsmall"
      variant="brandSolid"
      onClick={() => alert("보기 클릭됨")}
    >
      보기
    </ActionButton>
  </SeedList.Suffix>
</SeedList.Item>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `ListItemButton` 및 `ListItemLink`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { ListItemButton } from "seed-design/ui/list"

<ListItemButton
  onClick={() => alert("사용자 클릭됨")}
  title="사용자"
  detail="항목 6개"
  suffix={
    <ActionButton
      size="xsmall"
      variant="brandSolid"
      onClick={() => alert("보기 클릭됨")}
    >
      보기
    </ActionButton>
  }
/>
```

#### `List.Item`에 `asChild` prop을 사용하는 경우

리스트 항목 전체 영역을 `label`로 만들고, `List.Suffix`에 라디오 버튼, 체크박스 등 `input`을 넣는 경우 사용합니다.

```tsx
import { List as SeedList } from "@seed-design/react";

{/* [!code highlight] */}
<SeedList.Item asChild> {/* <label> */}
  {/* [!code highlight] */}
  <Checkbox.Root.Primitive defaultChecked>
    <SeedList.Content>
      <SeedList.Title>동의</SeedList.Title>
    </SeedList.Content>
    <SeedList.Suffix>
      <Checkmark />
      <Checkbox.HiddenInput />
    </SeedList.Suffix>
    {/* [!code highlight] */}
  </Checkbox.Root.Primitive>
  {/* [!code highlight] */}
</SeedList.Item>
```

[Snippet](/react/components/concepts/snippet)으로 제공되는 `ListItemCheck` 및 `ListItemRadio`는 이 패턴을 쉽게 구현할 수 있도록 돕습니다.

```tsx
import { ListItemCheck } from "seed-design/ui/list"

<ListItemCheck defaultChecked title="동의" />
```
