## Overview

Editor Toolbar 컴포넌트는 웹뷰에서 가상 키보드 위에 위치하여 텍스트 서식, 정렬, 리스트 등의 편집 기능을 제공합니다.

## Import

```tsx
import { EditorToolbar } from "@seed-design/react";
```

## Usage

### 기본 사용법

<ComponentExample name="editor-toolbar-preview" />

```tsx
<EditorToolbar showKeyboard={false}>
  <EditorToolbarItem>
    <PrefixIcon svg={<IconBold />} />
    굵게
  </EditorToolbarItem>
  <EditorToolbarItem>
    <PrefixIcon svg={<IconItalic />} />
    기울임
  </EditorToolbarItem>
  <EditorToolbarItem>
    <PrefixIcon svg={<IconUnderline />} />
    밑줄
  </EditorToolbarItem>
</EditorToolbar>
```

### Icon Only Layout

아이콘만 표시하는 컴팩트한 레이아웃을 제공합니다.

<ComponentExample name="editor-toolbar-icon-only" />

```tsx
<EditorToolbar showKeyboard={false}>
  <EditorToolbarItem layout="iconOnly" aria-label="굵게">
    <Icon svg={<IconBold />} />
  </EditorToolbarItem>
  <EditorToolbarItem layout="iconOnly" aria-label="기울임">
    <Icon svg={<IconItalic />} />
  </EditorToolbarItem>
  <EditorToolbarItem layout="iconOnly" aria-label="밑줄">
    <Icon svg={<IconUnderline />} />
  </EditorToolbarItem>
</EditorToolbar>
```

## Accessibility

### ARIA Labels

`iconOnly` 레이아웃을 사용할 경우, 반드시 `aria-label` 또는 `aria-labelledby`를 제공해야 합니다.

```tsx
<EditorToolbarItem layout="iconOnly" aria-label="굵게">
  <Icon svg={<IconBold />} />
</EditorToolbarItem>
```

### Keyboard Navigation

툴바 아이템들은 버튼으로 구현되어 있어 키보드로 접근 가능하며, Space 또는 Enter 키로 활성화할 수 있습니다.

## Best Practices

### 아이템 그룹화

관련된 기능들을 논리적으로 그룹화하여 사용자가 쉽게 찾을 수 있도록 합니다.

```tsx
<EditorToolbar showKeyboard={false}>
  {/* 텍스트 서식 */}
  <EditorToolbarItem><PrefixIcon svg={<IconBold />} />굵게</EditorToolbarItem>
  <EditorToolbarItem><PrefixIcon svg={<IconItalic />} />기울임</EditorToolbarItem>
  
  {/* 정렬 */}
  <EditorToolbarItem><PrefixIcon svg={<IconAlignLeft />} />왼쪽</EditorToolbarItem>
  <EditorToolbarItem><PrefixIcon svg={<IconAlignCenter />} />가운데</EditorToolbarItem>
</EditorToolbar>
```

### 상태 관리

선택된 아이템의 상태를 관리하여 현재 적용된 서식을 표시합니다.

```tsx
function MyEditor() {
  const [selectedItems, setSelectedItems] = React.useState<string[]>([]);

  const toggleSelection = (item: string) => {
    setSelectedItems((prev) =>
      prev.includes(item) ? prev.filter((i) => i !== item) : [...prev, item]
    );
  };

  return (
    <EditorToolbar showKeyboard={false}>
      <EditorToolbarItem
        selected={selectedItems.includes("bold")}
        onClick={() => toggleSelection("bold")}
      >
        <PrefixIcon svg={<IconBold />} />
        굵게
      </EditorToolbarItem>
    </EditorToolbar>
  );
}
```
