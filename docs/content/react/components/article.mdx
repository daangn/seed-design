#### 선택 시 `PullToRefresh` 또는 `TabsCarousel` 제스처 방지하기

`<Article />` 내부 요소는 사용자 선택이 가능합니다. 따라서, 드래그 동작을 통해 내부 요소를 선택 시 의도하지 않은 PTR(당겨서 새로고침) 또는 탭 스와이프 제스처가 발생할 수 있습니다.

`PullToRefresh.preventPull` 또는 `Tabs.carouselPreventDrag`를 `<Article />`에 전달하여 Article에서 발생한 이벤트가 제스처를 트리거하지 않도록 할 수 있습니다.

## Caveats

### `::selection` 스타일 제한 사항

`<Article />` 컴포넌트는 미리 정의된 `::selection` 스타일을 사용하지만, iOS WebView 환경에서는 이 스타일이 적용되지 않습니다. ([Can I use…](https://caniuse.com/css-selection))

SEED iOS에서는 사용자 선택 영역에 대해 커스텀 색상을 지정하지 않음으로써 네이티브-웹뷰 간 일관된 색상을 표시할 수 있도록 합니다.
