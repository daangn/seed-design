## Examples

### Type Preset

- 디자인시스템 팀이 아이콘 매핑을 관리합니다. 이후 아이콘이 교체되어도 버전 업만으로 변경을 반영할 수 있습니다.
- `type`을 생략하면 `"default"` 타입(당근 로고)이 렌더링됩니다.
- `type`과 `svg`는 동시에 전달할 수 없습니다.
