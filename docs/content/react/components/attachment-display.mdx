## Usage

### 기본 사용법

`AttachmentDisplayField` 안에 `AttachmentDisplayInput`을 배치합니다. HTML `<input type="file">`을 사용하지 않으며, 외부에서 `items`를 주입하여 미디어를 표시합니다.

```tsx
import {
  AttachmentDisplayField,
  AttachmentDisplayInput,
} from "seed-design/ui/attachment-display";

<AttachmentDisplayField defaultItems={items} maxItems={10}>
  <AttachmentDisplayInput />
</AttachmentDisplayField>;
```

### Item 직접 구성하기

`AttachmentDisplayInput`은 `children`을 render prop으로 사용합니다. `items`를 활용하여 `AttachmentDisplayItem`을 직접 렌더링할 수 있습니다.

```tsx
import {
  AttachmentDisplayField,
  AttachmentDisplayInput,
  AttachmentDisplayItem,
} from "seed-design/ui/attachment-display";

<AttachmentDisplayField items={items} onItemsChange={setItems} maxItems={10}>
  <AttachmentDisplayInput>
    {({ items }) =>
      items.map((entry) => (
        <AttachmentDisplayItem key={entry.id} entry={entry} />
      ))
    }
  </AttachmentDisplayInput>
</AttachmentDisplayField>;
```

### Trigger 커스터마이징

`onTriggerClick`으로 trigger 버튼 클릭 시 동작을 지정합니다. 네이티브 미디어 피커, 커스텀 모달 등 원하는 동작을 연결할 수 있습니다.

```tsx
<AttachmentDisplayField
  items={items}
  onItemsChange={setItems}
  maxItems={10}
  onTriggerClick={async () => {
    const media = await openMediaPicker({ ... });
    // media를 items로 변환하여 추가
  }}
>
  <AttachmentDisplayInput />
</AttachmentDisplayField>
```

## Managing Item Status

각 `DisplayItemEntry`는 `pending`, `uploading`, `success`, `error` 상태를 가질 수 있습니다. 외부 업로드 시스템(네이티브 브릿지, API 등)의 진행 상태를 반영하여 사용자에게 피드백을 제공합니다.

<ComponentExample name="react/attachment-display/status">
  ```json doc-gen:file

    "codeblock": true
  }
  ```

- `uploading`: [ProgressCircle](/react/components/progress-circle)이 표시됩니다.
  - `progress`를 설정하여 업로드 진행률을 표시할 수 있습니다.
  - `progress`를 지정하지 않는 경우 [indeterminate](/react/components/progress-circle#indeterminate) 상태로 표시됩니다.
- `error`: 재시도 버튼이 표시됩니다.
  - 클릭 시 `AttachmentDisplayItem`에 지정한 `onRetry` 콜백이 실행됩니다.

## Attachment Field과의 차이

| | Attachment Field | Attachment Display |
|---|---|---|
| 미디어 소스 | HTML `<input type="file">` | 외부 URL (브릿지, 서버 등) |
| 데이터 모델 | `FileEntry` (`File` 객체 포함) | `DisplayItemEntry` (URL 기반) |
| 파일 선택 | 브라우저 파일 다이얼로그 | `onTriggerClick` 콜백으로 외부 위임 |
| 드래그 앤 드롭 | Dropzone 지원 | 미지원 |
| 파일 검증 | accept, maxFileSize 등 | 없음 (외부에서 처리) |
| Form 연동 | `<input type="file">` 동기화 | 없음 |
| 비주얼 | 동일 | 동일 |
