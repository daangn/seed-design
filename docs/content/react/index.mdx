SEED Design은 당근의 디자인 시스템입니다. 40개 이상의 React 컴포넌트, 디자인 토큰(색상, 타이포그래피, 스페이싱), 테마 시스템을 제공합니다.

## AI와 함께 시작하기

`seed-design` 스킬을 설치하면 AI 에이전트가 프로젝트 셋업부터 컴포넌트 사용까지 안내합니다.

```package-install
npx skills add https://github.com/daangn/seed-design --skill seed-design
```

스킬이 설치되면 에이전트에게 자연스럽게 질문할 수 있습니다:

- "SEED Design 셋업해줘"
- "어떤 컴포넌트가 있어?"
- "색상 토큰 쓰는 법 알려줘"

스킬에 대한 자세한 내용은 [AI Integration - Skill](/ai-integration/skill) 문서를 참고하세요.

## 직접 시작하기

AI 스킬 없이 직접 시작하려면:

1. **[Installation](/react/getting-started/installation/vite)** - 번들러별 설치 가이드
2. **[Styling](/react/getting-started/styling/theming)** - 테마 및 스타일링 설정
3. **[CLI](/react/getting-started/cli/commands)** - CLI로 컴포넌트 추가/관리
