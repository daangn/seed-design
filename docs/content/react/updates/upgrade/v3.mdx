SEED React 3으로 업그레이드하는 방법을 안내합니다. 신규 기능 등 전체 변경사항은 [Changelog](/react/updates/changelog)에서 확인할 수 있습니다.

<Callout type="info">
  이 가이드는 `2.x`에서 `3`으로 업그레이드하는 경우를 기준으로 작성되었습니다.
  2보다 낮은 버전을 사용 중이라면 [SEED React 2](/react/updates/upgrade/v2)
  가이드를 따른 뒤 이 문서로 돌아와 주세요.
</Callout>

## 패키지 업그레이드

프로젝트에서 사용하는 `@seed-design/*` 패키지를 아래 버전 이상으로 업그레이드합니다.

| 패키지               | 최소 버전 |
| -------------------- | --------- |
| `@seed-design/css`   | `3.0.0`   |
| `@seed-design/react` | `3.0.0`   |

```package-install
@seed-design/react@latest @seed-design/css@latest
```

<Step>

## 코드 변경

### 코드 수정이 필요한 항목

#### 1. `@seed-design/css/vars/component`에서 `typography` 외 경로 제거

<Badge tone="positive">에러로 발견 가능</Badge>

`@seed-design/css/vars/component`에서는 `typography`만 제공합니다. 다른 컴포넌트의 vars는 recipe 구현용 내부 값이어서 2.x에서도 SemVer 보장 대상이 아니었고, 3.0에서 export를 제거했습니다.

**index에서 `typography`를 가져오는 경우**

`@seed-design/css/vars/component` index를 제거했습니다. `@seed-design/css/vars/component/typography`에서 `vars`를 가져옵니다.

```ts
import { typography } from "@seed-design/css/vars/component"; // [!code --]
import { vars as typography } from "@seed-design/css/vars/component/typography"; // [!code ++]
```

**다른 컴포넌트의 vars를 가져오는 경우**

같은 값을 [디자인 토큰](/foundations/color)(`@seed-design/css/vars`)에서 찾아 바꿉니다. 토큰을 참조하지 않는 값(`maxWidth: "7.5rem"` 등)은 컴포넌트 구현 세부 사항이므로 필요한 값을 직접 지정합니다.

```ts
import { badge } from "@seed-design/css/vars/component"; // [!code --]
import { vars } from "@seed-design/css/vars"; // [!code ++]

const minHeight = badge.sizeMedium.enabled.root.minHeight; // [!code --]
const minHeight = vars.$dimension.x5; // [!code ++]
```
