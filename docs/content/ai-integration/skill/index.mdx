`seed-design` 스킬은 AI 에이전트가 SEED를 쓰는 프로젝트를 도울 때 로드하는 가이드입니다.

스킬은 질문을 다음 세 층으로 나눠 필요한 공식 문서를 찾습니다.

1. **공통 디자인 지식** — 컴포넌트 Anatomy·Properties·Guidelines와 색상·타이포그래피·스페이싱 같은 Foundations
2. **플랫폼 구현** — React 또는 Lynx의 API, 설치, 스니펫, 코드 작성
3. **적응형 [Doctor](/ai-integration/skill/doctor)** — `seed-design.json`과 직접 의존성으로 워크스페이스 맥락을 찾고, 설정·호환·셋업·Foundations·컴포넌트·라이브러리 중 적용 가능한 건강검진을 실행

공통 컴포넌트 스펙과 Foundations는 프로젝트나 플랫폼을 확인하지 않고 바로 조회합니다. 구현·설치·Doctor처럼 플랫폼에 따라 결과가 달라지는 요청만 플랫폼을 판별합니다. 모노레포에서 React와 Lynx가 함께 발견되거나 단서가 없으면 에이전트가 React를 추측하지 않고 사용자에게 확인합니다. 선택한 플랫폼에 문서나 registry 항목이 없으면 다른 플랫폼 문서로 대체하지 않고 없다고 안내합니다.

## Migration and upgrade

설치된 스니펫이 요구하는 버전과 실제 패키지 버전이 맞는지 확인하고, 현재 CLI 문서가 안내하는 방식으로 커스터마이징을 보존하며 스니펫을 갱신합니다. 패키지 버전을 올릴 때는 현재 버전부터 목표 버전까지의 변경사항을 읽고 마이그레이션 경로를 제시합니다.

## Installation

`seed-design` 스킬을 설치하려면 다음 명령어를 사용하세요.

```package-install
npx skills add https://github.com/daangn/seed-design --skill seed-design
```

스킬의 전체 내용은 GitHub의 [`skills/seed-design`](https://github.com/daangn/seed-design/tree/dev/skills/seed-design)에서 볼 수 있습니다.
