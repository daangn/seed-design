`seed-design` 스킬은 AI 에이전트가 SEED를 쓰는 프로젝트를 도울 때 로드하는 가이드입니다.

**문서에 이미 있는 것은 스킬에 옮겨 적지 않습니다.** 셋업 절차나 컴포넌트 목록, 토큰 이름은 공식 문서가 원본이고 복사본은 원본보다 먼저 낡습니다. 스킬이 담는 것은 **문서만으로는 나오지 않는 것** 두 가지입니다.

- **여러 문서를 대조해야 결론이 나오는 판단** — 설치된 `react`와 `css`가 서로 맞는지, 어느 버전까지 어떤 순서로 올려야 하는지
- **코드를 문서 기준으로 검사하는 진단** — 구버전 스니펫, deprecated 사용, 가이드라인 준수 여부 ([Doctor](/ai-integration/skill/doctor))

## Installation

`seed-design` 스킬을 설치하려면 다음 명령어를 사용하세요.

```package-install
npx skills add https://github.com/daangn/seed-design --skill seed-design
```
