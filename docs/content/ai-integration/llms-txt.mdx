## 소개

SEED Design은 대규모 언어 모델(LLM)이 문서를 쉽게 이해하고 활용할 수 있도록 [llms.txt](https://llmstxt.org/) 형식의 문서를 제공합니다.
각 섹션별로 구조화된 텍스트 파일을 통해 AI 도구가 SEED Design의 컴포넌트, 가이드라인, API를 효과적으로 참조할 수 있습니다.

## 빠른 접근

자주 사용되는 문서에 빠르게 접근할 수 있습니다.

- **섹션 인덱스**: [/react/llms.txt](https://seed-design.io/react/llms.txt) - React 라이브러리의 모든 문서 목록과 링크
- **개별 컴포넌트 문서**: `/llms/react/components/{component}.txt` (예: [/llms/react/components/layout/box.txt](https://seed-design.io/llms/react/components/layout/box.txt))
- **컴포넌트 가이드라인**: [/docs/llms.txt](https://seed-design.io/docs/llms.txt) - 디자인 가이드라인 문서 진입점

## 사용 예시

### 특정 컴포넌트 문서 참조

```
@https://seed-design.io/llms/react/components/action-button.txt

ActionButton 컴포넌트의 variant 옵션에 대해 설명해주세요.
```

### docs-mcp를 통한 구조화된 접근

docs-mcp MCP 서버를 사용하면 필요한 문서만 선택적으로 가져올 수 있습니다.

```
list_sections → list_docs(section: "react", category: "components") → read_doc(section: "react", path: "components/action-button")
```

자세한 내용은 [Docs MCP](./docs-mcp) 문서를 참고하세요.
