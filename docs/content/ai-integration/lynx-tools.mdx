## 소개

Lynx는 SEED Design의 아이콘 및 UI 프레임워크입니다. AI 도구와 함께 Lynx를 활용하면 더욱 효율적으로 개발할 수 있습니다.

## LLMs.txt

Lynx 문서는 LLM이 쉽게 이해할 수 있도록 llms.txt 형식으로 제공됩니다.

### 진입점

- **Lynx 문서**: [/lynx/llms.txt](https://seed-design.io/lynx/llms.txt)

### 사용 예시

AI 어시스턴트에게 Lynx 문서를 컨텍스트로 제공하여 아이콘 관련 질문에 답변을 받을 수 있습니다.

```
@https://seed-design.io/lynx/llms.txt

Lynx 아이콘을 React 프로젝트에서 사용하는 방법을 알려주세요.
```

## AI 도구 활용 팁

### 아이콘 검색

AI 어시스턴트에게 원하는 아이콘을 설명하면 적합한 아이콘을 추천받을 수 있습니다.

```
SEED Design Lynx 아이콘 중에서 "설정" 또는 "환경설정"을 나타내는 아이콘을 추천해주세요.
```

### 아이콘 사용 코드 생성

AI 어시스턴트가 Lynx 아이콘을 사용하는 코드를 생성할 수 있습니다.

```
Lynx의 IconGearFill 아이콘을 사용해서 설정 버튼을 만들어주세요.
```
