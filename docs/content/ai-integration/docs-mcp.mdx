## 소개

[`@seed-design/docs-mcp`](https://github.com/daangn/seed-design/tree/dev/packages/docs-mcp)는 SEED Design 문서를 위한 공식 MCP 서버입니다.

핵심 원칙:

- `llms.txt` / `/llms/.../*.txt` 기반 문서 접근
- HTML 문서 파싱 fallback 없음
- MCP `outputSchema` + `structuredContent` 중심 응답
- stdio + Streamable HTTP 전송 지원

## 설치

```bash
bun add @seed-design/docs-mcp
# 또는
npm install @seed-design/docs-mcp
```

## 도구 목록 (V2)

### Documentation

#### `list_sections`

문서 섹션과 카테고리를 반환합니다.

#### `list_docs`

섹션 내 문서 목록을 반환합니다.

파라미터:

- `section` (필수)
- `category` (선택)
- `limit` (선택)

#### `search_docs`

문서 제목/경로를 기준으로 검색합니다.

파라미터:

- `query` (필수)
- `section` (선택)
- `category` (선택)
- `limit` (선택)

#### `read_doc`

단일 문서를 읽습니다.

파라미터:

- `section` (필수)
- `path` (필수)
- `maxChars` (선택)

#### `read_docs_batch`

여러 문서를 한 번에 읽습니다.

파라미터:

- `items: [{ section, path }]` (필수)
- `maxCharsPerDoc` (선택)

### Rootage

#### `read_rootage`

Rootage JSON 인덱스/리소스를 조회합니다.

파라미터:

- `path` (선택)

### Icons

#### `list_icons`
#### `search_icons`
#### `read_icon`

아이콘 목록/검색/상세 정보를 제공합니다.

## 리소스 (Resources)

- `seed-docs://sections`
- `seed-docs://{section}/index`
- `seed-rootage://index`
- `seed-icons://services`

## 프롬프트 (Prompts)

- `seed_docs_lookup`

## llms.txt 우선 정책

`read_doc`, `read_docs_batch`는 아래 텍스트 문서만 허용합니다:

- `.../llms.txt`
- `/llms/.../*.txt`

`text/html` 응답은 오류 처리되며 fallback으로 읽지 않습니다.

이는 에이전트의 문서 이해 품질을 높이고 불필요한 HTML 노이즈를 줄이기 위한 정책입니다.

## 브레이킹 변경

아래 도구는 V2에서 제거되었습니다:

- `discover_seed_docs`
- `get_doc`
- `get_full_docs`
- `get_rootage`
- `get_icon_details`

대응:

- `discover_seed_docs` -> `list_sections`
- `get_doc` -> `read_doc`
- `get_full_docs` -> `read_docs_batch`
- `get_rootage` -> `read_rootage`
- `get_icon_details` -> `read_icon`

## 프로그래매틱 사용

```ts
import { initializeTools, server, startHttpServer } from "@seed-design/docs-mcp";

await initializeTools(server, { baseUrl: "http://127.0.0.1:3000" });

// Streamable HTTP
await startHttpServer({
  host: "127.0.0.1",
  port: 3100,
  path: "/mcp",
  baseUrl: "http://127.0.0.1:3000",
});
```
