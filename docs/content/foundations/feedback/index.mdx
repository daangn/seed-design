사용자가 요소를 누르거나 조작할 때, 인터페이스는 그 입력이 전달되었음을 즉시 알려주어야 합니다. 이러한 반응은 [State](/foundations/state)가 정의하는 '상태'를 [Motion](/foundations/motion)의 언어로 전달하는 역할을 합니다.

## 반응을 표현하는 방법

하나의 상태를 한 가지 표현이 전담하지 않습니다. 여러 표현이 함께 눌림을 전달합니다.

| 표현 | 눌린 동안 일어나는 일 |
| --- | --- |
| **색상** | 배경과 전경의 색이 바뀝니다 |
| **축소** | 요소 또는 안쪽 콘텐츠가 살짝 작아집니다 |
| **여백** | 배경 레이어가 좌우로 좁혀집니다 |
| **모서리** | 배경 레이어의 모서리 반경이 커집니다 |

요소마다 사용하는 표현의 조합이 다릅니다. [Action Button](/components/action-button)은 색상과 축소를 쓰고, [List Item](/components/list)은 네 가지를 모두 씁니다. 표현마다 시간과 이징을 따로 지정할 수 있어, 같은 누름 안에서도 각 표현이 자기 속도로 움직입니다.

색상은 [Color](/foundations/color)에서, 표현이 움직이는 시간과 이징의 기준은 [Motion](/foundations/motion)에서 다룹니다.
