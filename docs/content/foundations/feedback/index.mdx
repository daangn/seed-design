사용자가 요소를 누르면, 인터페이스는 그 입력이 전달되었음을 즉시 알려주어야 합니다. 이 즉각적인 반응이 피드백입니다. [State](/foundations/state)가 정의한 상태를 [Motion](/foundations/motion)의 언어로 드러내는 역할을 합니다.

피드백을 전달하는 방법은 하나가 아닙니다. 색상처럼 눈에 띄는 방법이 있고, 축소처럼 형태로 드러나는 방법이 있으며, Haptic처럼 손끝으로 느껴지는 방법도 있습니다. 요소마다 쓰는 조합이 다릅니다.

## 피드백 채널

| 채널                                 | 전달 방식                                   |
| ------------------------------------ | ------------------------------------------- |
| [Color](/foundations/feedback/color) | 눌린 동안 표면 색이 바뀝니다                |
| [Scale](/foundations/feedback/scale) | 눌린 동안 요소가 정해진 거리만큼 작아집니다 |

Color는 누를 수 있는 모든 요소에 적용되는 기본 채널입니다. Scale은 그 위에 선택적으로 더해집니다. 어떤 요소에 Scale을 더할지는 [Scale 문서의 적용 범위](/foundations/feedback/scale#적용-범위-결정하기)에서 정의합니다.

촉각으로 전달하는 Haptic도 같은 층위의 채널이지만, SEED는 아직 정의하지 않았습니다.

## 원칙

### 채널은 함께 설계합니다

한 번의 입력에서 여러 채널이 동작할 때, 사용자는 이를 하나의 사건으로 인지해야 합니다. 채널이 서로 다른 시점에 시작하거나 서로 다른 속도로 진행되면 두 개의 반응처럼 읽히고, 요소가 잘못 동작하는 것처럼 느껴집니다.

SEED는 이를 위해 색 전환과 축소가 같은 시간을 쓰도록 맞춰두었습니다. `$duration.color-transition`과 `$duration.pressed-scale`은 모두 `$duration.d3`을 참조합니다.

### 하나의 채널에만 의존하지 않습니다

사용자의 환경에 따라 특정 채널이 전달되지 않을 수 있습니다. OS의 동작 줄이기(Reduce Motion)가 켜져 있으면 축소는 일어나지 않고, 촉각 신호는 기기나 시스템 설정에 따라 전달되지 않을 수 있습니다.

어떤 채널이 빠지더라도 입력이 전달되었다는 사실은 남아야 합니다. 그래서 Color는 어떤 환경에서도 빠지지 않는 기본 채널이며, Scale과 Haptic은 그 위에 더해지는 보강 채널입니다.

### 같은 인터랙션에는 같은 조합을 씁니다

같은 성격의 요소가 서로 다른 조합을 쓰면 사용자는 그 차이를 의미로 읽습니다. 조합은 요소의 시각적 특성이나 화면 단위로 정하지 않고, 아래 구조 기준에 따라 정합니다.

## 채널 조합

| 요소 구조                                                                        | Color | Scale               |
| -------------------------------------------------------------------------------- | ----- | ------------------- |
| 표면을 가지고 단일 동작을 수행하는 요소 ([Action Button](/components/action-button)) | 적용  | Root Scale          |
| 배경이 넓고 안쪽에 여러 요소가 정렬된 구조 ([List Item](/components/list), [Accordion](/components/accordion)) | 적용  | Content Scale       |
| 표면이 없는 텍스트 요소 (Link Text Button)                                        | 적용  | 적용하지 않음       |
| 대등한 동작이 여러 개 놓인 요소 (탭·좋아요·저장이 함께 있는 카드)                  | 적용  | 적용하지 않음       |

각 판단 기준의 근거는 [Scale의 적용 범위 결정하기](/foundations/feedback/scale#적용-범위-결정하기)에서 자세히 다룹니다.

## 피드백이 일어나지 않는 상태

- **Loading** — 이미 진행 중인 동작이 있어 추가 입력을 받지 않습니다. 어떤 채널도 반응하지 않습니다.
- **Disabled** — 상호작용을 받지 않는 상태이므로 누름에 대한 반응도 일어나지 않습니다.

두 상태 모두 pressed 표현 대신 해당 상태의 고유한 표현을 유지합니다.
