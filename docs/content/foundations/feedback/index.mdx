사용자가 요소를 누르면, 인터페이스는 그 입력이 전달되었음을 즉시 알려주어야 합니다. 이 즉각적인 반응이 피드백입니다. [State](/foundations/state)가 정의한 pressed 상태를 사용자가 눈과 손으로 감지할 수 있는 형태로 바꾸는 일입니다.

## 피드백 채널

| 채널                                 | 전달 방식                                   |
| ------------------------------------ | ------------------------------------------- |
| [Color](/foundations/feedback/color) | 눌린 동안 표면 색이 바뀝니다                |
| [Scale](/foundations/feedback/scale) | 눌린 동안 요소가 정해진 거리만큼 작아집니다 |

Color는 누를 수 있는 모든 요소에 적용되는 기본 채널이고, Scale은 그 위에 선택적으로 더해집니다. 촉각으로 전달하는 Haptic도 같은 층위의 채널이지만, SEED는 아직 정의하지 않았습니다.

## 원칙

### 채널은 함께 설계합니다

한 번의 입력에서 여러 채널이 동작할 때, 사용자는 이를 하나의 사건으로 인지해야 합니다. 채널이 서로 다른 시점에 시작하거나 서로 다른 속도로 진행되면 두 개의 반응처럼 읽히고, 요소가 잘못 동작하는 것처럼 느껴집니다.

SEED는 이를 위해 색 전환과 축소가 같은 시간을 쓰도록 맞춰두었습니다. `$duration.color-transition`과 `$duration.pressed-scale`은 모두 `$duration.d3`을 참조합니다.

### 하나의 채널에만 의존하지 않습니다

사용자의 환경에 따라 특정 채널이 전달되지 않을 수 있습니다. 축소는 [OS 설정에 따라 일어나지 않을 수 있고](/foundations/feedback/scale#접근성), 촉각 신호는 기기나 시스템 설정에 따라 전달되지 않을 수 있습니다.

어떤 채널이 빠지더라도 입력이 전달되었다는 사실은 남아야 합니다. 그래서 Color는 어떤 환경에서도 빠지지 않는 기본 채널이며, Scale과 Haptic은 그 위에 더해지는 보강 채널입니다.

## 채널 조합

같은 성격의 요소가 서로 다른 조합을 쓰면 사용자는 그 차이를 의미로 읽습니다. 조합은 요소의 시각적 특성이나 화면 단위로 정하지 않고, 아래 구조 기준을 따릅니다.

| 요소 구조                 | 예시                                                                       | Color | Scale         |
| ------------------------- | -------------------------------------------------------------------------- | ----- | ------------- |
| 단일 표면                 | [Action Button](/components/action-button)                                 | 적용  | Root Scale    |
| 넓은 배경 + 정렬된 콘텐츠 | [List Item](/components/list), [Accordion](/components/accordion)          | 적용  | Content Scale |
| 표면 없음                 | Link Text Button                                                           | 적용  | 적용하지 않음 |
| 복수 동작                 | 탭·좋아요·저장이 함께 있는 카드                                            | 적용  | 적용하지 않음 |

각 판단 기준의 근거는 [Scale의 적용 범위 결정하기](/foundations/feedback/scale#적용-범위-결정하기)에서 자세히 다룹니다.
