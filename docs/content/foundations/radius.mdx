Radius는 UI 구성 요소의 모서리를 둥글게 처리하여 부드럽고 현대적인 느낌을 제공합니다.
일관된 Radius 값은 브랜드 아이덴티티를 강화하고, 사용자 경험을 향상시키며,
다양한 화면과 컨텍스트에서 시각적 일관성을 유지하는 데 중요한 역할을 합니다.
