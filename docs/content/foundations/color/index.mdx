## Overview

SEED 색상 시스템은 역할 기반 색상과 팔레트 색상으로 구성되어 있으며, 모두를 위한 글로벌 접근성 충족을 목표로 설계되었습니다.
이를 통해 인터페이스 내에서 충분한 명도 대비를 보장하고, 명확성과 가시성을 확보할 수 있습니다.

## Role Based Color

**역할 기반 색상** 시스템은 디자이너와 개발자 모두를 위한 구조화된 색상 구현 방식을 제공합니다.

색상 역할은 인터페이스의 시각적 요소와 기능 사이의 명확한 관계를 설정하여 사용자에게 더 직관적이고 예측 가능한 UI를 제공합니다.
임의의 색상값을 사용하는 대신, 각 색상은 인터페이스 내에서 특정한 목적과 의미를 가집니다.

### 장점 1. 접근성

<Image src="/foundations/color/color-system/contrast.webp" alt="대비" />

역할 기반 색상을 사용하면 전체 애플리케이션에서 접근성 표준을 더 쉽게 유지할 수 있습니다.
모든 역할 기반 색상은 의도된 전경/배경의 모든 조합에 대해 [포용적 디자인 문서의 APCA 기준](/foundations/inclusive-design)을 충족하도록 설계되어 있습니다.

### 장점 2. 빈틈없는 업데이트

<Image
  src="/foundations/color/color-system/category.webp"
  alt="분류에 따른 색상 업데이트"
/>

색상을 업데이트해야 할 때, 값이 아닌 의미를 기준으로 업데이트 할 수 있습니다.
동일한 값을 가지더라도 의미가 다르다면, 따로 업데이트가 가능해야 합니다.
전체 시스템의 일관성을 보장하면서 지속적으로 UI 색상을 개선할 수 있는 기반을 제공합니다.

### 장점 3. 테마 적응성

<Image
  src="/foundations/color/color-system/adaptive-theme.webp"
  alt="테마 적응성"
/>

역할 기반 색상은 라이트 모드와 다크 모드를 포함한 여러 테마를 지원하기 위한 기반을 제공합니다.
특정 색상 대신 역할을 정의함으로써 시스템은 적절한 대비와 시각적 계층 구조를 유지하면서 다양한 테마에 자동으로 적응할 수 있습니다.

## Palette Color

<Image
  src="/foundations/color/color-system/palette.webp"
  alt="팔레트 색상"
/>

팔레트 색상은 역할 기반 색상으로 표현하기 어려운 예외적인 경우에 사용되는 색상입니다.

SEED 팔레트 색상은 적응형 팔레트로 구성되어 기기의 화면 모드(라이트/다크)에 따라 알맞은 명도의 색상이 배정되어 있습니다.
이를 통해 특정 화면 모드를 기준으로 디자인 하더라도, 다른 화면 모드에서도 충분히 인지하기 쉬운 색상을 사용하는 것을 보장합니다.

## Color Stability

색상 토큰은 이름과 값이 서로 다른 수준의 안정성을 가집니다. 아래 규칙은 역할 기반 색상과 팔레트 색상 모두에 동일하게 적용되며, [SEED의 시맨틱 버저닝 정책](/react/updates/upgrade/v2)을 따릅니다.

| 변경                  | bump    | 사용자 영향                                                |
| --------------------- | ------- | ---------------------------------------------------------- |
| 토큰 이름 변경·제거   | `major` | 코드 수정이 필요합니다.                                    |
| 의도적인 색상 값 변경 | `major` | 코드 수정은 필요 없지만 화면의 색이 달라집니다.            |
| 잘못된 색상 값의 수정 | `patch` | 대비 기준 미달처럼 값이 의도와 달랐던 경우를 바로잡습니다. |

<Callout type="info">
  디자인 판단에 따른 색상 변경은 `major`에서만 일어납니다. `^` 범위로 SEED를
  사용하더라도 `major`를 올리지 않는 한 의도적으로 색이 바뀌지는 않습니다. 다만
  잘못된 값을 바로잡기 위한 조정은 `patch`에 포함될 수 있습니다.
</Callout>

라이트 모드와 다크 모드에서 같은 토큰이 서로 다른 값을 갖는 것은 값 변경에 해당하지 않습니다. 테마에 따른 적응은 색상 시스템의 설계 자체입니다.
