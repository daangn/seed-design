# @seed-design/react — 문서 색인

설치된 @seed-design/react 버전과 함께 배포된 문서 사본입니다. 각 문서에는 예제 코드와 props 목록이 인라인되어 있으므로, 해당 파일 하나만 읽으면 됩니다.

예제 코드의 `seed-design/ui/*` import는 CLI 스니펫(`npx @seed-design/cli add`)이 프로젝트에 생성하는 경로입니다. 스니펫 없이 이 패키지를 직접 사용한다면 같은 이름의 컴포넌트를 `@seed-design/react`에서 임포트하세요.

최신(latest) 버전 문서: https://seed-design.io/react/components

## Components

- [Accordion](./accordion.md) — 여러 개의 관련된 콘텐츠 섹션을 수직으로 나열하고, 각 섹션을 펼치거나 접어 정보를 탐색할 수 있는 컴포넌트입니다.
- [Action Button](./action-button.md) — 명확한 액션을 쉽게 수행할 수 있도록 돕는 기본 인터랙션 컴포넌트입니다.
- [Alert Dialog](./alert-dialog.md) — 사용자의 확인이 반드시 필요한 경우 강력한 표현 및 경고 수단으로 활용하는 컴포넌트입니다.
- [Article](./article.md) — Article은 일관된 selection 및 줄바꿈 정책을 사용할 수 있게 돕는 유틸리티 컴포넌트입니다.
- [Aspect Ratio](./aspect-ratio.md) — 가로(width)가 정해지면 비율에 따라 세로(height)가 자동으로 결정되는 레이아웃 컨테이너입니다.
- [Attachment Display Field](./attachment-display-field.md) — 외부 소스에서 제공된 미디어를 URL 기반으로 표시하고 관리하는 컴포넌트입니다.
- [Attachment Field](./attachment-field.md) — 파일을 선택하거나 드래그 앤 드롭으로 업로드할 수 있는 컴포넌트입니다.
- [Avatar](./avatar.md) — 사용자의 프로필 이미지를 표시하는 컴포넌트입니다.
- [Badge](./badge.md) — 객체의 속성이나 상태를 시각적으로 표현하는 작은 텍스트 라벨입니다. 사용자의 주의를 끌고 콘텐츠의 빠른 인지와 탐색을 돕기 위해 사용됩니다.
- [Bottom Sheet](./bottom-sheet.md) — 화면 하단에서 올라오는 모달 컴포넌트입니다. 추가 정보나 액션 목록을 제공하면서도 현재 컨텍스트를 유지할 때 사용됩니다.
- [Callout](./callout.md) — 사용자에게 중요한 정보나 팁을 시각적으로 강조하여 전달하는 메시지 컴포넌트입니다.
- [Checkbox](./checkbox.md) — 사용자가 하나 이상의 옵션을 선택할 수 있게 해주는 컴포넌트입니다. 목록에서 여러 항목을 선택하거나 약관 동의와 같은 선택적 작업에 사용됩니다.
- [Chip](./chip.md) — 사용자가 선택하거나 입력하는 값을 표시하는 컴포넌트입니다.
- [Chip Tabs](./chip-tabs.md) — Chip 형태로 표현된 탭 컴포넌트입니다. 카테고리나 필터를 선택하여 콘텐츠를 전환할 때 사용됩니다.
- [Content Placeholder](./content-placeholder.md) — 이미지나 콘텐츠가 로드되지 않았을 때, 해당 영역의 성격을 전달하는 대체 시각 요소입니다.
- [Contextual Floating Button](./contextual-floating-button.md) — 화면 위에 떠 있으며 특정 상황에서만 나타나는 보조적인 동작을 위한 버튼입니다.
- [Dialog](./dialog.md) — 화면 중앙에 떠서 사용자의 주의를 모으는 다이얼로그입니다. 제목, 본문, 푸터와 닫기 버튼을 갖추어 폼이나 스크롤되는 콘텐츠 등 풍부한 내용을 담을 때 사용합니다.
- [Divider](./divider.md) — 시각적 구분자로써 역할을 하며, 콘텐츠 간의 구획을 명확히 나누는 데 사용하는 컴포넌트입니다.
- [Field Button](./field-button.md) — 입력 필드 형태의 버튼으로, 선택창이나 피커를 열 때 사용합니다. 선택이 완료되면 버튼 라벨에 선택된 값이 표시됩니다.
- [Floating Action Button](./floating-action-button.md) — 화면 상에 떠 있으며 주요 액션을 실행하는 버튼입니다.
- [Help Bubble](./help-bubble.md) — 사용자에게 컴포넌트의 상태나 특정 기능에 대한 추가 정보를 제공하는 컴포넌트입니다.
- [Help Bubble Tooltip](./help-bubble-tooltip.md) — 포인터를 올리거나 포커스했을 때 보조 정보를 보여주는 툴팁 형태의 Help Bubble입니다.
- [Identity Placeholder](./identity-placeholder.md) — 인물을 표현하는 이미지가 로드되지 않았을 때 보여지는 대체 시각 요소입니다.
- [Image Frame](./image-frame.md) — 사용자가 업로드한 이미지를 표시하기 위한 컴포넌트입니다.
- [List](./list.md) — 가로 행으로 구성된 콘텐츠를 표현하는 컴포넌트입니다.
- [Manner Temp](./manner-temp.md) — 사용자의 매너온도를 시각적으로 표현하는 컴포넌트입니다. 신뢰도/매너 정도를 직관적으로 보여주는 데에 사용합니다.
- [Manner Temp Badge](./manner-temp-badge.md) — 매너 온도를 배지 형태로 표현하는 컴포넌트입니다. 콤팩트한 공간에서 사용자의 매너 온도 레벨을 간단히 표시할 때 사용됩니다.
- [Menu](./menu.md) — 사용자가 취할 수 있는 선택지나 액션 리스트를 제공하는 컴포넌트입니다.
- [Page Banner](./page-banner.md) — 페이지 상단에 위치하며 사용자에게 전체적인 상태나 중요한 메시지를 전달하는 상위 레벨 메시지 컴포넌트입니다.
- [Progress Circle](./progress-circle.md) — 작업이 진행 중임을 알리거나 작업 시간을 시각적으로 나타내는 데 사용됩니다.
- [Pull To Refresh](./pull-to-refresh.md) — 사용자가 화면을 아래로 당겨 콘텐츠를 새로고침할 수 있게 해주는 컴포넌트입니다. 모바일 환경에서 최신 콘텐츠를 불러올 때 사용됩니다.
- [Quantity Picker](./quantity-picker.md) — 정수 단위의 수량을 늘리거나 줄일 때 사용하는 컴포넌트입니다.
- [Radio Group](./radio-group.md) — 여러 옵션 중 하나를 선택할 수 있도록 할 때 사용하는 컴포넌트입니다.
- [Reaction Button](./reaction-button.md) — 사용자가 콘텐츠에 대한 반응을 표현할 수 있게 해주는 컴포넌트입니다. 좋아요, 관심있어요 등의 감정적 피드백을 간편하게 제공할 때 사용됩니다.
- [Result Section](./result-section.md) — 데이터 로딩 결과, 사용자의 액션 완료 여부 등 사용자에 액션에 대한 결과를 제공하는 템플릿입니다. 주로 전체 화면이나 특정 영역을 차지하여 다음 액션을 유도하거나 현재 상황을 안내하는 역할을 합니다.
- [Scroll Fog](./scroll-fog.md) — 스크롤 가능한 영역에서 사용자에게 추가 콘텐츠가 있음을 시각적으로 알려주는 힌트 역할을 합니다.
- [Segmented Control](./segmented-control.md) — 여러 옵션 중 하나를 선택하여 관련 콘텐츠를 즉시 필터링하거나 전환할 때 사용하는 컴포넌트입니다.
- [Select](./select.md) — 트리거를 눌러 열리는 목록에서 값을 선택하는 컴포넌트입니다.
- [Select Box](./select-box.md) — 명확한 테두리를 가진 컨테이너를 활용하여, 정의된 목록 중 하나 이상의 옵션을 선택하는 UI 요소입니다.
- [Side Panel](./side-panel.md) — 화면 좌측 또는 우측 가장자리에서 슬라이드하여 나타나는 패널 컴포넌트입니다. 데스크탑 환경에서 추가 콘텐츠나 네비게이션을 제공할 때 사용됩니다.
- [Skeleton](./skeleton.md) — 콘텐츠가 로딩되는 동안 이후 나타날 요소의 윤곽을 미리 보여주어 로딩 시간을 짧게 느끼게 하는 UI 요소입니다.
- [Slider](./slider.md) — 지정된 범위 내에서 하나 또는 두 개의 값을 선택해 입력할 수 있는 컴포넌트입니다.
- [Snackbar](./snackbar.md) — 화면 하단에 일시적으로 나타나 상태나 결과를 안내하는 컴포넌트입니다.
- [Swipeable Menu Sheet](./swipeable-menu-sheet.md) — 사용자의 작업과 관련된 선택지를 제공하는 시트 형태의 컴포넌트입니다.
- [Switch](./switch.md) — 특정 설정 및 상태를 즉시 켜거나 끌 수 있도록 하는 컴포넌트입니다.
- [Tabs](./tabs.md) — 한 화면 내에서 콘텐츠를 탭 단위로 구분하여 전환할 수 있는 컴포넌트입니다.
- [Tag Group](./tag-group.md) — 아이콘과 텍스트 태그를 수평으로 나열해 여러 속성·상태·메타데이터를 한눈에 보여주는 정보 요약 컴포넌트입니다.
- [Text Field Input](./text-field-input.md) — 한 줄 텍스트를 입력받는 컴포넌트입니다.
- [Text Field Textarea](./text-field-textarea.md) — 여러 줄의 긴 텍스트를 입력받고 자동으로 높이를 조절하는 컴포넌트입니다.
- [Toggle Button](./toggle-button.md) — 사용자가 특정 상태를 켜거나 끌 수 있게 해주는 버튼 형태의 컴포넌트입니다. 필터링이나 뷰 전환과 같은 즉각적인 상태 변경에 사용됩니다.

## Concepts

- [Composition](./concepts/composition.md) — 컴포넌트를 조합하여 복잡한 UI를 구성하는 방법과 원칙을 설명합니다.
- [Interaction States](./concepts/interaction-states.md) — SEED React 컴포넌트가 디바이스 환경에 따라 상호작용 스타일을 적용하는 방식을 설명합니다.
- [Responsive Design](./concepts/responsive-design.md) — Viewport 크기에 따라 레이아웃과 스타일을 조정하는 방법을 알아봅니다.
- [Snippet](./concepts/snippet.md) — 자주 사용되는 UI 패턴을 스니펫으로 제공하여 개발 효율성을 높이는 방법을 안내합니다.

## Iconography

## Layout

- [Box](./layout/box.md) — Box 컴포넌트는 가장 기초적인 레이아웃 컴포넌트입니다. 디자인 토큰을 JSX에서 사용할 수 있도록 도와줍니다.
- [Flex](./layout/flex.md) — Flex 컴포넌트는 flexbox를 사용하며 디자인 토큰을 JSX에서 사용할 수 있도록 도와줍니다.
- [Float](./layout/float.md) — Float 컴포넌트는 특정 위치에 고정된 요소를 배치할 때 사용합니다.
- [Grid](./layout/grid.md) — Grid 컴포넌트는 CSS Grid를 사용하며 디자인 토큰을 JSX에서 사용할 수 있도록 도와줍니다.
- [HStack](./layout/h-stack.md) — 가로로 쌓이는 레이아웃을 구성합니다. 디자인 토큰을 JSX에서 사용할 수 있도록 도와줍니다.
- [VStack](./layout/v-stack.md) — 세로로 쌓이는 레이아웃을 구성합니다. 디자인 토큰을 JSX에서 사용할 수 있도록 도와줍니다.

## Typography
