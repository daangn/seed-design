## Overview

## Arguments

- $COMPONENT_NAME: 만들 컴포넌트 이름
- $FIGMA_IMAGE: 피그마에 제작된 컴포넌트 캡쳐 이미지
- $ADDITIONAL_INSTRUCTIONS: 컴포넌트 제작에 필요한 추가 맥락
