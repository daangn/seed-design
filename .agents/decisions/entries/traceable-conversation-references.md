# 대화의 판단에는 실제 적용한 참고 근거를 연결한다

## 결정과 적용 조건

- 계획·설계 제안·리뷰·결과 답변에 실제 적용한 lesson·decision·지침을 짧은 참고 근거 appendix로 연결하고 이번 판단에 어떤 영향을 줬는지 적는다.
- 제안·확정된 결정·관찰한 사실·새 해석을 구분한다. 조회만 한 자료를 적용 근거로 쓰지 않고, 중요한 충돌·예외의 근거도 표시한다.
- 형식과 예외의 원천은 Attention Kind의 참고 근거 지침이다. 단순 확인·같은 판단의 반복은 목록을 반복하지 않으며 최종 결과는 필요한 근거를 자체적으로 포함한다.

## 배경·대안·비용

- 결정과 lesson이 쌓여도 답변에서 연결하지 않으면 사용자가 과거 맥락이 실제로 적용됐는지 확인하기 어렵다.
- 모든 읽은 파일을 나열하면 판단의 근거가 묻힌다. 실제 적용한 핵심 자료와 적용 조건을 연결하면 검토할 대상을 좁힐 수 있다.
- 링크와 상태를 확인하는 비용이 생긴다. 자동 인용 도구 없이 문서 지침으로 시작하고, 원문을 읽은 범위와 실행 증거를 과장하지 않는다.

## 확정 근거와 재검토

- 확정 근거: 2026-10-06 사용자 명시 요청. 대화에서 어떤 lesson·decision을 참고해 판단했는지 볼 수 있도록 appendix에 레퍼런스를 연결해 달라고 요청했다.
- 담당자: 별도 유지 담당자는 미정이다. 형식 변경은 요청자 또는 관련 지침 담당자와 판단한다.
- 재검토 조건: 링크가 끊기거나, 반복 목록이 읽기를 방해하거나, 근거와 주장 사이의 연결이 부정확하면 인용 범위와 형식을 보완한다.
- 현재 구현은 응답 지침이다. 모든 클라이언트의 실제 준수나 자동 링크 검사를 강제한 상태는 아니다.
