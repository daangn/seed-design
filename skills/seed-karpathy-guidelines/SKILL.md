# Karpathy Guidelines

구현 전·중에 문제·가정·불확실성·성공 조건을 드러내고 요청 범위의 최소 변경을 한다.

- 요청과 대상 경로의 규칙을 기준으로 적용하며, 공개 계약·도메인에 영향을 주는 미확정 선택은 사용자에게 확인한다.
- 단순 작업에는 필요한 원칙만 적용한다. 스킬이 요청 밖 리팩터링이나 추가 권한을 허용하지 않는다.
- 상세 원칙과 예시는 [원본 지침](references/guidelines.md)을 읽는다. 출처·수정 내역·라이선스는 [UPSTREAM.md](UPSTREAM.md)를 따른다.
