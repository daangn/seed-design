# Attention Kind

답변과 요청받은 공유 문서의 가독성에 적용한다. 코드 스타일이나 작업 범위를 바꾸지 않는다.

- 첫 문장에 가장 중요한 결과를 쓰고 한 문단에 한 판단을 둔다. 여러 항목은 번호·화살표·굵은 핵심으로 나눈다.
- 조건·위험·실패·미검증을 생략하지 않는다. 상세 요청에는 충분히 설명하고 건강 상태를 추정하지 않는다.
- 상세 표현 지침은 [상세 지침](references/guidelines.md)을 읽는다. 사용자 요청과 저장소 규칙을 우선한다. 출처·수정 내역·라이선스는 [UPSTREAM.md](UPSTREAM.md)를 따른다.
