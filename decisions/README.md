# 결정 기록

방향·공개 계약·팀 품질 정책을 사람이 결정할 때 사용한다. 현재의 구조 판단은 [컴포넌트 아키텍처 결정](../skills/seed-component/references/architecture-decisions.md), 실무 교훈은 [학습 기록](../.agents/learnings/AGENTS.md)이 원천이다. 이 폴더는 앞으로 생기는 결정을 연결하며 기존 기록을 복제하지 않는다.

1. [템플릿](template.md)을 복사해 `<id>.md`를 만든다. 제안은 `proposed`이며 결정 담당자·검토자가 확인한 근거가 생긴 뒤에만 `accepted`로 바꾼다.
2. 문제·선택 이유·대안 비용·적용 경로·예외·검사 수단·재검토 조건을 남긴다. 담당자가 미정이면 미정으로 기록한다.
3. 관련 PR·lesson·실제 강제 수단을 링크한다. 검사 설치와 실행·통과 증거를 구분한다. lesson의 승격은 학습 기록 규칙을 따른다.
4. 변경·대체 시 과거 이유를 보존하고 새 결정의 링크를 남긴다. 가장 좁은 AGENTS·Skill·설정·테스트를 실행 지침의 원천으로 삼는다.
5. [harness 시각화](../harness/README.md)를 재생성해 링크와 상태를 확인한다.
